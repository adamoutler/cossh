## 1. Feature Overview
SSH-239 delivers an enterprise-grade adaptive layout architecture and full UI/mapper integration for the terminal extra keys system:
1. **Adaptive Display Resolver (`AdaptiveLayoutResolver.kt`)**: Dynamically resolves device form factors into five primary layout modes:
   - `SINGLE_PANE_COMPACT`: Handsets and narrow split windows (< 600dp).
   - `DUAL_PANE_MEDIUM`: Folded unfolded tablets and medium screens (600dp..840dp).
   - `EXPANDED_DESKTOP_DEX`: Samsung DeX, ChromeOS, and large desktop windows (>= 840dp).
   - `TABLETOP_HALF_OPEN`: Foldables with a horizontal hinge in half-opened posture, partitioning the terminal canvas to the top pane and the virtual extra keys deck to the bottom pane.
   - `BOOK_POSTURE_SPLIT`: Foldables with a vertical hinge in half-opened or separating posture, dividing left/right split panes around the physical hinge.
2. **Hardware Keyboard & Extra Keys Visibility**:
   - `shouldShowVirtualExtraKeys`: Automatically set to `!environment.hasHardwareKeyboard`, ensuring full-canvas utilization when physical keyboards are attached.
   - Tabletop override: In `TABLETOP_HALF_OPEN` posture, `shouldShowVirtualExtraKeys` is unconditionally `true` so the bottom pane acts as an on-screen terminal keyboard and modifier cockpit.
3. **Settings Persistence (`SettingsManager.kt`)**:
   - `globalExtraKeysPreset`: Persisted preference for the active preset name.
   - `extraKeysPreset`: Enum accessor for `ExtraKeysPresetId` with safe fallback to `ExtraKeysPresetId.DEFAULT` upon unexpected strings.
4. **Extra Keys UI Integration (`TerminalExtraKeys.kt`)**:
   - Backward-compatible optional parameters: `presetId: ExtraKeysPresetId = ExtraKeysPresetId.DEFAULT` and `onKeySpecPress: ((ExtraKeySpec) -> Unit)? = null`.
   - Page 0 renders structured rows from `ExtraKeysPresets.getPreset(presetId)`.
   - `ExtraKeyButton` applies Compose accessibility semantics: `semantics { this.contentDescription = contentDescription ?: text }`.
5. **Key Dispatching Engine (`TerminalKeyMapper.kt`)**:
   - `onKeySpecPress(spec: ExtraKeySpec)`: Toggles modifiers or emits payload/mapped bytes, consuming sticky modifiers on key release.
   - `onExtraKeyPress(key: String)`: Adds fallback UTF-8 byte conversion for custom preset symbols (e.g., `:`, `/`, `{`, `}`, `~`, `|`).
