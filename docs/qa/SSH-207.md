### 1. Architectural & Logic Implementation
* **Hardened Keepalive Provider (`SecureSshConfig.kt`):**
  - Explicitly configured `keepAliveProvider = KeepAliveProvider.KEEP_ALIVE` to activate cryptographic keepalive probe exchanges.
  - Hardened ciphers, MACs, and KEX retain complete isolation from deprecated primitives.
* **Keepalive Coordinator Handshake (`SshHandshakeCoordinator.kt`):**
  - Added support for `keepAliveIntervalSeconds` parameter. When positive, sets `client.connection.keepAlive.keepAliveInterval`.
  - Reset socket read timeout `client.timeout` from 10s to 0 immediately upon entering streaming mode so quiescent socket reads do not throw false timeouts.
* **Profile Configuration & UI:**
  - `ConnectionProfile.kt`: Added `keepAliveIntervalSeconds: Int = 15`.
  - `AddEditProfileScreen.kt` & `AddEditProfileViewModel.kt`: Added segmented button selector with presets: 0s (Off), 15s, 30s, 60s under Advanced Configuration with explanatory help text.
