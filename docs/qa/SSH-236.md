# Verification Proof for SSH-236: Portable Profile Exporter & JuiceSSH Importer

## Overview
SSH-236 delivers a comprehensive import/export compatibility subsystem enabling seamless migration from JuiceSSH backups and portable OpenSSH and JSON profile synchronization while eliminating secret leakage and directive injection attack vectors.

---

## Key Components Implemented

### 1. `com.adamoutler.ssh.network.HostValidator`
- **Control Character Stripping:** Neutralizes control characters (`\u0000..\u001F`, `\u007F`), carriage returns (`\r`), newlines (`\n`), and tabs across all input and output fields.
- **Host Validation:** Enforces RFC 1123 hostname compliance, IPv4 dotted-quad verification, and IPv6 hex colon validation (including bracketed `[::1]` notation).
- **Port Bounds Checking:** Restricts valid port numbers to `1..65535`.
- **Username Sanitization:** Neutralizes shell delimiters (`;`, `&`, `|`, `` ` ``, `$`, `<`, `>`, quotes).

### 2. `com.adamoutler.ssh.network.JuiceSshImporter`
- **JSON Structure Parsing:** Parses standard JuiceSSH backup JSON structures containing `connections` (`name`, `address`, `port`, `username`, `type` / protocol, `group`) and `groups` (`id`, `name`).
- **Group Hierarchy Resolution:** Resolves JuiceSSH group IDs to human-readable folder names and populates `ConnectionProfile.folderId`.
- **DoS Limits:** Enforces strict 1 MB (`MAX_PAYLOAD_BYTES`) payload limits and 500 entry bounds (`MAX_ENTRY_COUNT`) across both string and stream (`InputStream`) parsers.
- **Collision Resolution Strategies:**
  - `ImportCollisionStrategy.SKIP`: Retains existing profiles and skips incoming collisions.
  - `ImportCollisionStrategy.OVERWRITE`: Updates existing profiles in-place with incoming attributes, retaining original IDs and sort order.
  - `ImportCollisionStrategy.RENAME`: Resolves collisions by generating unique suffixed identifiers (`"Profile (1)"`, `"Profile (2)"`).

### 3. `com.adamoutler.ssh.network.PortableProfileExporter`
- **OpenSSH Stanza Generation (`exportToOpenSshConfig`):** Generates standard OpenSSH `~/.ssh/config` blocks (`Host`, `HostName`, `User`, `Port`, `ProxyJump`, `ServerAliveInterval`) for SSH profiles.
- **Directive Injection Defense:** Strips control characters and converts alias spaces into hyphens to prevent malicious injection of OpenSSH execution directives (`ProxyCommand`, `LocalCommand`, `PermitLocalCommand`, `Match`).
- **Round-Trip Fidelity:** 100% verified bi-directional round-trip compatibility with `OpenSshConfigParser.parse(...)`, including nested `ProxyJump` jump-host relationship preservation.
- **Leak-Proof JSON Export (`exportToSanitizedJson`):** Serializes connection metadata (`nickname`, `host`, `port`, `username`, `protocol`, `authType`, `groupId`, `useMosh`, `keepAliveIntervalSeconds`) while guaranteeing zero passwords, zero ciphertexts, zero private keys, and zero keystore references are exported.
