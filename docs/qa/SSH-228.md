# QA Audit: SSH-228 — OpenSSH User & Host Certificate Wire Parser, CA Signature Verification & Host-CA Wildcard Trust Store

## Epic
**SSH-187**: [EPIC] Power Features — SFTP, Mosh, Automation, Accessibility

## Scope of Implementation
- **OpenSSH Certificate Data Structures (`OpenSshCertificate.kt`):**
  - Created `OpenSshCertType` enum (`USER(1)`, `HOST(2)`).
  - Created `OpenSshCertificate` data class with full fields matching `PROTOCOL.certkeys`.
  - Created `CertValidationResult` sealed interface for granular validation outcomes (`Valid`, `Expired`, `NotYetValid`, `InvalidPrincipal`, `UnsupportedCriticalOption`, `InvalidSignature`, `InvalidCertType`, `CaNotTrusted`).
- **Binary Wire Parser (`OpenSshCertificateParser.kt`):**
  - Implemented binary wire reader/writer adhering to RFC 4251 and `PROTOCOL.certkeys`.
  - Added support for Ed25519 (`ssh-ed25519-cert-v01@openssh.com`), RSA (`ssh-rsa-cert-v01@openssh.com`, `rsa-sha2-256-cert-v01@openssh.com`, `rsa-sha2-512-cert-v01@openssh.com`), and ECDSA (`ecdsa-sha2-nistp256-cert-v01@openssh.com`).
  - Added helpers `parse(encodedOrAuthorizedLine: String)`, `parseWireBytes(wireBytes: ByteArray)`, `serializeWireBytes(cert: OpenSshCertificate)`, and `encodeAuthorizedLine(cert: OpenSshCertificate)`.
- **Cryptographic Certificate Validator (`OpenSshCertificateValidator.kt`):**
  - Temporal validity checks comparing `validAfterSeconds` and `validBeforeSeconds` with unsigned long comparison.
  - Principal matching supporting exact hostnames, wildcard globs (`*.internal.corp`), and empty host principals.
  - Strict Critical Options trap enforcement: rejects unrecognized critical options.
  - Cryptographic signature validation across Ed25519, RSA-SHA2-256/512, and ECDSA with RFC 5656 `(mpint r, mpint s)` to ASN.1 DER conversion.
- **SSHJ Certificate Key Provider (`CertificateKeyProvider.kt`):**
  - Implemented `KeyProvider` bridge returning `com.hierynomus.sshj.userauth.certificate.Certificate` and associated private key for SSH authentication.
- **Wildcard Host-CA Trust Store (`KnownHostsManager.kt`):**
  - Full `@cert-authority` line parsing with wildcard pattern matching and negation (`!untrusted.corp,*.corp`).
  - Implemented `findTrustedCaForHost(hostname, port): List<PublicKey>`.
  - Implemented `saveCertAuthority(hostPattern, keyType, keyBlobBase64, comment)`.
  - Ensured `hashAllPlaintextHosts()` ignores `@cert-authority` lines.
- **Zero-TOFU Host Verification (`SshConnectionManager.kt`):**
  - In `TofuHostKeyVerifier`, added pre-check for OpenSSH Host Certificates. Automatically verifies certificate against Host-CA trust store and bypasses TOFU prompts when valid.
- **UI Components (`SshCertificateBottomSheet.kt` & `KnownHostsScreen.kt`):**
  - Created `SshCertificateBottomSheet` displaying certificate details.
  - Added Host-CA filter chip and `HOST-CA 🏛️` badge to `KnownHostsScreen.kt`.
