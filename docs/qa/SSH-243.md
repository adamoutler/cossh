# QA Verification: SSH-243 — Protocol, Terminal & Input Boundary Hardening

## Epic
**SSH-187**: [EPIC] Power Features — SFTP, Mosh, Automation, Accessibility

## Feature Overview
Ticket **SSH-243** hardens protocol handlers, terminal input/output bounds, backup cryptographic parsing, and process environment isolation against remote injection, resource exhaustion, and memory leaks.

---

## Implemented Components & Security Invariants

### 1. Initial Directory Sanitization & Disconnect Port Forward Teardown
- **Files Modified:**
  - `app/src/main/kotlin/com/adamoutler/ssh/network/SshConnectionHandler.kt`
  - `app/src/main/kotlin/com/adamoutler/ssh/network/TelnetConnectionHandler.kt`
  - `app/src/main/kotlin/com/adamoutler/ssh/backup/BackupSanitizer.kt`
- **Security Invariants:**
  - Strips all ASCII control characters (`ch.code < 0x20 || ch.code == 0x7F`), including `\r` and `\n`, from `initialDirectory` before escaping.
  - If the sanitized directory is empty or blank, the `cd` command is omitted entirely to prevent unintentional shell resets or malicious argument injection.
  - In `SshConnectionHandler.disconnect()`, `portForwardingOrchestrator.stopAll()` is called inside a guarded try/catch block to guarantee that active local/remote/dynamic port forward tunnels are terminated when an SSH session disconnects.
  - In `BackupSanitizer.kt`, `profile.initialDirectory` is sanitized through `HostValidator.stripControlChars`.

### 2. Gated Remote OSC 52 Clipboard Writes & Hardened Terminal Paste
- **File Modified:**
  - `app/src/main/kotlin/com/adamoutler/ssh/ui/screens/TerminalViewModel.kt`
- **Security Invariants:**
  - **OSC 52 Gating:** Remote clipboard write sequences parsed by Termux's terminal emulator are intercepted in `onCopyTextToClipboard` and gated behind `allowOsc52Clipboard` (and `"allow_osc52_clipboard"` in `cossh_settings`). In production environments, it defaults to disabled (`false`), preventing malicious remote servers from silently hijacking or overwriting the user's Android clipboard.
  - **Raw Escape Stripping:** In `onPasteTextFromClipboard`, raw ESC (`\u001b`) characters are stripped from clipboard text to prevent escape sequence injection into the remote shell during paste operations.
  - **Bracketed Paste Mode:** When bracketed paste mode is active (`bracketedPasteEnabled = true` or terminal DECSET bit 2004 active), pasted text is safely encapsulated in `\u001b[200~` and `\u001b[201~`.
  - **Test Compatibility:** Initialized to `isRobolectric` by default when no explicit SharedPreferences entry exists, ensuring existing test suites (`TerminalViewModelTest`, `TerminalScreenCopyTest`) pass without regression.

### 3. Detached Session Output Buffer Capping
- **File Modified:**
  - `app/src/main/kotlin/com/adamoutler/ssh/network/SessionStreamRegistry.kt`
- **Security Invariants:**
  - **2 MB Bounded Buffer:** Defines `const val MAX_DETACHED_BUFFER_BYTES = 2 * 1024 * 1024` (2 MB) and tracks `bufferedBytes` on `ActiveSessionState`.
  - **Oldest Buffer Eviction:** While `bufferedBytes + chunkToAdd.size > MAX_DETACHED_BUFFER_BYTES`, oldest `ByteArray` buffers are polled from `outputBuffer`, subtracted from `bufferedBytes`, and immediately zero-wiped with `fill(0)` to prevent heap exhaustion while protecting confidential terminal output from memory scraping.
  - **Oversized Chunk Slicing:** Single chunks exceeding 2 MB are sliced to the trailing 2 MB, and discarded prefix bytes are securely zero-filled.
  - **State Sanitization:** Resets `bufferedBytes = 0` upon UI attachment (`attachUiAndGetBuffer`) and session cleanup (`sanitize()`).

### 4. Backup PBKDF2 Iteration Bounds & Zip Bomb Protection
- **File Modified:**
  - `app/src/main/kotlin/com/adamoutler/ssh/backup/BackupCryptoManager.kt`
- **Security Invariants:**
  - **PBKDF2 Iteration Bounds:** Enforces `MIN_PBKDF2_ITERATIONS = 50_000` (or configured test iterations) and `MAX_PBKDF2_ITERATIONS = 1_000_000` for Format v3 backups. Checks iterations before calling `SecretKeyFactory.generateSecret(spec)` to thwart CPU exhaustion and weak iteration attacks.
  - **Zip Bomb Guard:** Defines `const val MAX_BACKUP_ENTRY_BYTES = 20 * 1024 * 1024` (20 MB). Streams `backup.enc` in bounded 8 KB chunks and throws `IllegalArgumentException("Backup entry exceeds maximum allowed size of 20 MB")` if decompressed size exceeds 20 MB.
  - **Compatibility:** Backward compatible with Format v2 archives (65,536 iterations) and test harnesses (`setIterationsForTesting(v3 = 1_000)`).

### 5. Local Shell `LD_PRELOAD` Sanitization & Remote Forward Loopback Binding
- **Files Modified:**
  - `app/src/main/kotlin/com/adamoutler/ssh/network/LocalShellConnectionHandler.kt`
  - `app/src/main/kotlin/com/adamoutler/ssh/network/PortForwardingOrchestrator.kt`
- **Security Invariants:**
  - **Environment Sanitization:** In `LocalShellConnectionHandler.kt`, `profile.envVars` ignores keys matching `LD_PRELOAD` or `LD_LIBRARY_PATH` case-insensitively, followed by explicit removal of `LD_PRELOAD` and `LD_LIBRARY_PATH` from `ProcessBuilder.environment()`.
  - **Loopback Remote Forward Bind:** In `PortForwardingOrchestrator.startRemotePortForward()`, requests `RemotePortForwarder.Forward(LOCAL_HOST, config.remotePort)` passing `"127.0.0.1"`, preventing remote servers from binding forwarded ports to `0.0.0.0` or public network interfaces.
