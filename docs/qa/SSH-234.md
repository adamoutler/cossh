# QA Audit: SSH-234 — Post-Quantum Hybrid Key Exchange (sntrup761x25519-sha512@openssh.com) & DNSSEC SSHFP Host Verification

## Epic
**SSH-188**: [EPIC] Security Differentiators — "Most Secure SSH Client on Android"

## Scope of Implementation
1. **Post-Quantum Hybrid Key Exchange (`Sntrup761X25519KeyExchange.kt`):**
   - Implemented OpenSSH hybrid Post-Quantum key exchange algorithm `sntrup761x25519-sha512@openssh.com`.
   - Combines Streamlined NTRU Prime lattice-based KEM (`SNTRUPrimeParameters.sntrup761`) with classical Curve25519 (`X25519`).
   - Client ephemeral public key: 1190 bytes (1158 bytes sntrup761 public key + 32 bytes X25519 public key).
   - Server ephemeral public key: 1071 bytes (1039 bytes sntrup761 ciphertext + 32 bytes server X25519 public key).
   - Shared secret combiner: $K = \text{SHA-512}(ss_{\text{sntrup761}} \parallel ss_{\text{x25519}})$ converted to an SSH mpint.
   - Enforced volatile state sanitization: all ephemeral secret byte arrays ($ss_{\text{sntrup761}}$, $ss_{\text{x25519}}$, intermediate combined bytes) are zero-wiped in `finally` blocks.
   - Implemented `Sntrup761X25519KeyExchange.Factory` implementing `Factory.Named<KeyExchange>`.
2. **Configuration Suite Prioritization (`SecureSshConfig.kt`):**
   - Registered `Sntrup761X25519KeyExchange.Factory()` at index 0 of `keyExchangeFactories` in `SecureSshConfig.kt`.
   - Verified that legacy broken algorithms (SHA-1, MD5, 3DES, Blowfish, DH Group 1) remain strictly purged.
3. **DNSSEC SSHFP Verification Engine (`SshfpVerifier.kt`):**
   - Implemented RFC 8484 DNS binary wire format query builder with EDNS0 OPT RR (Type 41) setting the `DO` (DNSSEC OK) bit (`0x8000`).
   - Implemented DNS wire response parser extracting the `AD` (Authenticated Data) bit (bit 10 of flags, `0x0020`) and RFC 4255 SSHFP Resource Records (Type 44).
   - Implemented `verifyHostKeyWire` host key verifier validating raw host key wire bytes against authenticated DNSSEC digests, handling `ValidDnssecMatch`, `DnssecNotAuthenticated`, `FingerprintMismatchAlert`, and `NoRecordsFound`.
