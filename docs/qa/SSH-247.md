# QA Proof & Architecture Certification: SSH-247

**Ticket:** SSH-247  
**Title:** Binary & Reverse-Engineering Hardening  
**Status:** Verification Complete  

---

## 1. User Story

*As a paranoiac Android security architect, I want release binaries to enforce aggressive R8 full-mode obfuscation, strip debug and verbose string xrefs, omit raw exception and connection traces from stdout, prune full DWARF native debugging symbols, and neutralize test-only billing override hooks in production environments, so that static and dynamic reverse-engineering attacks (Frida, decompilation, binary analysis) fail to expose application architecture, credentials, or bypass premium feature entitlements.*

---

## 2. Implementation Summary

1. **R8 Full Mode & ProGuard Rules (`gradle.properties`, `app/proguard-rules.pro`):**
   - Enabled R8 full-mode optimization across all modules:
     - `android.enableR8.fullMode=true` in `gradle.properties`.
   - Stripped verbose and debug `AppLog` calls from release binaries via `-assumenosideeffects`:
     - `-assumenosideeffects class com.adamoutler.ssh.util.AppLog { public static void v(...); public static void d(...); }`
   - Added `@JvmStatic` annotations to `AppLog` functions (`v`, `d`, `i`, `w`, `e`) in `com.adamoutler.ssh.util.AppLog` to guarantee static call signatures in bytecode.
   - Removed broad keep rules (`-keep class com.adamoutler.ssh.data.** { *; }`, `network`, `ui`, `security`, `backup`) while preserving `@kotlinx.serialization.Serializable` class and field rules, allowing R8 to shrink and obfuscate production classes while preventing serialization deserialization failures.

2. **Network & UI Base Logging Hardening:**
   - Replaced all raw `println(...)` calls with structured, ProGuard-strippable `AppLog.d(...)` and `AppLog.e(...)` across:
     - `com.adamoutler.ssh.network.SshConnectionManager`
     - `com.adamoutler.ssh.network.SshService`
     - `com.adamoutler.ssh.network.SshConnectionHandler`
     - `com.adamoutler.ssh.network.SshHandshakeCoordinator`
     - `com.adamoutler.ssh.network.PtyStreamBridge`
     - `com.adamoutler.ssh.ui.base.BaseAndroidViewModel`
     - `com.adamoutler.ssh.ui.base.BaseViewModel`
   - Eliminates sensitive connection parameters, hostnames, and stack traces from raw process stdout.

3. **Release Native Debug Symbol Hardening (`app/build.gradle.kts`):**
   - Configured release NDK debug symbol level:
     - `debugSymbolLevel = "SYMBOL_TABLE"`
   - Strips full DWARF debug symbols and disassembly metadata from `libtermux.so` while retaining basic symbol table mappings for production stack traces.

4. **Entitlement Tamper Guard Hardening (`com.adamoutler.ssh.billing.BillingManager`):**
   - Protected test bypass flag `forceCloudSyncEnabledForTest` behind runtime environment checks:
     - `isTestOverrideAllowed(isDebugBuild: Boolean, isRobolectricEnv: Boolean): Boolean = (isDebugBuild || isRobolectricEnv) && forceCloudSyncEnabledForTest`
     - `isTestEnvironment(): Boolean = com.adamoutler.ssh.BuildConfig.DEBUG || isRobolectric`
     - `isForceCloudSyncActive(): Boolean = isTestOverrideAllowed(BuildConfig.DEBUG, isRobolectric)`
   - In production release builds outside test environments (`!BuildConfig.DEBUG && !isRobolectric`), mutating `forceCloudSyncEnabledForTest` via Frida or memory patchers has zero effect.

## 3. Automated Verification Proof

### Automated Unit Test Suite (`ReverseEngineeringHardeningTest.kt`)
The dedicated automated verification suite tests all configuration assertions:
- `testProguardRules_stripsAppLogVerboseAndDebug`: Asserts `-assumenosideeffects` for `com.adamoutler.ssh.util.AppLog` (`v` and `d`).
- `testProguardRules_doesNotContainBlanketDomainKeeps`: Asserts blanket keep rules for `data`, `network`, `ui`, `security`, and `backup` packages are absent.
- `testGradleProperties_enablesR8FullMode`: Asserts `android.enableR8.fullMode=true` and absence of `android.enableR8.fullMode=false`.
- `testBuildGradle_configuresReleaseNdkSymbolTable`: Asserts `debugSymbolLevel = "SYMBOL_TABLE"` and absence of `debugSymbolLevel = "FULL"` in release build.
- `testNetworkClasses_containZeroRawPrintln`: Asserts zero raw `println(` calls in `SshConnectionManager.kt`, `SshService.kt`, `SshConnectionHandler.kt`, `SshHandshakeCoordinator.kt`, and `PtyStreamBridge.kt`.
- `testBillingManager_neutralizesTestOverrideInProduction`: Asserts `isTestOverrideAllowed` returns `false` in production release runtime when `forceCloudSyncEnabledForTest = true`, and returns `true` only in debug or Robolectric environments.
- `testBillingManager_isTestEnvironmentReflectsCurrentRuntime`: Asserts `isTestEnvironment` returns `true` in test harness.

### Existing Release Build Hardening Verification (`ReleaseBuildHardeningVerificationTest.kt`)
All assertions in `ReleaseBuildHardeningVerificationTest.kt` pass with 100% success, confirming zero regressions to SSH-246 rules.
