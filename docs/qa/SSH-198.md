# QA Verification Report: SSH-198 - Enforce ≥80% Jacoco Coverage Verification, Remediate Sonar Exclusions, and Pin CI Workflows

## Executive Summary & Security Rationale
In accordance with the **Supply Chain Paranoia** and **Zero-Tolerance Quality** engineering standards, this ticket hardens the CI/CD pipeline against supply-chain compromise, enforces automated coverage verification gates, and eliminates historical Sonar exclusions that masked coverage on core security-critical packages.

### Threat Model & Defenses
1. **Hostile Workflow Injection / Mutable Action Tags:** Mutable tags like `@v4` or `@v3` can be hijacked if an upstream action repository or credential is compromised. By pinning every GitHub and Forgejo action to an immutable 40-character cryptographic commit SHA, the pipeline guarantees cryptographic integrity of executed workflow dependencies.
2. **Excessive Runner Permissions:** The previous workflows defaulted to `contents: write`, granting actions write access to repository contents. Reverting top-level permissions to `contents: read` enforces the principle of least privilege.
3. **Hidden Regressions in Security Packages:** Historically, Sonar exclusions bypassed analysis on `crypto`, `network`, `sync`, `backup`, and `security`. By removing these exclusions, all cryptographic and communication infrastructure is subject to scrutiny.
4. **Automated Jacoco Enforcement:** `jacocoTestCoverageVerification` is registered and integrated directly into the test pipeline, enforcing an absolute `minimum = 0.80` instruction covered ratio.

## Jacoco Verification Task Configuration
Registered in `app/build.gradle.kts`:
```kotlin
tasks.register<JacocoCoverageVerification>("jacocoTestCoverageVerification") {
    group = "Verification"
    description = "Enforce >=80% instruction coverage verification."
    dependsOn("testDebugUnitTest")

    val fileFilter = listOf(
        "**/R.class", "**/R$*.class", "**/BuildConfig.*", "**/Manifest*.*",
        "**/*Test*.*", "android/**/*.*", "**/ui/theme/*.*", "**/*$serializer.class", "**/*$$serializer.class", "**/*$Companion.class",
        "**/ui/**/*.class", "**/*ScreenKt*.class", "**/*DialogKt*.class", "**/components/**/*.class"
    )
    val debugTree = fileTree(mapOf(
        "dir" to layout.buildDirectory.dir("tmp/kotlin-classes/debug").get().asFile,
        "excludes" to fileFilter
    ))
    val mainSrc = "${project.projectDir}/src/main/kotlin"

    sourceDirectories.setFrom(files(mainSrc))
    classDirectories.setFrom(files(debugTree))
    executionData.setFrom(fileTree(mapOf(
        "dir" to layout.buildDirectory.get().asFile,
        "includes" to listOf(
            "jacoco/testDebugUnitTest.exec",
            "outputs/unit_test_code_coverage/debugUnitTest/testDebugUnitTest.exec"
        )
    )))

    violationRules {
        rule {
            element = "BUNDLE"
            limit {
                counter = "INSTRUCTION"
                value = "COVEREDRATIO"
                minimum = 0.80.toBigDecimal()
            }
        }
    }
}
```

## Unit Test Coverage Suite

### 1. `TelnetConnectionHandlerCoverageTest.kt`
* `testDisconnectWhenClientIsNull`: Validates safe no-op when client is uninitialized.
* `testConnectWithoutInitialDirectoryAndFailedHost`: Validates graceful error handling when target host/port is unreachable.
* `testTelnetSessionLifecycleOptionsAndStreaming`:
  - Validates Telnet option negotiation (`TerminalTypeOptionHandler`, `EchoOptionHandler`, `SuppressGAOptionHandler`).
  - Validates CRLF translation and escaping in `autoFlushingStream` (single byte, byte array, byte array with offset, `\r\n` handling, single `\n` expansion).
  - Validates quote escaping in `initialDirectory`.
  - Validates inbound terminal stream consumption via `PtyStreamBridge` and `onOutput` callback.
* `testConnectionProtocolFactoryCreation`: Validates dynamic instantiation of `TelnetConnectionHandler` and `SshConnectionHandler` via `ConnectionProtocolFactory`.
* `testPtyStreamBridgeStreamingAndClearing`: Validates direct stream bridging via `PtyStreamBridge` and memory sanitization.
* `testAppLogFallbacks`: Validates `AppLog` logging fallbacks across all levels (`v`, `d`, `i`, `w`, `e`) with and without `Throwable`.

### 2. `DriveSyncAuthorizeCoverageTest.kt`
* `testAuthorizeScope_SuccessWithoutResolution`: Validates direct token reception when Google Play Identity resolution is not required.
* `testAuthorizeScope_SuccessWithResolution_StandardActivity`: Validates resolution flow with `startIntentSenderForResult` and asynchronous continuation resumption via `handleAuthorizationResult`.
* `testAuthorizeScope_SuccessWithResolution_MainActivity`: Validates resolution flow targeting `MainActivity.startAuthFlow`.
* `testAuthorizeScope_Failure_ThrowsException`: Validates error trapping, `oauthToken` sanitization, and exception re-throwing on authorization failure.
