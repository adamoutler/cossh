## Epic
**SSH-187**: [EPIC] Power Features — SFTP, Mosh, Automation, Accessibility

## Scope of Implementation
- **Storage Access Framework (SAF) Scoped Storage Bridge (`SftpSafBridge.kt`):**
  - Implemented `downloadToSafUri` and `uploadFromSafUri` streaming directly between remote SFTP files and Android `Uri` targets.
  - Introduced `SafIoHandler` interface and `ContentResolverSafIoHandler` to ensure testability without brittle Android `ContentResolver` subclassing.
- **Atomic Transfer Staging & Hygenic Cancellation:**
  - Files are streamed to private temporary cache files (`.cossh_part_<uuid>`) during download.
  - Full `finally` block ensures that any aborted transfer immediately deletes lingering staging files to prevent storage pollution.
- **In-App Reactive Transfer Banner (`SftpTransferBanner.kt`):**
  - Persistent bottom banner displaying transfer file name, current transfer rate, progress indicator, and cancel button.
  - Integrated into `SftpBrowserScreen` and reactive to `SftpTransferManager` state.
