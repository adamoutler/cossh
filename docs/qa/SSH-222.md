# QA Audit: SSH-222 — Hardened SFTP Client Engine with Strict Path Canonicalization & Traversal Guards

## Epic
**SSH-187**: [EPIC] Power Features — SFTP, Mosh, Automation, Accessibility

## Scope of Implementation
- **SFTP Domain Models & Transfer Contracts (`com.adamoutler.ssh.sftp.model`):**
  - Created `SftpFileItem` data class: attributes include `name`, `fullPath`, `size`, `formattedSize`, `isDirectory`, `isRegularFile`, `isSymlink`, `permissions`, `octalPermissions`, and `modifiedTimeEpochMs`.
  - Created `SftpTransferState` sealed interface: `Idle`, `Transferring(bytesTransferred, totalBytes, speedBytesPerSec, percent)`, `Completed(bytesTransferred)`, and `Failed(throwable)`.
- **Hardened SFTP Manager Core (`SftpClientManager.kt`):**
  - Abstracted transport via `SftpClientAdapter`:
    - Production `SshjSftpClientAdapter` wrapping SSHJ's built-in `SFTPClient`.
    - Zero-overhead in-memory test double `FakeSftpClientAdapter` executing unit tests in sub-milliseconds without external network dependencies or lockfile mutations.
  - Implemented remote operations: `listDirectory`, `createDirectory`, `delete`, `rename`, `setPermissions`, `stat`, `readFileContent`, `downloadFile`, `uploadFile`.
  - Configurable `CoroutineDispatcher` defaulting to `Dispatchers.IO` with test dispatcher injection support.
- **Strict Path Canonicalization & Traversal Neutralization (`SftpPathValidator.kt`):**
  - Normalizes Windows backslashes (`\`) to forward slashes (`/`).
  - Resolves relative segments (`.` and `..`).
  - Rejects traversal attempts escaping root or designated sandbox.
  - Neutralizes forbidden null bytes (`\u0000`).
- **Atomic File Staging & Zero-Retention Cleanup:**
  - Streams downloads to `.cossh_part_<uuid>` temporary files, executing atomic moves upon verified completion.
  - Immediately wipes partial staging files on cancellation or error.
  - Strict 2MB memory inspection safety ceiling for text viewing.
