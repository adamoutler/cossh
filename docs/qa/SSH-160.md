# SSH-160 QA Proof and Evidence

## Mission Statement
Implement a configurable "Keep Screen On" (Display Mode) feature for individual SSH terminal connections. This mode must be accessible via a long-press menu in the active terminal and saved as part of the connection profile.
- **Pocket-Dial Vulnerability:** The screen must NOT stay on if the proximity sensor is covered, regardless of the setting, to prevent accidental keystrokes.
- **Unattended Terminal Risk:** A "Smart Awake" mode should only keep the screen on while the device is actively receiving data, preventing infinite unlocks on a desk.

## Implementation Details
1. **Data Model:** Added `KeepScreenOnMode` enum (`SYSTEM_DEFAULT`, `SMART_AWAKE`, `ALWAYS_ON`) and `keepScreenOnMode` attribute to `ConnectionProfile` data class with full persistence.
2. **UI Surfaces:**
   - `AddEditProfileScreen.kt`: Segmented buttons for Display Mode selection (`System`, `Smart`, `Always On`).
   - `TerminalScreen.kt`: Long-press bottom sheet / settings menu options to adjust display mode on-the-fly.
3. **Sensor Integration:** `ProximitySensorManager` dynamically registers `Sensor.TYPE_PROXIMITY` listener, which correctly clears `FLAG_KEEP_SCREEN_ON` whenever `isProximityNear` is true, eliminating pocket wakeups.
4. **Window Flag Control:**
```kotlin
    androidx.compose.runtime.LaunchedEffect(keepScreenOnMode, isProximityNear, isDataFlowing) {
        if (window == null) return@LaunchedEffect

        val shouldKeepOn = com.adamoutler.ssh.data.shouldKeepScreenOn(
            mode = keepScreenOnMode,
            isProximityNear = isProximityNear,
            isDataFlowing = isDataFlowing,
        )

        if (shouldKeepOn) {
            window.addFlags(android.view.WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON)
        } else {
            window.clearFlags(android.view.WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON)
        }
    }
```
