# Verification Proof for SSH-244: Comprehensive Privacy & OS Leakage Hardening

## Overview
Ticket `SSH-244` implements defense-in-depth measures against OS-level data leakage, credential retention, unencrypted cloud exfiltration, and local entitlement tampering.

---

## Key Security Improvements Implemented

### 1. In-Memory Clipboard Reference Scrubbing & Sensitive Extras Flagging
- **`SecureClipboardManager.kt`**:
  - Scrubbed `lastCopiedText = null` inside `clearIfMatching()` immediately after clipboard contents are cleared, neutralizing in-memory secret retention.
  - Added `@VisibleForTesting internal fun getLastCopiedTextForTest(): String? = lastCopiedText` for unit test validation.
  - Automatically tags copied sensitive payloads with `ClipDescription.EXTRA_IS_SENSITIVE = true` on API 33+ to suppress OS clipboard preview notifications and overlay caching.
- **Routing All Clipboard Copies to `SecureClipboardManager`**:
  - **`KnownHostsViewModel.kt`**: Replaced manual clipboard operations in `copyFingerprintToClipboard(fingerprint)` with `SecureClipboardManager.copyToClipboard(context, fingerprint, "SSH Fingerprint", viewModelScope)`.
  - **`SecurityAuditLogScreen.kt`**: Routed JSON-LD export (`"CoSSH Audit Log JSON-LD"`) and raw record hash copy actions (`"Hash"`) through `SecureClipboardManager.copyToClipboard(...)`.
  - **`SftpTextViewerModal.kt`**: Routed preview text copy actions through `SecureClipboardManager.copyToClipboard(...)`.

### 2. Incognito Keyboard Options on Credential Fields
- **`QuickConnectBottomSheet.kt`**:
  - Configured password `OutlinedTextField` with `keyboardOptions = KeyboardOptions(autoCorrect = false, keyboardType = KeyboardType.Password, imeAction = ImeAction.Done)`.
- **`AddEditIdentityScreen.kt`**:
  - Configured password and manual PEM private key input fields with `keyboardOptions = KeyboardOptions(autoCorrect = false, keyboardType = KeyboardType.Password)`.
  - Added incognito keyboard options to locked password placeholders to ensure no IME personalization attaches.

### 3. Backup and Data Extraction Rules Hardening
- **`app/src/main/res/xml/backup_rules.xml`**:
  - Added exclusions for:
    - `<exclude domain="sharedpref" path="BillingPrefs.xml" />`
    - `<exclude domain="sharedpref" path="security_audit_anchor_prefs.xml" />`
    - `<exclude domain="file" path="security_audit" />`
- **`app/src/main/res/xml/data_extraction_rules.xml`**:
  - Fully mirrored identical exclusions under both `<cloud-backup>` and `<device-transfer>` sections to prevent device-to-device and cloud migration of billing cache and audit records.

### 4. Billing Entitlement Cryptographic Tamper Guard
- **`BillingManager.kt`**:
  - Implemented `computeEntitlementHmac(packageName: String): String` generating an HMAC-SHA256 signature tag over canonical entitlement token `"cloud_sync_entitled:true:${context.packageName}"` using a constant-time comparison.
  - Implemented `persistEntitlement(targetPrefs: SharedPreferences = prefs)` which atomically writes `cloud_sync_entitled = true` and `cloud_sync_entitled_hmac`.
  - Implemented `verifyEntitlementIntegrity(): Boolean` which verifies both the entitlement flag and the cryptographic HMAC tag, preventing unauthorized tampering, offline XML editing, or backup transfer replay attacks.

3. `testKnownHostsViewModel_routesFingerprintCopyThroughSecureClipboardManager`: Confirms known hosts fingerprints are tagged with `EXTRA_IS_SENSITIVE` and routed through `SecureClipboardManager`.

5. `testDataExtractionRules_excludesSensitiveDataInBothCloudAndDeviceTransfer`: Verifies all required exclusions exist in both `<cloud-backup>` and `<device-transfer>` sections of `data_extraction_rules.xml`.
6. `testBillingEntitlementTamperGuard_persistEntitlementGeneratesValidHmacAndPasses`: Verifies HMAC tag generation and verification.
7. `testBillingEntitlementTamperGuard_unverifiedFlagWithoutHmacFailsIntegrity`: Proves tampered boolean flags without HMAC are rejected.
8. `testBillingEntitlementTamperGuard_tamperedHmacTagFailsIntegrity`: Proves forged HMAC tags are rejected.
