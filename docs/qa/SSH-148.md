# SSH-148: Feature: Use Local Network DNS (Bypass Private DNS)

## User Story
As a user connecting to local servers (like a homelab or mock server), I need the app to resolve local hostnames even when Android's Private DNS is enabled, so that I don't have to disable system-wide secure DNS just to use the app.

## Implementation Strategy
1. **Per-Profile Setting**: Added `useLocalDns: Boolean = false` to the `ConnectionProfile` data class and corresponding ViewModel/State flows.
2. **UI Implementation**: Added a "Use Local Network DNS" switch to the "Advanced Configuration" section of the `AddEditProfileScreen`. It includes warning subtext that queries may be unencrypted.
3. **Network Layer**: Updated `SshHandshakeCoordinator.executeWithConnection()` to explicitly fetch the `activeNetwork` from the Android `ConnectivityManager` if `useLocalDns` is enabled. It uses `network.getAllByName(profile.host)` to resolve the IP locally, while wrapping it back into `InetAddress.getByAddress(profile.host, ipBytes)` so that the SSHJ library still correctly verifies the Host Key against the original hostname, avoiding TOFU mismatches or security bypasses.

## Verification Proof
- All unit and screenshot tests passed locally after the change.
- A new UI element was added successfully.
- Code implements local resolution safely and only when requested by the specific profile.
