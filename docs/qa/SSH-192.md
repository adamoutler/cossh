# Verification Proof for SSH-192: Replace Generic Notification Icon with Branded Monochrome CoSSH Status Bar Vector

## 1. Overview
Previously, `SshService` used `android.R.drawable.ic_dialog_info` as the small icon for both group summary notifications and individual SSH active session notifications. This resulted in a generic Android system informational circle `(i)` appearing in the status bar and notification drawer rather than distinctive CoSSH branding.

SSH-192 implements a dedicated, branded 24dp monochrome status bar vector (`ic_stat_ssh.xml`) featuring the CoSSH shield outline and terminal prompt (`>_`), conforming to Android status bar notification design guidelines.

### B. Service Notification Binding (`app/src/main/kotlin/com/adamoutler/ssh/network/SshService.kt`)
Replaced `android.R.drawable.ic_dialog_info` with `R.drawable.ic_stat_ssh` in `createSummaryNotification()` and `buildSessionNotification()`:
```kotlin
    internal fun createSummaryNotification(): Notification = NotificationCompat.Builder(this, CHANNEL_ID)
        .setContentTitle("CoSSH")
        .setContentText("${connectionJobs.size.coerceAtLeast(1)} Active Sessions")
        .setSmallIcon(R.drawable.ic_stat_ssh)
        .setGroup(GROUP_KEY_SSH)
        .setGroupSummary(true)
        .setOngoing(true)
        .build()

    internal fun buildSessionNotification(profileId: String, sessionId: String, profileName: String, contentText: String): Notification {
        // ...
        return NotificationCompat.Builder(this, CHANNEL_ID)
            .setContentTitle(profileName)
            .setContentText(contentText)
            .setSmallIcon(R.drawable.ic_stat_ssh)
            // ...
            .build()
    }
```

## 3. Test Verification
Robolectric unit test suite in `app/src/test/kotlin/com/adamoutler/ssh/network/SshServiceNotificationTest.kt` verifies:
1. `ic_stat_ssh` loads cleanly via `ContextCompat.getDrawable` and renders onto a 96x96 dark cobalt (`#0A192F`) bitmap with non-transparent white pixels (>1,500 white pixels confirmed).
2. `createSummaryNotification()` produces a notification with `smallIcon.resId == R.drawable.ic_stat_ssh`.
3. `buildSessionNotification()` produces a notification with `smallIcon.resId == R.drawable.ic_stat_ssh`.
4. Starting `SshService` foreground service registers `lastForegroundNotification.smallIcon.resId == R.drawable.ic_stat_ssh`.
