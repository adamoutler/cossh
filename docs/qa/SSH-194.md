# Verification Proof for SSH-194: Implement Terminal Bell Haptic Feedback and Shift Modifier State Tracking (readShiftKey)

## Overview
Implemented tactile haptic feedback for terminal bell events and complete Shift modifier tracking in `TerminalKeyMapper` and `TerminalScreen` for both physical hardware keyboards and virtual on-screen modifier controls.

## Key Changes
1. **Terminal Bell Haptic Trigger:**
   - In `TerminalViewModel.kt`, added `private val _bellEvents = MutableSharedFlow<Unit>(extraBufferCapacity = 1)` and `val bellEvents = _bellEvents.asSharedFlow()`.
   - In `TerminalViewModel.onBell(session: TerminalSession)`, invokes `_bellEvents.tryEmit(Unit)`.
   - In `TerminalScreen.kt`, added `LaunchedEffect(terminalViewModel, terminalViewRef)` collecting `terminalViewModel?.bellEvents` to invoke `terminalViewRef?.performHapticFeedback(android.view.HapticFeedbackConstants.KEYBOARD_TAP)`.
2. **Shift Modifier State Machine (`TerminalKeyMapper.kt`):**
   - Added `private var shiftState = ModifierState.INACTIVE` and `private var hardwareShiftPressed = false`.
   - Added `getShiftState()`, `onShiftButtonClick()`, `setHardwareShiftPressed(pressed: Boolean)`.
   - In `onKeyDown`: tracks hardware Shift press (`isShiftPressed`, `KEYCODE_SHIFT_LEFT`, `KEYCODE_SHIFT_RIGHT`).
   - In `onKeyUp`: clears hardware Shift press on release.
   - Sticky shift consumption: in `consumeStickyModifiers()` and `onCodePoint()`, resets `shiftState = ModifierState.INACTIVE` when in `STICKY` mode after a character is dispatched.
   - `readShiftKey(): Boolean = shiftState.isActive || hardwareShiftPressed`.
3. **TerminalViewClient Integration (`TerminalScreen.kt`):**
   - `override fun readShiftKey(): Boolean = terminalKeyMapper.readShiftKey()`.
   - `override fun onKeyUp(keyCode: Int, e: android.view.KeyEvent?): Boolean = terminalKeyMapper.onKeyUp(keyCode, e)`.
