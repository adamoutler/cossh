# QA Audit: SSH-226 — Pre-Connect Wake-on-LAN (WOL) Dispatcher & Rate-Limited Port Knocking Engine

## Epic
**SSH-187**: [EPIC] Power Features — SFTP, Mosh, Automation, Accessibility

## Scope of Implementation
- **Domain Models & Serialization (`ConnectionProfile.kt`):**
  - Added `WolConfig`, `KnockProtocol`, `PortKnockStep`, and `PortKnockingConfig` with full `@Serializable` annotations.
  - Added optional `wolConfig` and `portKnockingConfig` fields to `ConnectionProfile` with updated `equals()` and `hashCode()`.
- **Hardened Wake-on-LAN Engine (`WolManager.kt`):**
  - Strict 6-octet colon/hyphen MAC address regex validation (`^([0-9A-Fa-f]{2}[:-]){5}([0-9A-Fa-f]{2})$`).
  - Standard 102-byte magic packet construction: 6 bytes `0xFF` + 16 repetitions of target MAC.
  - Safe non-blocking broadcast dispatch over `DatagramSocket` on `Dispatchers.IO` with socket timeout and configurable post-wake delay.
- **Rate-Limited Port Knocking Engine (`PortKnockingManager.kt`):**
  - Sequential TCP socket connect attempts (bounded 400ms timeout) and UDP datagram probes.
  - Enforced 5000ms cooldown rate limit per target host to protect firewalls from flooding.
  - Configurable inter-step delays and post-knock propagation delays.
- **Pre-Connection Dispatcher (`SshHandshakeCoordinator.kt`):**
  - Pre-connect steps 1 (WOL) and 2 (Port Knocking) wired directly prior to socket connection in `executeWithConnection`.
  - Non-fatal error resilience: failures are logged via `AppLog` without crashing the app.
- **Configuration UI (`PreConnectActionsCard.kt` & `AddEditProfileScreen.kt`):**
  - Expandable Pre-Connect Actions card in profile editor.
  - Real-time MAC format validation and port knock sequence builder with TCP/UDP protocol selection chips.
  - TalkBack accessibility content descriptions and state announcements.
