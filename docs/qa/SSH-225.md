# QA Audit: SSH-225 — Home-Screen Dynamic Shortcuts, Quick Connect Launcher & Biometric-Gated IPC

## Epic
**SSH-187**: [EPIC] Power Features — SFTP, Mosh, Automation, Accessibility

## Scope of Implementation
- **Dynamic Launcher Shortcuts (`ShortcutManagerHelper.kt`):**
  - Implemented `ShortcutManagerHelper.updateProfileShortcuts` and `removeProfileShortcut` using `ShortcutManagerCompat`.
  - Configured profile nickname, host/user details, and branded protocol icon (`R.drawable.ic_shortcut_ssh`).
  - Strict limitation to a maximum of 4 dynamic shortcuts as recommended by Android OS guidelines.
  - Wired into `ConnectionItem.kt` trailing dropdown menu ("Add to Home Screen" action) and `ConnectionListScreen.kt` deletion flows.
- **Hardened Intent Receiver & Parameter Sanitization (`IntentSanitizer.kt`):**
  - Defined explicit intent action `ACTION_LAUNCH_PROFILE = "com.adamoutler.ssh.LAUNCH_PROFILE"` and extra `EXTRA_PROFILE_ID`.
  - Added `validateLaunchIntent`: validates `profileId` against alphanumeric regex (`^[a-zA-Z0-9_-]{1,64}$`) and verifies the profile exists in secure internal storage.
  - **Zero External Command Injection:** Explicitly sanitizes and rejects hostile external intent extras (e.g. `command`, `host`, `port`, `password`). External callers cannot bypass credentials or supply ad-hoc command strings.
- **Biometric App Lock Gate Invariant:**
  - If `AppLockManager.isLocked.value == true`, any incoming shortcut intent is buffered in `AppLockManager.pendingResumeIntent`.
  - The connection is strictly prevented from opening or accessing Keystore credentials until user biometric/PIN verification succeeds.
