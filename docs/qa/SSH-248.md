## 1. Feature & Security Architecture Overview
SSH-248 implements essential runtime protocol wiring and cryptographic defenses across key operational boundaries:

1. **Live Intent Pipeline Wiring (`IntentSanitizer.kt` & `AppNavigation.kt`)**:
   - `IntentSanitizer` integrates support for `AutomationIntentGuard.ACTION_EXECUTE_AUTOMATION`.
   - Method signatures provide backwards-compatible optional `automationIntentGuard: AutomationIntentGuard? = null` parameters.
   - For `ACTION_EXECUTE_AUTOMATION`:
     - If `automationIntentGuard == null`, strictly rejected (`null`).
     - Invokes `automationIntentGuard.validateIntent(intent)`:
       - On `AutomationValidationResult.Authenticated`: validates profile existence against the supplied lookup predicate and enforces strict identifier format bounds (`^[a-zA-Z0-9_-]{1,64}$`), returning a sanitized route.
       - On `AutomationValidationResult.Rejected`: rejects navigation and logs rejection reason.
   - In `AppNavigation.kt`, remembers `AutomationIntentGuard` backed by `SecurityStorageManager` and `SecurityAuditLogManager` and supplies it to `sanitizeAndNavigate`.

2. **DNSSEC SSHFP Verification & SHA-256 Hardening (`SshfpVerifier.kt` & `SshConnectionManager.kt`)**:
   - Replaced SHA-1 matching in `SshfpVerifier.kt`: legacy `FPTYPE_SHA1` (1) records are strictly ignored/rejected during verification; only `FPTYPE_SHA256` (2) records are accepted to eliminate SHA-1 collision vulnerabilities.
   - Added `SshfpVerificationResult` sealed interface (`Verified`, `FingerprintMismatchAlert`, `NoRecordsFound`, `DnssecNotAuthenticated`, `NetworkError`).
   - Added DoH resolution helper `verifyHostKey(hostname, algorithm, keyEncoded)`.
   - In `TofuHostKeyVerifier` (`SshConnectionManager.kt`), added optional `sshfpVerifier: SshfpVerifier? = null` parameter.
   - When encountering an unknown host key (`status == HostKeyStatus.UNKNOWN`):
     - On `SshfpVerificationResult.Verified`: auto-accepts, saves to `known_hosts` via `KnownHostsManager.saveHostKey`, records in ephemeral registry, logs audit event, and returns `true` without user prompt.
     - On `SshfpVerificationResult.FingerprintMismatchAlert`: logs rejection to `auditLogManager` and returns `false` immediately.
     - On `NoRecordsFound`, `DnssecNotAuthenticated`, or `NetworkError`: falls through cleanly to standard interactive TOFU prompt.

3. **UTF-8 Multi-Byte Password Byte Decoding (`PasswordAuthenticator.kt`)**:
   - Replaced raw integer cast byte-to-char conversion with `decodeUtf8BytesToChars(bytes: ByteArray): CharArray` using `StandardCharsets.UTF_8.newDecoder()`, `ByteBuffer.wrap(bytes)`, and `CharBuffer`.
   - Intermediate `CharBuffer` backing array is sanitized via `charBuffer.array().fill('\u0000')` inside a `finally` block.
   - Preserves multi-byte international and symbol characters (e.g. `"pässwörd🔒€"`).

4. **Purge of Legacy `-cbc` Ciphers from SSH Transport (`SecureSshConfig.kt`)**:
   - `SecureSshConfig.init` filters out any cipher factory containing `"cbc"` in addition to `"3des"` and `"blowfish"`.
   - Eliminates padding oracle and plaintext recovery attacks on hostile wires while preserving modern AEAD and CTR ciphers (`aes128-ctr`, `aes256-ctr`, `aes128-gcm@openssh.com`, `aes256-gcm@openssh.com`).
