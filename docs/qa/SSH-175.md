# SSH-175: Implement Dynamic Port Forwarding (SOCKS Proxy)

## Overview & Architecture
Dynamic Port Forwarding (SOCKS5 Proxy) allows users to route arbitrary network traffic through the encrypted SSH tunnel. 

### Implementation Details:
1. **Data Model**: `PortForwardType` enum in `app/src/main/kotlin/com/adamoutler/ssh/data/ConnectionProfile.kt` extended with `@SerialName("DYNAMIC") DYNAMIC`.
2. **SOCKS5 Engine**: `PortForwardingOrchestrator.kt` binds a local `ServerSocket` and handles RFC 1928 SOCKS5 handshakes (method `0x00` NO AUTH, command `0x01` CONNECT, address types IPv4 `0x01`, Domain `0x03`, IPv6 `0x04`) and pipes traffic bidirectionally through SSHJ direct-tcpip channels.
3. **UI & Accessibility**:
   - `AddEditProfileScreen.kt` includes a 3-way segmented control (`Local`, `Remote`, `Dynamic`).
   - Dynamic selection hides `Remote Host` and `Remote Port` input fields via `AnimatedVisibility`.
   - Displays an explicit high-contrast warning card: `⚠️ Warning: This turns your device into a proxy. Ensure the port is not exposed to untrusted networks.`
   - TalkBack accessibility announcement via `liveRegion = LiveRegionMode.Polite` on dynamic mode description text.
