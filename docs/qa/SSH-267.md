## 1. Feature Overview
SSH-267 exposes global terminal cursor controls allowing users to customize cursor style and cursor blinking behavior across all active terminal sessions:
1. **Settings Persistence**:
   - `SettingsManager.globalCursorStyle` ("BLOCK", "UNDERLINE", "VERTICAL_BAR")
   - `SettingsManager.cursorStyle` (`TerminalCursorStyle` enum accessor)
   - `SettingsManager.globalCursorBlink` (`Boolean`)
2. **ViewModel & UI Reactive Binding**:
   - `SettingsViewModel.updateCursorStyle(TerminalCursorStyle)`
   - `SettingsViewModel.updateCursorBlink(Boolean)`
   - `SettingsUiState.globalCursorStyle` and `SettingsUiState.globalCursorBlink`
3. **Terminal Engine & Session Binding**:
   - `TerminalScreen.kt` collects `cursorStyleFlow` and `cursorBlinkFlow` from `TerminalViewModel`.
   - Sends Termux blinker updates (`terminalViewRef?.setTerminalCursorBlinkerState(cursorBlink, true)`).
   - Transmits standard DECSCUSR ANSI emulator escape sequences (`\u001B[1 q` to `\u001B[6 q`) into `session.emulator`.
