## 1. User Story

*As a paranoiac Android security architect, I want release builds to be protected against runtime reflection breakage under R8 obfuscation, obsolete client dependencies pruned, cloud sync enabled in release artifacts, lint checks hardened against insecure trust managers, test runner concurrency constrained to prevent flaky JVM cold boots, and Detekt static analysis enforced in CI pipelines, so that production releases maintain cryptographic integrity, deterministic verification, and attack-resistant binary hygiene.*

## 2. Implementation Summary

1. **R8 / ProGuard Hardening (`app/proguard-rules.pro`):**
   - Preserved SSH network protocols and reflection:
     - `-keep class net.schmizz.sshj.** { *; }`
     - `-dontwarn net.schmizz.sshj.**`
   - Preserved cryptographic primitives:
     - `-keep class com.google.crypto.tink.** { *; }`
     - `-dontwarn com.google.crypto.tink.**`
   - Preserved terminal emulation JNI and UI bindings:
     - `-keep class com.termux.terminal.** { *; }`
     - `-keep class com.termux.view.** { *; }`
   - Preserved WorkManager background sync reflection:
     - `-keep class com.adamoutler.ssh.sync.SyncWorker { *; }`
   - Preserved Kotlinx Serialization across all application modules:
     - `-keep @kotlinx.serialization.Serializable class * { *; }`
     - `-keepclassmembers class * { @kotlinx.serialization.Serializable <fields>; }`
     - Domain explicit keep rules for `com.adamoutler.ssh.security.**`, `com.adamoutler.ssh.network.**`, `com.adamoutler.ssh.ui.**`, `com.adamoutler.ssh.data.**`, and `com.adamoutler.ssh.backup.**`.

2. **Release Build Hygiene & Dependency Pruning (`app/build.gradle.kts`, `gradle/libs.versions.toml`):**
   - Pruned obsolete, unused Google Drive dependencies from `app/build.gradle.kts`:
     - `libs.google.api.services.drive`
     - `libs.google.api.client.android`
     - `libs.google.auth.library.oauth2.http`
   - Pruned corresponding unused versions and library entries from `gradle/libs.versions.toml`:
     - `googleApiServicesDrive`, `googleApiClientAndroid`, `googleAuthLibraryOauth2Http`
     - `google-api-services-drive`, `google-api-client-android`, `google-auth-library-oauth2-http`
   - Updated `buildTypes.release` to set `buildConfigField("boolean", "ENABLE_CLOUD_SYNC", "true")`.
   - Hardened `android.lint.disable` by removing `"TrustAllX509TrustManager"` to prevent blind SSL/TLS certificate acceptance vulnerabilities.

3. **Test Runner Concurrency Alignment (`app/build.gradle.kts`):**
   - Aligned test runner settings with `AGENTS.md` Rule 7:
     - `testOptions.unitTests.all`: `it.maxParallelForks = 1` and `it.forkEvery = 25`.
     - `tasks.withType<Test>`: `maxParallelForks = 1` and `forkEvery = 25`, keeping `maxHeapSize = "3072m"`.
   - Prevents Robolectric concurrent `MavenArtifactFetcher` collision lockups and JVM paging thrash under QEMU emulation.

4. **Detekt CI Integration (`.forgejo/workflows/ci.yml`, `.github/workflows/ci.yml`):**
   - Added `./gradlew detekt` execution in Forgejo CI workflow (`Run Tests and Coverage` and dedicated `Run Detekt Static Analysis` step).
   - Added `./gradlew detekt` execution in GitHub CI workflow (`Run Tests and Coverage` and dedicated `Run Detekt Static Analysis` step).
