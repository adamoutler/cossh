## Ticket: SSH-208 - Implement Auto-Reconnect on Network Change with Circuit Breakers & TOFU Guard
* **User Story:** [SSH-208](file:///home/adamoutler/git/ssh/user_stories/SSH-208.md)

### 1. Architectural & Logic Implementation
* **Exponential Backoff Reconnect Loop (`SshService.kt`):**
  - Manages background connection retry attempts up to `profile.maxReconnectAttempts` (default 5).
  - Calculates exponential backoff: $2\text{s} \times 2^{\text{attempt}-1}$ capped at 60s.
  - Updates foreground service notification and reactive connection state `ConnectionState.Reconnecting(attempt, maxAttempts, message)`.
  - Emits inline ANSI status warning to active terminal transcript when connection drops, and green restored notice when recovered.
* **Immediate Circuit Breakers:**
  - `UserAuthException` / authentication errors immediately terminate reconnect loop with `ConnectionState.Error` to prevent account lockout.
  - Manual disconnect (`ConnectionState.Disconnecting` / cancellation) cleanly aborts without retrying.
* **Zero-Prompt TOFU Guard (`SshConnectionManager.kt` & `TofuHostKeyVerifier.kt`):**
  - Flags autonomous background reconnections (`isAutonomousReconnect = true`).
  - Rejects unknown or changed host keys immediately with `HOST_KEY_MISMATCH_SECURITY_ALERT` / `ConnectionState.Terminated`, never prompting in the background.
* **Terminal Status UI (`TerminalReconnectBanner.kt` & `TerminalScreen.kt`):**
  - Pinned non-modal top status banner displaying progress, reconnect attempt count, animated progress bar, and "Cancel" action button.
  - Full TalkBack accessibility support via `LiveRegionMode.Polite`.
