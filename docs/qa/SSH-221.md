# QA Audit: SSH-221 — Multi-Session Tab Strip, Flicker-Free Hot-Swap Switching, and Zero-Retention Session Teardown

## Epic
**SSH-186**: [EPIC] Terminal Experience

## Scope of Implementation
- **Dedicated Per-Session Streams & State Keying:**
  - `SessionStreamRegistry.kt`: Dedicated per-session flows via `getSessionOutputFlow(sessionId): SharedFlow<ByteArray>` preventing buffer contention and bleed between concurrent sessions. Concurrent linked queue byte isolation and atomic draining.
  - `ConnectionStateRepository.kt`: Per-session state tracking (`sessionStates`, `updateSessionState`, `clearSessionState`) eliminating collisions between concurrent sessions of the same profile.
  - `SshService.kt`: Fully synchronizes `updateSessionState(sessionId, state)` and `clearSessionState(sessionId)` across all connecting, connected, reconnecting, error, and disconnecting lifecycle transitions.
- **Material 3 Horizontal Tab Bar (`TerminalSessionTabBar.kt`):**
  - Horizontal `ScrollableTabRow` (38dp height) displaying when `sessions.size > 1` (auto-collapses when $\le 1$).
  - Tab items: protocol badge (Cobalt Terminal for SSH, Amber Warning for Telnet), host/profile nickname, live connection status dot (Green connected, Amber connecting/reconnecting, Red error), and close button (`x`).
  - Trailing "+ Connect" button triggering new session launch.
- **Flicker-Free Hot-Swap Switching (`TerminalScreen.kt`):**
  - Retains a persistent `TerminalView` instance, hot-swapping via `terminalView.attachSession(session)` both within `AndroidView.update` and `LaunchedEffect(session, terminalViewRef)`.
  - Replays buffered background bytes atomically on attach and dispatches `terminalView.onScreenUpdated()`.
  - Subscribes directly to `getSessionOutputFlow(sessionId)` for isolated output delivery.
- **Zero-Retention Session Teardown (`TerminalViewModel.kt` & `ActiveSessionState`):**
  - Tab closure in `TerminalScreen.kt` calls `terminalViewModel.closeSession(closedSessionId)`, finishing the session and invoking `onSessionFinished(session)` which explicitly zero-wipes `mLines` character arrays via reflection.
  - Complete buffer draining and `fill(0)` zero-wiping on teardown in `ActiveSessionState.sanitize()`.
  - Service sends `ACTION_DISCONNECT` with `sessionId` and clears session tracking atomically.
