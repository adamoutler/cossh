# Verification Proof for SSH-193: Implement Bounded Pinch-to-Zoom Terminal Font Scaling (8sp–32sp)

## Overview
Implemented bounded pinch-to-zoom font scaling for the CoSSH terminal interface, allowing users to dynamically scale font size between 8sp and 32sp using two-finger pinch gestures on the terminal display.

## Key Changes
1. **TerminalScaleHandler Component:**
   - Created `app/src/main/kotlin/com/adamoutler/ssh/ui/components/TerminalScaleHandler.kt`.
   - Bounds: `MIN_FONT_SIZE_SP = 8`, `MAX_FONT_SIZE_SP = 32`.
   - Gesture thresholding: Zoom-in trigger at `scale > 1.1f`, zoom-out trigger at `scale < 0.9f`, with intermediate accumulation returning raw `scale` and threshold trigger returning `1.0f` to reset gesture state.
   - `clampFontSize(sizeSp: Int): Int = sizeSp.coerceIn(8, 32)`.
2. **TerminalViewModel Bound Enforcement:**
   - `updateFontSize(newSize: Int)` uses `TerminalScaleHandler.clampFontSize(newSize)` to enforce the 8sp–32sp boundary.
3. **TerminalScreen Density Alignment & Delegation:**
   - In `AndroidView` `factory`, initial text size is aligned with `update`: `terminalView.setTextSize((currentFontSize * density.density * density.fontScale).toInt())`.
   - `TerminalViewClient.onScale(scale: Float)` delegates directly to `TerminalScaleHandler.onScale(scale, currentFontSizeState.value, onUpdateFontSizeState.value)`.
   - Headless test fallback renders with `fontSize = currentFontSize.sp`.
