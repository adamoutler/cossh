## 1. Feature Overview
SSH-268 implements end-to-end wiring of customizable terminal UX preferences:
1. **Volume Keys Behavior (`TerminalVolumeKeysAction`)**:
   - `SYSTEM_VOLUME`: Passes through hardware volume keys to the OS for system media/volume adjustment.
   - `ZOOM_FONT`: Intercepts `KEYCODE_VOLUME_UP` and `KEYCODE_VOLUME_DOWN` to scale terminal font size.
2. **Pinch-to-Zoom Control**:
   - Gated via `isPinchToZoomEnabled`. Returns `1.0f` when disabled to freeze canvas zoom against accidental touches.
3. **Terminal Bell Haptics**:
   - `isTerminalBellHapticEnabled` controls tactile feedback when bell events are received.
4. **Configurable Back Button Behavior (`TerminalBackButtonBehavior`)**:
   - `SEND_ESC`: Maps back key to raw ANSI `0x1B` byte in `BackHandler` and `shouldBackButtonBeMappedToEscape()`.
   - `BACKGROUND_SESSION`: Instantly backgrounds active session without displaying confirmation dialog.
   - `PROMPT_DIALOG`: Maintains double-tap or keep-alive exit prompt.
5. **Direct Character Input Enforcement**:
   - `enforceCharBasedInput` mapped to `TerminalViewClient.shouldEnforceCharBasedInput()`.
6. **Hardware Pocket Detection Optimization**:
   - `rememberProximitySensorState(enabled = ...)` skips registering hardware proximity listeners when pocket detection is disabled.
7. **URL Confirmation Defense Modes (`TerminalUrlConfirmationMode`)**:
   - `ALWAYS`, `SUSPICIOUS_ONLY`, and `NEVER` options controlling URL confirmation sheet vs direct browser launching.
