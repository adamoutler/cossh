# QA Verification Proof for SSH-210

## Ticket: SSH-210 - Implement Hardened Ephemeral Quick Connect with Zero-Retention Memory Sanitization & Session TOFU
* **User Story:** [SSH-210](file:///home/adamoutler/git/ssh/user_stories/SSH-210.md)

### 1. Architectural & Logic Implementation
* **Hardened URI / Target Address Parser (`QuickConnectParser.kt`):**
  - Parses `[user@]host[:port]` syntax with comprehensive protocol awareness (SSH: 22, Telnet: 23).
  - Handles IPv6 literal addresses bracketed with port (`[2001:db8::1]:2222`).
  - Rejects shell injection metacharacters (`;`, `&`, `|`, `$`, `` ` ``, `<`, `>`, `\n`, `\r`) and whitespaces to prevent terminal injection.
  - Validates port numbers strictly within `1..65535`.
* **Zero-Retention Ephemeral Storage (`EphemeralProfileStore.kt` & `SecurityStorageManager.kt`):**
  - `ConnectionProfile.kt` includes `val isEphemeral: Boolean = false`.
  - `SecurityStorageManager.saveProfile()` explicitly rejects ephemeral profiles with `IllegalArgumentException` to ensure sensitive credentials never touch Room or Android Keystore on disk.
  - Ephemeral profiles are held exclusively in volatile memory via `EphemeralProfileStore`.
  - Password and sensitive credentials are encrypted in-memory and sanitized via zeroing upon session termination.
* **Session-Isolated TOFU Host Key Verification (`EphemeralHostKeyRegistry.kt`):**
  - In-memory host key cache prevents MITM during the active session without persisting ephemeral host keys to `ssh_known_hosts`.
* **Material 3 Quick Connect UI (`QuickConnectBottomSheet.kt`):**
  - Material 3 bottom sheet accessible from the connection list top bar bolt action.
  - Supports dual action modes: "Connect" (ephemeral in-memory execution) and "Save & Connect" (permanent encrypted persistence).
  - Accessibility semantics: TalkBack content descriptions and assertive live region error announcements.
