# QA Report: SSH-214 - Passphrase-Protected Key Decryption & ECDSA Key Parity

## Overview
Ticket: **SSH-214**
Objective: Implement Passphrase-Protected Key Decryption (OpenSSH bcrypt-pbkdf, PKCS#8) & ECDSA Key Parity with strict memory sanitization.

## Code Citations & Implementation Verification
1. **Passphrase Decryption Engine (`PemUtils.kt`)**:
   - `isKeyEncrypted()` and `detectKeyEncryptionSummary()` inspect file headers and OpenSSH v1 magic bytes (`openssh-key-v1`) to detect `bcrypt-pbkdf`, AES/ChaCha20, PKCS#8, and legacy OpenSSL encrypted PEMs.
   - `parsePemToKeyPair()` accepts an optional `passphrase: CharArray` and routes encrypted payloads to `parseEncryptedOpenSshKey` (via SSHJ `OpenSSHKeyFile` with SAM-safe `PasswordFinder`) or BouncyCastle `JcePKCSPBEInputDecryptorProviderBuilder`.
   - Derives matching `PublicKey` automatically for `Ed25519`, `RSA`, and `ECDSA` (`secp256r1`, `secp384r1`, `secp521r1`).
   - Volatile passphrase buffers are zero-wiped (`passphrase.fill('\u0000')`) in `finally` blocks.
2. **ECDSA Cryptographic Parity (`SSHKeyGenerator.kt`)**:
   - `generateECDSAKeyPair(curveName)` generates standard NIST P-256, P-384, and P-521 keys.
   - `encodePublicKey()` encodes EC keys using `Buffer.putPublicKey()` to generate valid OpenSSH wire format strings (`ecdsa-sha2-nistp256`, `ecdsa-sha2-nistp384`, `ecdsa-sha2-nistp521`).
3. **Interactive Modal (`EncryptedKeyPassphraseModal.kt`)**:
   - Implements Material 3 dialog with `FLAG_SECURE` window protection.
   - Employs `SecurePasswordEditText` with `IME_FLAG_NO_PERSONALIZED_LEARNING`.
   - Displays format summary chip and assertive TalkBack error accessibility.
