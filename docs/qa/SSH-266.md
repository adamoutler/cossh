# Verification Proof for SSH-266: Per-Profile Legacy SSH Crypto Compat Mode, Profile Styling Preservation & Confirmation Friction Modes

## Summary of Changes
1. **Per-Profile Legacy SSH Crypto Compatibility Mode (`ConnectionProfile.kt` & `SecureSshConfig.kt`):**
   - Added `allowLegacyAlgorithms: Boolean = false` to `ConnectionProfile` (updating `equals()` and `hashCode()`).
   - Updated `SecureSshConfig(val allowLegacyAlgorithms: Boolean = false) : AndroidConfig()`:
     - When `allowLegacyAlgorithms == false` (default): Strictly purges weak KEX (`sha1`, `group1-`), weak ciphers (`3des`, `blowfish`, `cbc`), and weak MACs (`sha1`, `md5`) while prioritizing post-quantum hybrid KEX `Sntrup761X25519KeyExchange.Factory()` at index 0.
     - When `allowLegacyAlgorithms == true`: Retains standard `AndroidConfig` legacy algorithms (SHA-1, CBC, 3DES, MD5) for connecting to legacy networking equipment while prioritizing `Sntrup761X25519KeyExchange.Factory()` at index 0 without duplicates.
   - Updated `SshConnectionHandler.kt` and `SshConnectionManager.kt` to initialize `SecureSshConfig(allowLegacyAlgorithms = profile.allowLegacyAlgorithms)` (and `jumpProfile.allowLegacyAlgorithms`).

2. **Per-Profile Styling Reset Bug Fix (`AddEditProfileViewModel.kt`):**
   - Added `fontSize: Int? = null`, `colorTheme: String? = null`, `fontChoice: String? = null`, `cursorStyle: String? = null`, `cursorBlink: Boolean? = null`, and `allowLegacyAlgorithms: Boolean = false` to `ProfileFormState`.
   - Populated these attributes in `loadProfileIfNeeded(profileId)`.
   - Preserved all styling and crypto flags in `saveProfileFromState(id)` and `saveProfile(...)`.

3. **Legacy SSH Crypto Switch (`AddEditProfileScreen.kt`):**
   - Added `"Allow Legacy SSH Algorithms (SHA-1, CBC, 3DES)"` toggle with testTag `"AllowLegacyAlgorithmsSwitch"` under Advanced Configuration when protocol is SSH.

4. **Host Key Change Confirmation Friction (`AppNavigation.kt`):**
   - In `HostKeyPromptDialog`, checked `SettingsManager(LocalContext.current).isHoldToConfirmHostKeyEnabled`.
   - When `request.isKeyChanged && isHoldToConfirmHostKeyEnabled`: Renders `HoldToConfirmButton` (2.5s hold).
   - When `request.isKeyChanged && !isHoldToConfirmHostKeyEnabled`: Renders standard error-styled button `"Overwrite Host Key"`.

5. **Terminal URL Confirmation Modes (`TerminalScreen.kt`):**
   - Integrated `SettingsManager(context).terminalUrlConfirmationMode` (`ALWAYS`, `NEVER`, `SUSPICIOUS_ONLY`) into URL tap and long-press handlers in `TerminalScreen.kt`.
