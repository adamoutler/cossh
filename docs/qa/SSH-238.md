# QA Audit: SSH-238 — OpenSSH known_hosts Bulk Porter (Import/Export & Conflict Detection)

## Epic
**SSH-188**: [EPIC] Security Differentiators — "Most Secure SSH Client on Android"

## Scope of Implementation
1. **Hardened Resource Bounds & Input Sanitization (`KnownHostsBulkPorter.kt`):**
   - Enforced `MAX_PAYLOAD_BYTES = 1024 * 1024` (1 MB) across `String` and `InputStream` boundaries to neutralize memory exhaustion / DoS attacks.
   - Enforced `MAX_ENTRY_COUNT = 2000` entries per payload.
   - Enforced `MAX_LINE_LENGTH = 8192` characters.
   - Strictly rejected lines containing forbidden control characters (`\r`, `\n`, `\u0000`, `\u001B`, `\u007F`).
   - Implemented comment sanitization stripping unprintable control sequences and escape characters.
2. **OpenSSH Wire-Format Public Key Validation:**
   - Implemented `validatePublicKeyBlob(keyType: String, base64Blob: String): Boolean`:
     - Validates Base64 decoding.
     - Parses uint32 big-endian wire length prefix.
     - Verifies key type string matches `keyType`.
     - Validates presence of key material beyond the type header.
3. **Marker & Line Parsing:**
   - Extended `KnownHostRecord` in `KnownHostsManager.kt` with `val isRevoked: Boolean = false`.
   - Updated `parseLine` to parse `@revoked` entries and mark `isRevoked = true`.
   - Fully supports standard plaintext `hostname[,ip]`, bracketed `[host]:port`, hashed `|1|salt|hash`, `@cert-authority`, and `@revoked` entries.
4. **Conflict Detection & Merge Strategies:**
   - Detects key conflicts across both plaintext and HMAC-SHA1 hashed entries using `manager.matchesHost(...)`.
   - `STRICT_REJECT_CONFLICTS`: Aborts import (`isSuccess = false`) leaving `manager` completely untouched if any incoming key differs from an existing key for the host, returning full conflict details.
   - `SKIP_EXISTING`: Retains existing host keys, skipping conflicting entries, while importing new entries.
   - `OVERWRITE_CHANGED`: Overwrites conflicting keys in-place, preserving file comments.
5. **OpenSSH Export:**
   - Implemented `exportToOpenSshFormat` (string and `OutputStream` overloads) preserving `@cert-authority`, `@revoked`, host patterns, key types, Base64 blobs, and sanitized comments.
