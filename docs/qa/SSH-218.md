# QA Audit: SSH-218 — Hardened Terminal URL Detection, Strict URI Sanitization, and Secure Confirmation Modal

## Epic
**SSH-186**: [EPIC] Terminal Experience

## Scope of Implementation
- **Sanitizer Engine (`app/src/main/kotlin/com/adamoutler/ssh/util/TerminalUrlSanitizer.kt`):**
  - Bounded candidate regex enforcing maximum length 2048 characters to eliminate ReDoS.
  - Unicode Bidi control character stripping (`\u202A`–`\u202E`, `\u2066`–`\u2069`, ASCII controls) to neutralize Trojan Source and visual spoofing.
  - Dual RFC parser validation (`android.net.Uri.parse` and `java.net.URI` agreement) strictly pinning scheme to `http` or `https`.
  - Complete rejection of non-HTTP schemes (`file:`, `content:`, `intent:`, `javascript:`, `data:`, `about:`, `market:`).
  - Authority injection and userinfo spoofing rejection (`@`).
  - IDN Punycode domain detection (`xn--`) and Unicode homoglyph flagging.
  - Trailing terminal transcript punctuation stripping (`)`, `]`, `}`, `.`, `,`, `;`, `:`, `'`, `"`).
- **Confirmation Modal (`app/src/main/kotlin/com/adamoutler/ssh/ui/components/UrlConfirmationBottomSheet.kt`):**
  - Material 3 bottom sheet enforcing `WindowManager.LayoutParams.FLAG_SECURE` on containing window during display.
  - Registered host highlighted in high-contrast bold typography with path and parameters demoted to prevent visual deception.
  - Security alert cards for insecure cleartext HTTP, raw IP addresses (no cert parity), and IDN Punycode homograph domains.
  - Dual actions: "Copy Link" via `SecureClipboardManager` (30s auto-clear) and "Open Link".
- **Terminal View Client Integration (`app/src/main/kotlin/com/adamoutler/ssh/ui/components/TerminalScreen.kt`):**
  - Integrated into `TerminalViewClient.onSingleTapUp` and `TerminalViewClient.onLongPress`.
  - Coordinates mapped via `TerminalView.getColumnAndRow(e, true)` and `session.emulator.screen.getWordAtLocation`.
  - Browsable intent dispatched safely via chooser with error handling.
