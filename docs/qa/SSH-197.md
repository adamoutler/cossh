# Verification Proof for SSH-197: Implement Terminal Color Themes, Monospace Font Selection, and Paparazzi Snapshots

## Overview
Implemented terminal color themes (`COBALT_BLUE`, `SOLARIZED_DARK`, `MONOKAI`, `DRACULA`), monospace font selection (`DEFAULT_MONOSPACE`, `JETBRAINS_MONO`, `FIRA_CODE`, `INCONSOLATA`, `SOURCE_CODE_PRO`), user preferences in `SettingsManager` and `ConnectionProfile`, live terminal rendering in `TerminalScreen`, and interactive `TerminalPreviewCard` in `SettingsScreen`.

## Key Changes
1. **Curated Color Palettes (`TerminalTheme.kt`):**
   - Implemented `COBALT_BLUE` (default CoSSH cobalt aesthetic), `SOLARIZED_DARK`, `MONOKAI`, and `DRACULA`.
   - Each theme defines a 16-color ANSI palette (`ansiColors: IntArray`), default `foreground`, `background`, and `cursor` colors.
   - `applyTo(terminalView, session)` sets `terminalView.setBackgroundColor(background)`, updates `emulator.mColors.mCurrentColors` (indices 0..15 ANSI, 256 foreground, 257 background, 258 cursor), and invokes `terminalView.onScreenUpdated()`.
2. **Monospace Font Engine (`TerminalFontChoice.kt`):**
   - Curated options: `DEFAULT_MONOSPACE`, `JETBRAINS_MONO`, `FIRA_CODE`, `INCONSOLATA`, `SOURCE_CODE_PRO`.
   - `getTypeface()` creates font with safe fallback to `Typeface.MONOSPACE`.
   - `composeFontFamily` provides Compose `FontFamily` for headless preview.
3. **Preferences & Profile Integration:**
   - `SettingsManager`: Added `globalColorTheme` (defaults to `"COBALT_BLUE"`) and `globalFontChoice` (defaults to `"DEFAULT_MONOSPACE"`).
   - `ConnectionProfile`: Added optional per-host overrides `colorTheme: String? = null` and `fontChoice: String? = null` with updated `equals()` and `hashCode()`.
4. **Active Terminal Engine & Headless Rendering (`TerminalScreen.kt`):**
   - `TerminalScreen` collects `currentTheme` and `currentFont` flows from `TerminalViewModel`.
   - Resolves profile-level overrides with fallback to global settings.
   - Updates `AndroidView` `factory` and `update` blocks to apply font typeface and theme colors.
   - Updates headless test fallback (`isHeadlessTest = true`) to render with theme background, foreground color, and font family.
5. **Interactive Customization (`SettingsScreen.kt`):**
   - Added "Terminal Appearance" card with `ExposedDropdownMenuBox` selectors for theme and font.
   - Added `TerminalPreviewCard` rendering an authentic terminal command preview showing ANSI colors, prompt, output, and cursor.
