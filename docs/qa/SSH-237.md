## 1. Feature Overview
SSH-237 introduces high-productivity terminal input enhancements, accessibility live-region sanitization, and an in-depth architectural spike for Mosh (Mobile Shell) UDP state synchronization:
1. **Extra Keys Presets (`ExtraKeysPreset.kt`)**: Structured, swappable 2-row layouts for `DEFAULT`, `VIM_CODING`, `TMUX`, and `NAVIGATION`, featuring validation rules (`validateKeySpec`, `validatePreset`) and cryptographic JSON round-trip serialization (`serializePreset`, `deserializePreset`).
2. **Tmux Multiplexer Action Helper (`TmuxActionHelper.kt`)**: Maps terminal multiplexer commands (splits, window navigation, zoom, kill, pane selection) to prefix-encoded byte sequences with configurable prefix keys (`Ctrl-B` vs `Ctrl-A`).
3. **Terminal Accessibility Helper (`TerminalAccessibilityHelper.kt`)**: Filters ANSI CSI/OSC escape sequences, extracts clean visible lines for TalkBack screen readers, formats polite live-region announcements, and articulates modifier transitions (`Active: Off`, `Sticky`, `Locked`).
4. **Mosh Architectural Spike (`docs/architecture/mosh-spike.md`)**: Comprehensive technical evaluation covering State Synchronization Protocol (SSP), AES-128-OCB AEAD over UDP (ports 60000–61000), SSH bootstrap handshake, Android 15+ 16KB ELF page alignment (`-Wl,-z,max-page-size=16384`), CGNAT keepalive probes (20s), Doze mode mitigations, and a phased four-stage integration roadmap.

### 2.1 Core Implementation
- **`app/src/main/kotlin/com/adamoutler/ssh/ui/components/ExtraKeysPreset.kt`**:
  - `ExtraKeysPresetId`: `DEFAULT`, `VIM_CODING`, `TMUX`, `NAVIGATION`.
  - `ExtraKeySpec`: Serializable data model (`id`, `label`, `contentDescription`, `payload`, `isModifier`, `isRepeatable`).
  - `ExtraKeysPresets`: Preset registries, bounds checking (rejecting IDs > 64 chars, labels > 32 chars, payloads > 128 chars, non-modifier keys with empty payloads, duplicate IDs), and JSON serialization.
- **`app/src/main/kotlin/com/adamoutler/ssh/ui/components/TmuxActionHelper.kt`**:
  - `TmuxPrefix`: `CTRL_B` (0x02) and `CTRL_A` (0x01).
  - `TmuxCommand`: `SPLIT_HORIZONTAL`, `SPLIT_VERTICAL`, `PANE_UP`, `PANE_DOWN`, `PANE_LEFT`, `PANE_RIGHT`, `ZOOM_TOGGLE`, `NEW_WINDOW`, `NEXT_WINDOW`, `PREV_WINDOW`, `DETACH_SESSION`, `KILL_PANE`.
  - `buildCommandBytes` & `buildCommandPayload`: Prefix-aware byte and string constructors.
- **`app/src/main/kotlin/com/adamoutler/ssh/ui/components/TerminalAccessibilityHelper.kt`**:
  - `stripAnsiControlCodes`: Cleans ANSI escape sequences (CSI `\u001b[...]`, OSC `\u001b]...\u0007`, 2-char escapes, and non-printable control chars), normalizing `\r\n` and `\r` to `\n`.
  - `extractAccessibleLines`: Extracts up to `maxLines` of sanitized visible transcript lines.
  - `buildModifierAnnouncement`: Announces modifier latch states (`Active: Off`, `Sticky`, `Locked`).
  - `buildOutputAnnouncement`: Politeness-bounded live region text with ellipsis truncation.
- **`docs/architecture/mosh-spike.md`**:
  - 8-section architectural evaluation covering protocol theory, threat modeling, NDK 16KB alignment, battery/CGNAT survival, and phased implementation.
