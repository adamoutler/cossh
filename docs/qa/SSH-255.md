## 1. Feature & Hygiene Overview
SSH-255 prepares the CoSSH codebase for enterprise production release by purging test doubles from the production APK, replacing fallback mock adapters with a secure fail-fast disconnected guard, eliminating prototype dead code and developer scratch files, and ensuring clean headless builds:

1. **Disconnected SFTP Guard & Test Double Segregation (`DisconnectedSftpClientAdapter.kt` & `AppNavigation.kt`)**:
   - `DisconnectedSftpClientAdapter` implements `SftpClientAdapter` where every operation (`list`, `makeDirectory`, `remove`, `rename`, `setPermissions`, `openInputStream`, `openOutputStream`, `stat`, and `close`) immediately throws `IOException("SFTP client is not connected: active SSH session required")`.
   - In `AppNavigation.kt` (`sftpBrowser` route), replaced fallback instances of `FakeSftpClientAdapter()` with `DisconnectedSftpClientAdapter()`.
   - When users open the SFTP file browser without an active, authenticated SSH session, `SftpBrowserViewModel` catches the `IOException` and presents a clean error state with a retry option in `SftpBrowserScreen.kt`.
   - Segregated `FakeSftpClientAdapter.kt` by moving it from `app/src/main/kotlin/com/adamoutler/ssh/sftp/` to `app/src/test/kotlin/com/adamoutler/ssh/sftp/`, ensuring test doubles are 100% isolated within the test source set and never packaged into production APKs or AABs.

2. **Dead Code & Prototype Screen Purge**:
   - Removed obsolete `PlaceholderScreen()` composable from `app/src/main/kotlin/com/adamoutler/ssh/MainActivity.kt`.
   - Deleted `app/src/test/kotlin/com/adamoutler/ssh/PlaceholderScreenScreenshotTest.kt` along with its Paparazzi snapshot `app/src/test/snapshots/images/com.adamoutler.ssh_PlaceholderScreenScreenshotTest_defaultScreen.png`.
   - Deleted diagnostic scratch file `app/src/main/kotlin/com/adamoutler/ssh/ReflectionTest.kt`.
   - Purged dead prototype `app/src/main/kotlin/com/adamoutler/ssh/ui/keys/KeyManagementScreen.kt` (superseded by the modern Identity subsystem), removed its `"keyManagement"` route and unused import from `AppNavigation.kt`, and removed its navigation invocation from `AppNavigationCoverageTest.kt`.
   - Deleted `app/src/test/kotlin/com/adamoutler/ssh/ui/keys/KeyManagementScreenTest.kt`, `app/src/test/kotlin/com/adamoutler/ssh/ui/keys/KeyManagementScreenScreenshotTest.kt`, and their 2 Paparazzi snapshots (`app/src/test/snapshots/images/com.adamoutler.ssh.ui.keys_KeyManagementScreenScreenshotTest_defaultScreen.png` and `..._screenWithGeneratedKey.png`).

3. **Scratch Files Removal**:
   - Purged tracked root scratch files `build.gradle.kts.test` and `test.gradle.kts` from git tracking.
   - Confirmed absence of legacy temporary files (`methods_dump.txt`, `session_client_methods.txt`).
