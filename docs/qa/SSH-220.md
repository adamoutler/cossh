## Epic
**SSH-186**: [EPIC] Terminal Experience

## Scope of Implementation
- **Domain Model & Persistence:**
  - `app/src/main/kotlin/com/adamoutler/ssh/data/TerminalCursorStyle.kt`:
    - `BLOCK("BLOCK", 0, "Block")`
    - `UNDERLINE("UNDERLINE", 1, "Underline")`
    - `VERTICAL_BAR("BAR", 2, "Bar")`
  - Global settings in `SettingsManager.kt`: `globalCursorStyle` (default `BLOCK`) and `globalCursorBlink` (default `true`).
  - Per-profile overrides in `ConnectionProfile.kt`: `cursorStyle: String? = null` and `cursorBlink: Boolean? = null`.
- **ViewModel & Terminal Integration:**
  - `TerminalViewModel.kt`: `cursorStyleFlow`, `cursorBlinkFlow`, `initCursor`, `updateCursorStyle`, `updateCursorBlink`.
  - `TerminalScreen.kt`:
    - Termux blink rate synchronization via `terminalView.setTerminalCursorBlinkerState(cursorBlink, true)`.
    - Standard DECSCUSR ANSI escape sequence synchronization (`\e[1 q` through `\e[6 q`).
- **UI & Live Animated Preview:**
  - `TerminalCursorPreviewBox.kt`: authentic VT100 prompt with square-wave 1 Hz blink dynamics and exact geometry.
  - Integrated into `TerminalScreen` settings bottom sheet:
    - Material 3 `SingleChoiceSegmentedButtonRow` for shape selection.
    - Blinking cursor `Switch` toggle.
    - Real-time `TerminalCursorPreviewBox`.
