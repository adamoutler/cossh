# SSH-158 QA Proof and Evidence

## Ticket Requirement
As a user, if I attempt to connect to a profile that has no saved password (or a blank username), the terminal opens to a black screen and hangs instead of asking me for the missing credentials. I need the app to detect missing or failed authentication and provide an ephemeral prompt so I can manually enter my username and password to continue the connection.

## Implementation Details
1. **Intercept Missing Credentials:** Intercept connection attempts where `username` or `password` (if using password auth) are missing before or during the SSH handshake.
2. **Ephemeral UI State:** Emit `ConnectionState.RequiresCredentials` triggering the Compose `AuthPromptDialog` on `TerminalScreen`.
3. **Resumption without Persistence:** Once the user inputs ephemeral credentials, the SSH connection retries with injected credentials without persisting them to disk.
4. **Retry on Failure:** `PasswordAuthenticator.kt` loops with `UserAuthException` interception, reprompting on invalid credentials.
