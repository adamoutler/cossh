# QA Audit: SSH-219 — Hardware Keyboard VT100/xterm Key-Mapping Engine with Focus Loss Auto-Reset

## Epic
**SSH-186**: [EPIC] Terminal Experience

## Scope of Implementation
- **VT100 / xterm ANSI Key Engine (`app/src/main/kotlin/com/adamoutler/ssh/ui/components/TerminalAnsiKeyMapper.kt`):**
  - Standard xterm modifier formula: `1 + (Shift * 1) + (Alt * 2) + (Ctrl * 4)`.
  - Navigation keys mapped with modifier support: Up (`\e[1;{mod}A`), Down (`\e[1;{mod}B`), Right (`\e[1;{mod}C`), Left (`\e[1;{mod}D`), Home (`\e[1;{mod}H`), End (`\e[1;{mod}F`).
  - Tilde navigation keys: Insert (`\e[2;{mod}~`), Forward Delete (`\e[3;{mod}~`), Page Up (`\e[5;{mod}~`), Page Down (`\e[6;{mod}~`).
  - Function keys F1-F12:
    - Unmodified F1-F4 use SS3 encoding (`\eOP` through `\eOS`).
    - Modified F1-F4 use CSI encoding (`\e[1;{mod}P` through `\e[1;{mod}S`).
    - F5-F12 use standard CSI tilde encoding (`15~`, `17~`, `18~`, `19~`, `20~`, `21~`, `23~`, `24~`).
  - Dedicated Escape key (`0x1B`) and Backtab (`Shift+Tab` -> `\e[Z`).
  - Strict 16-byte bounds assertion on every generated sequence.
- **Hardware Modifier Bug Fix & Zero Allocation (`app/src/main/kotlin/com/adamoutler/ssh/ui/components/TerminalKeyMapper.kt`):**
  - Physical Alt inspection: `val altActive = getAltState().isActive || (e?.isAltPressed == true)`.
  - Alt chord handling: prefixes `0x1B` (ESC) to single-byte keystrokes (e.g. `Alt+B`, `Alt+F`, `Alt+.`).
  - Zero heap-string allocations on hot path: direct `ByteArray` assembly.
  - Physical Shift synchronization with `readShiftKey()`.
- **Focus Loss Auto-Reset (`TerminalKeyMapper.resetModifiers()` & `TerminalScreen.kt`):**
  - All hardware modifiers and virtual sticky states cleanly cleared on window focus loss and composable disposal.
