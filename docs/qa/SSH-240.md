# QA Verification: SSH-240 — Automation Guard, HMAC-SHA256 Token Authentication & Quick Connect AppWidget

## Epic
**SSH-187**: [EPIC] Power Features — SFTP, Mosh, Automation, Accessibility

## Feature Overview
SSH-240 delivers a hardened external automation boundary (`AutomationIntentGuard`) and a home-screen Quick Connect AppWidget (`CoSshAppWidgetProvider`).
External automation intents (`ACTION_EXECUTE_AUTOMATION`) are verified using constant-time HMAC-SHA256 signatures, bounded LRU nonce replay caching, strict timestamp freshness enforcement (+/- 60s), zero-credential extra filtering, and tamper-evident security audit logging. The home-screen Quick Connect widget provides one-tap connection launching via explicit immutable pending intents with strictly zero credentials or commands exposed in IPC extras.

## Implemented Components & Security Invariants

### 1. `NonceReplayCache.kt` (`com.adamoutler.ssh.security.automation`)
- **Bounded LRU Cache:** Thread-safe `LinkedHashMap` bounded to a maximum of 1,000 entries with automatic eldest-entry eviction.
- **Time-to-Live (TTL):** Enforces a 60,000ms TTL. Entries older than 60s are purged automatically.
- **Replay Protection:** Rejects any duplicate nonce received within the TTL window.

### 2. `AutomationIntentGuard.kt` (`com.adamoutler.ssh.security.automation`)
- **Action Verification:** Strictly requires `ACTION_EXECUTE_AUTOMATION = "com.adamoutler.ssh.ACTION_EXECUTE_AUTOMATION"`.
- **Zero Hostile Override Extras:** Explicitly scans for and rejects hostile intent extras (`command`, `cmd`, `exec`, `host`, `hostname`, `port`, `password`, `user`, `username`) across case variations.
- **Identifier Regex Whitelisting:**
  - `profileId` must match alphanumeric format `^[a-zA-Z0-9_-]{1,64}$`.
  - `nonce` must match alphanumeric format `^[a-zA-Z0-9_-]{1,128}$`.
- **Canonical Payload & Constant-Time HMAC:**
  - Canonical format: `$timestampMs|$nonce|$profileId|$action`.
  - Authenticated via HMAC-SHA256 using `securityStorageManager.getAutomationSecretKey()`.
  - Verified using constant-time `MessageDigest.isEqual` to prevent timing side-channel attacks.
- **Timestamp Freshness:** Rejects timestamps more than 60,000ms in the past (expired) or more than 60,000ms into the future (excessive drift).
- **Profile Storage Verification:** Requires `profileId` to exist in `SecurityStorageManager`.
- **Tamper-Evident Audit Logging:** Logs `AUTOMATION_INTENT_AUTHENTICATED` on success and `AUTOMATION_INTENT_REJECTED` on failure with reason to `SecurityAuditLogManager`.

### 3. `SecurityStorageManager.kt` (`com.adamoutler.ssh.crypto`)
- Added `getAutomationSecretKey()`, `generateOrGetAutomationSecretKey()`, and `rotateAutomationSecretKey()`.
- Secret key stored under `key_automation_secret` in hardware-backed `EncryptedSharedPreferences`.

### 4. `AuditRecord.kt` (`com.adamoutler.ssh.security.audit`)
- Added `AUTOMATION_INTENT_AUTHENTICATED` and `AUTOMATION_INTENT_REJECTED` to `AuditEventType`.

### 5. `CoSshAppWidgetProvider.kt` (`com.adamoutler.ssh.ui.widget`)
- Extends `AppWidgetProvider`.
- `createPendingIntent(context, appWidgetId, profileId)` constructs an explicit intent targeting `MainActivity::class.java` with `IntentSanitizer.ACTION_LAUNCH_PROFILE` and `IntentSanitizer.EXTRA_PROFILE_ID`.
- Enforces `PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE`.
- **Zero Credentials in Extras:** Passes strictly zero passwords, private keys, hostnames, or shell commands in widget extras.
- Layout: `app/src/main/res/layout/widget_quick_connect.xml` (RemoteViews container, icon, title, button).
- Metadata: `app/src/main/res/xml/appwidget_quick_connect_info.xml`.
- Registered receiver in `AndroidManifest.xml`.
