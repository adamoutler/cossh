# SSH-177 QA Proof: Fix Crash When Pasting Via Default Android Long-Press Context Menu

## User Story
**As an** Android SSH client user,  
**I need** to paste clipboard content directly via the default Android long-press context menu and action mode without crashes,  
**So that** I can seamlessly paste shell commands, scripts, and credentials into active terminal sessions without encountering `NetworkOnMainThreadException` or thread death under StrictMode.

| Acceptance Criteria | Implementation Status | Evidence / Verification |

## Implementation Details

### 1. `TerminalViewModel.kt`
```kotlin
override fun onPasteTextFromClipboard(session: TerminalSession) {
    val context = getContext?.invoke() ?: return
    val clipboard = context.getSystemService(Context.CLIPBOARD_SERVICE) as? android.content.ClipboardManager ?: return
    val clipData = clipboard.primaryClip ?: return
    if (clipData.itemCount <= 0) return

    val item = clipData.getItemAt(0) ?: return
    val rawText = try {
        item.coerceToText(context)?.toString()
    } catch (e: Exception) {
        null
    }
    if (rawText.isNullOrEmpty()) return

    val sanitizedText = rawText.replace("\r\n", "\r").replace("\n", "\r")
    val sessionId = sessions.entries.firstOrNull { it.value == session }?.key ?: return

    viewModelScope.launch(kotlinx.coroutines.Dispatchers.IO) {
        val activeSession = com.adamoutler.ssh.network.ConnectionStateRepository.sessions[sessionId] ?: return@launch
        val ptyOutputStream = activeSession.ptyOutputStream ?: return@launch
        try {
            synchronized(ptyOutputStream) {
                ptyOutputStream.write(sanitizedText.toByteArray(Charsets.UTF_8))
                ptyOutputStream.flush()
            }
        } catch (e: Exception) {
            println("TerminalViewModel: Failed to paste text: $e")
        }
    }
}
```

### 2. `TerminalScreen.kt`
- Added synchronization on `ptyOutputStream` within the `writeChannel` reader loop to ensure thread safety against background paste operations.
- Intercepted `android.R.id.paste` and `android.R.id.pasteAsPlainText` inside `ActionMode.Callback2.onActionItemClicked`.
- Restored terminal focus (`terminalView.requestFocus()`) across all paste paths and within `onDestroyActionMode`.
- Configured `setOnCreateContextMenuListener` on `terminalView` for devices triggering standard context menus on long-press.
