# SSH-157: Back navigation from reorder mode should exit reorder mode

## User Story
As a user managing my connections, when I am in "reorder mode" and I press the system back button (or swipe back), I expect the app to exit reorder mode and return to the normal connection list, rather than navigating away from the screen or exiting the app.

## Fix Implementation
Added a `BackHandler(enabled = isReordering) { isReordering = false }` inside `ConnectionListContent.kt`. This intercepts the system back press when in reorder mode, gracefully turning off reorder mode and returning the UI to the normal view without disrupting navigation.

## Verification Proof
A UI test was written in `ConnectionListScreenTest.kt` named `testBackNavigationExitsReorderMode`. 

The test explicitly sets the UI to reorder mode, verifies that the "Add Connection" floating action button is missing (since it hides during reorder), triggers the system back dispatcher, and finally asserts that the "Add Connection" button is visible again, proving the UI returned to normal state.
