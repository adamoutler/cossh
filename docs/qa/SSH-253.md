## 1. User Story

*As a security-conscious systems administrator and CoSSH user, I want CoSSH to rigorously validate execution environments, sanitize environment variables and directory paths, enforce biometric gating on critical command snippets, validate OpenSSH host certificates against Certificate Authorities, prevent known_hosts MITM poisoning, verify DNSSEC SSHFP fingerprints on the wire, and authenticate pre-connect automation intents, so that hostile local injections, rogue host certificates, tampered DNS records, replayed automation commands, and unauthenticated terminal snippet executions are deterministically blocked.*

---

## 2. Implementation Summary

1. **Environment Variable & `initialDirectory` Injection Hardening:**
   - Evaluated and verified `LocalShellConnectionHandler.sanitizeEnvironment`:
     - Strips `LD_PRELOAD`, `LD_LIBRARY_PATH`, `ld_preload`, `Ld_Preload`, `ld_library_path`, `Ld_Library_Path` (case-insensitive) from incoming profile environment variables.
     - Automatically removes pre-existing `LD_PRELOAD` and `LD_LIBRARY_PATH` keys from the process environment map.
     - Preserves valid custom environment variables (`APP_ENV=production`, `TERM=xterm-256color`, custom API tokens).
   - Evaluated and verified `SshConnectionHandler` and `BackupSanitizer` directory sanitization:
     - Strips control characters (`ch.code >= 0x20 && ch.code != 0x7F`), neutralizing CRLF (`\r\n`), null byte (`\u0000`), and terminal escape (`\u001B`) injection vectors.
     - Safely escapes single quotes (`replace("'", "'\\''")`) ensuring the shell `cd '$escapedDir'\r\n` command cannot be escaped.
     - `BackupSanitizer.sanitize` cleanses incoming profiles using `HostValidator.stripControlChars`.

2. **Command Snippets Biometric Gate & Formatting (`TerminalSnippetHandler`):**
   - Verified that command snippets with `requireAuth = true` invoke `requestAuthentication` and halt execution without emitting any bytes to terminal standard input until simulated biometric authentication explicitly succeeds.
   - Verified that user cancellation or biometric mismatch results in zero terminal dispatch.
   - Verified that snippets with `requireAuth = false` dispatch immediately without prompting.
   - Verified that `autoSend = true` appends `\r` (ASCII `0x0D`), whereas `autoSend = false` emits raw command strings without newline execution.

3. **OpenSSH Host Certificates & `KnownHostsBulkPorter` Anti-MITM Guard:**
   - Verified `OpenSshCertificateValidator`:
     - Accepts valid `@cert-authority` host certificates within `[validAfter, validBefore]` with matching principals.
     - Rejects expired certificates (`CertValidationResult.Expired`).
     - Rejects not-yet-valid certificates (`CertValidationResult.NotYetValid`).
     - Rejects principal mismatches (`CertValidationResult.InvalidPrincipal`).
     - Rejects tampered signatures or tampered signedBytes (`CertValidationResult.InvalidSignature`).
     - Rejects unrecognized critical options (`CertValidationResult.UnsupportedCriticalOption`).
     - Rejects certificates signed by untrusted CAs (`CertValidationResult.CaNotTrusted`).
   - Verified `KnownHostsBulkPorter`:
     - Accurately parses `@cert-authority` and `@revoked` markers.
     - Strictly rejects lines with ANSI escape sequences (`\u001B`) or control characters (`\u0000`, `\r`).
     - Aborts bulk imports with conflict detection under `KnownHostsMergeStrategy.STRICT_REJECT_CONFLICTS` when an imported key conflicts with an existing trusted entry, leaving existing records untouched.

4. **DNSSEC `SSHFP` Adversarial Wire Validation (`SshfpVerifier`):**
   - Verified RFC 8484 DNS binary wire response parsing:
     - Rejects responses lacking the `AD` (Authenticated Data) bit (`SshfpValidationResult.DnssecNotAuthenticated`).
     - Rejects mismatched SHA-256 fingerprints (`SshfpValidationResult.FingerprintMismatchAlert`).
     - Handles responses with no matching algorithm records (`SshfpValidationResult.NoRecordsFound`).
     - Accepts valid authenticated SHA-256 (`fpType = 2`) records matching the host key (`SshfpValidationResult.ValidDnssecMatch`).

5. **Pre-Connect Automation (`AutomationIntentGuard`, `WolManager`, `PortKnockingManager`):**
   - Verified `AutomationIntentGuard`:
     - Authenticates valid HMAC-SHA256 intents (`AutomationValidationResult.Authenticated`).
     - Rejects replayed nonces via `NonceReplayCache`.
     - Rejects expired timestamps (`> 60_000ms` old) and future timestamps (`> 60_000ms` drift).
     - Rejects tampered HMAC-SHA256 signatures.
     - Rejects hostile override extras (`command`, `exec`, `cmd`, `host`, `hostname`, `port`, `password`, `user`, `username`).
   - Verified `WolManager`:
     - Conforms to standard 102-byte magic packets (`6x 0xFF` + 16x MAC repetitions) for colon and hyphen separated MAC strings.
     - Validates MAC strings and throws `IllegalArgumentException` on malformed formats (`"invalid-mac"`, `"00:11:22"`).
   - Verified `PortKnockingManager`:
     - Dispatches sequential TCP and UDP knock probes deterministically.
     - Enforces a 5-second cooldown rate limit per target host.

6. **Updated `SshConnectionManagerIntegrationTest.kt` (`testEnvVarTransmission`):**
   - Replaced trivial `assertTrue("Env var transmitted successfully", true)` with real assertions validating `ConnectionProfile.envVars` JSON serialization and `LocalShellConnectionHandler.sanitizeEnvironment` stripping of `LD_PRELOAD` / `LD_LIBRARY_PATH` while preserving valid env vars.
