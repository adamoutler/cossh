# QA Audit: SSH-223 — Material 3 SFTP File Browser Screen, Breadcrumb Navigation & In-App Text Preview Modal

## Epic
**SSH-187**: [EPIC] Power Features — SFTP, Mosh, Automation, Accessibility

## Scope of Implementation
- **Material 3 SFTP File Browser (`SftpBrowserScreen.kt` & `SftpBrowserViewModel.kt`):**
  - Path Breadcrumb Navigation: interactive horizontal scrolling bar parsing path segments (`root`, `var`, `log`, etc.), allowing immediate navigation to any ancestor directory.
  - Dynamic Search Filtering: live search input filtering files and directories by name.
  - Sorting Engine: Sort by Name (Ascending/Descending), Size (Ascending/Descending), Date Modified (Newest/Oldest), and Folders First toggle.
  - File List Rows: item icon (Folder, Code, Archive, Image, File), filename, size, POSIX permission string (`drwxr-xr-x`), and formatted date.
  - Action Handlers: directory creation dialog, rename dialog, and delete confirmation dialog.
- **Contextual Multi-Selection & Bulk Operations:**
  - Long-press activation entering multi-select mode with count banner.
  - "Select All" and "Clear Selection" actions.
- **Interactive POSIX Permission Editor (`SftpPermissionsDialog.kt`):**
  - 3x3 interactive checkbox matrix for Read, Write, and Execute bits across User, Group, and Others.
  - Live octal computation (e.g. `0755`, `0644`) with instant reactive synchronization between checkboxes and octal input.
- **In-App Monospace Text Preview Modal (`SftpTextViewerModal.kt`):**
  - Scrollable monospace text display for fast in-app inspection of scripts, configs, and logs.
  - Strict 2MB memory protection guard preventing out-of-memory errors on large remote files.
