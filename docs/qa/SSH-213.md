# QA Verification: SSH-213 Multi-Challenge Keyboard-Interactive & PAM (2FA TOTP) Authentication

## Overview
Ticket SSH-213 implements multi-challenge keyboard-interactive / PAM (Pluggable Authentication Modules) support for SSH connections in CoSSH. This enables enterprise two-factor authentication (e.g. PAM password + Duo/TOTP prompt) with zero-retention memory sanitization, heuristic echo protection, and secure UI modal prompts.

## Implemented Components
1. **`KeyboardInteractiveAuthenticator.kt` & `UserPromptRegistry.kt`**:
   - Registered `AuthKeyboardInteractive` handler implementing SSHJ `ChallengeResponseProvider`.
   - Bounded challenge exchange protection: enforces a maximum of 5 rounds, aborting with `UserAuthException` if the server loops infinitely.
   - Cleans up ephemeral prompt responses (`CharArray`) by filling with `\u0000` in `finally` blocks.
   - Sanitizes server prompts to strip ANSI escape sequences and bidirectional Unicode override characters (`\u202A`..`\u202E`, `\u2066`..`\u2069`).
   - Intelligent heuristic echo override: if `echo = true` from server, checks prompt text for sensitive keywords (`password`, `passcode`, `pin`, `token`, `secret`, `verification code`, `totp`) and enforces password visual transformation masking.
2. **`PamAuthDialog.kt`**:
   - Material 3 modal dialog with `FLAG_SECURE` window policy.
   - IME private mode (`IME_FLAG_NO_PERSONALIZED_LEARNING`).
   - Round counter indicator badge (`Round $round`), instructional text card, and responsive input field with TalkBack support.
3. **`TerminalScreen.kt`**:
   - Observes active `keyboardInteractivePromptRequest` from `ConnectionStateRepository` and presents `PamAuthDialog`.
