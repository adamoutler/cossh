# Verification Proof for SSH-206: Cloud Restore UI, Disable Sync & Zero-Knowledge Passphrase Storage

## Overview
Implemented complete user controls for Google Drive Cloud Sync, interactive cloud restore flows, and zero-knowledge memory sanitization for the sync passphrase:
1. Refactored `SecurityStorageManager` to encode/decode sync passphrases directly between `CharArray` and `ByteArray` using NIO buffers without creating immutable heap `String(passphrase)` instances.
2. Added `clearSyncPassphrase()` for secure credential wiping.
3. Added `isCloudSyncActive` user preference in `SettingsManager`.
4. Replaced the placeholder TODO in `SettingsScreen` with a functional toggle switch, a `DisableSyncConfirmationDialog` (with optional remote backup deletion), a `RestorePassphraseDialog`, a "Restore from Cloud" button, and status messaging.
5. Implemented `enableCloudSync()`, `disableCloudSync(deleteRemoteBackup: Boolean)`, and `restoreFromCloud(passphrase)` in `SettingsViewModel` with unique WorkManager task management (`"cossh_cloud_sync"`).
6. Made `WorkManager` optional in `SettingsViewModel` to prevent ARM64 native SQLite crashes in Robolectric tests.

## Key Implementation Details
1. **Zero-Knowledge Passphrase Handling (`SecurityStorageManager.kt`):**
   - `saveSyncPassphrase(passphrase: CharArray)` wraps `passphrase` in `CharBuffer.wrap()`, encodes using `StandardCharsets.UTF_8.newEncoder()`, extracts backing `ByteArray`, stores encrypted bytes, and in `finally` zeroes both the byte array and char array.
   - `getSyncPassphrase()` decodes stored ciphertext directly into a `CharArray` via `StandardCharsets.UTF_8.newDecoder()` and zero-wipes the intermediate byte array.
   - `clearSyncPassphrase()` securely removes `"sync_passphrase"` and `"sync_passphrase_iv"` from `EncryptedSharedPreferences`.
2. **Cloud Sync Settings & ViewModel (`SettingsViewModel.kt`, `SettingsManager.kt`):**
   - `disableCloudSync(deleteRemoteBackup: Boolean)` cancels `"cossh_cloud_sync"`, invokes `clearSyncPassphrase()`, sets `isCloudSyncActive = false`, and optionally invokes `driveSyncManager.deleteBackup()`.
   - `restoreFromCloud(passphrase)` calls `driveSyncManager.downloadBackup(passphrase)`, imports profiles and identities via `BackupCryptoManager.importProfilesFromZip`, persists them to secure storage, saves the sync passphrase, and zeroes `passphrase` in `finally`.
3. **UI Controls & Dialogs (`SettingsScreen.kt`):**
   - Active switch bound to `uiState.isCloudSyncActive`.
   - `DisableSyncConfirmationDialog` with checkbox to optionally delete remote backup from Google Drive.
   - `RestorePassphraseDialog` prompting for the zero-knowledge passphrase with password visibility toggle.
   - "Restore from Cloud" button and informational status banner with dismiss action.
