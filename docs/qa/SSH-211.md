## Ticket: SSH-211 - Implement Hardened OpenSSH Config Importer with Strict Directive Allowlist & Traversal Neutralization
* **User Story:** [SSH-211](file:///home/adamoutler/git/ssh/user_stories/SSH-211.md)

### 1. Architectural & Logic Implementation
* **Strict Directive Allowlist (`OpenSshConfigParser.kt`):**
  - Parses OpenSSH client configuration directives: `Host`, `HostName`, `User`, `Port`, `IdentityFile`, `ProxyJump`.
  - Enforces strict allowlist policy; any unsupported or dangerous directive (e.g. `ProxyCommand`, `LocalCommand`, `PermitLocalCommand`, `Match exec`) is strictly ignored and neutralized to eliminate Remote Code Execution (RCE) vectors.
  - Automatically bounds ports to `1..65535` and defaults to standard SSH port 22.
* **Path Traversal Neutralization & Key Association:**
  - Neutralizes relative and absolute directory traversal in `IdentityFile` (e.g., `../../etc/passwd` or `~/.ssh/id_ed25519`) by extracting strictly sanitized base filenames (`id_ed25519`).
  - Matches sanitized key names against available CoSSH `IdentityProfile` records.
* **Denial-of-Service (DoS) and Resource Exhaustion Defenses:**
  - Rejects files larger than 256 KB (`IllegalArgumentException`).
  - Rejects lines exceeding 4,096 characters to prevent memory thrashing.
  - Limits parsed host definitions to a maximum of 250 profiles to protect internal database capacity.
* **Interactive Conflict Resolution & Summary UI (`OpenSshImportDialogs.kt`):**
  - Integrated into `ConnectionListTopBar` overflow menu ("Import OpenSSH Config") via Android Storage Access Framework (SAF).
  - Displays `OpenSshConflictDialog` when duplicate profiles are encountered, offering "Skip" or "Rename" resolution.
  - Displays `OpenSshImportSummaryDialog` reporting successfully imported, renamed, and skipped profile counts upon completion.
