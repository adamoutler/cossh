# Verification Proof for SSH-204: Navigation Gating & Snippet Authentication

## Overview
Implemented UI navigation gating and snippet biometric authentication in CoSSH, including a cobalt-themed `AppLockScreen`, lifecycle hooks in `MainActivity` intercepting content when locked, incoming deep-link intent buffering and sanitized resumption in `AppNavigation`, and biometric authentication protection for sensitive command snippets (`requireAuth == true`) in `TerminalSnippetHandler` and `TerminalScreen`.

## Key Changes
1. **Cobalt-Themed Biometric Lock Screen (`AppLockScreen.kt`):**
   - Full-screen composable aligned with CoSSH cobalt aesthetic (`DeepCobalt`, `CobaltPrimary`, `CobaltCard`).
   - Displays lock security icon, "CoSSH Locked" title, explanatory subtitle, and an "Unlock with Biometrics" button with fingerprint icon.
2. **Activity Lifecycle Gating & Content Protection (`MainActivity.kt`):**
   - Initialized `AppLockManager.getInstance(applicationContext)`.
   - Wired `onStart` to `appLockManager.onAppForegrounded()` and `onStop` to `appLockManager.onAppBackgrounded()`.
   - In `setContent`: observes `appLockManager.isLocked`. When `true`, presents `AppLockScreen` and prevents access to terminal, saved credentials, or connection views.
   - Provides `promptBiometricUnlock()` using Android P `BiometricPrompt.Builder` and `CryptoObject` decryption verification against stored token.
3. **Deep-Link Intent Queuing & Sanitized Resumption (`AppNavigation.kt`):**
   - Injected `appLockManager: AppLockManager? = null` parameter (falls back to singleton).
   - When `isLocked` is true during launch or incoming intents (`activity?.intent` and `onNewIntentListener`), incoming intents are buffered in `appLockManager.pendingResumeIntent`.
   - When unlocked (`isLocked` transitions to `false`), the buffered intent is retrieved, `pendingResumeIntent` is cleared, and the intent is safely validated and routed via `IntentSanitizer.sanitizeAndNavigate()`.
4. **Command Snippet Biometric Authentication (`TerminalSnippetHandler.kt` & `TerminalScreen.kt`):**
   - `TerminalSnippetHandler` supports `requestAuthentication: ((CommandSnippet, onAuthenticated: () -> Unit) -> Unit)?`.
   - When `snippet.requireAuth == true`: delegates to `requestAuthentication` (or fallback confirmation dialog). Commands are never written to the terminal PTY unless authentication succeeds.
   - In `TerminalScreen.kt`: in production environments, invokes Android P `BiometricPrompt` before dispatching command bytes to the PTY. In headless test mode (`ConnectionStateRepository.isHeadlessTest == true`), safely routes to the interactive confirmation dialog.
