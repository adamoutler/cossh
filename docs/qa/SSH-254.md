# QA Audit: SSH-254 — Enforce Entitlement Integrity on Startup, Provision AndroidKeyStore HMAC Key, and Eliminate Dead DriveSync PBKDF2 Ciphers

## Epic
**SSH-188**: [EPIC] Security Differentiators — "Most Secure SSH Client on Android"  
**SSH-180**: [EPIC] Security Hardening

## Scope of Implementation
1. **Startup Entitlement Tamper Enforcement (`BillingManager.kt`):**
   - Refactored `_isCloudSyncEnabled` initialization to evaluate `isTestOverrideAllowed() || verifyEntitlementIntegrity()`.
   - Enhanced `verifyEntitlementIntegrity()`: if `cloud_sync_entitled = true` exists in `BillingPrefs.xml` but the HMAC tag is null or invalid, `BillingManager` immediately resets `cloud_sync_entitled` to `false`, purges `cloud_sync_entitled_hmac` from `BillingPrefs.xml`, and returns `false`.
   - Guaranteed that tampering with XML preferences on rooted devices cannot activate Cloud Sync without a valid HMAC signature.
2. **Hardware Keystore-Backed HMAC Key (`BillingManager.kt`):**
   - Removed the static plaintext `HMAC_KEY_SEED = "CoSSH_Billing_Entitlement_Key_Salt_2026"` constant from the codebase.
   - Implemented `getEntitlementKey()` which provisions and loads an `HmacSHA256` secret key inside `AndroidKeyStore` (`KEY_ALGORITHM_HMAC_SHA256`, alias `"cossh_billing_entitlement_hmac_key"`, `KeyProperties.PURPOSE_SIGN`).
   - Integrated a deterministic in-memory `SecretKey` fallback for Robolectric/JVM testing, ensuring test isolation and deterministic HMAC calculation across unit test runners.
3. **Elimination of Dead 65,536-Iteration Ciphers (`DriveSyncManager.kt` & `sync/GEMINI.md`):**
   - Deleted dead `private fun encrypt(...)` and `private fun decrypt(...)` methods (which used legacy 65,536 iterations).
   - In `downloadBackup()`, removed the obsolete decrypt fallback; HTTP 200..299 responses now return `downloadedPayload` directly to the caller.
   - Cleaned up companion iteration properties (`DEFAULT_PBKDF2_ITERATIONS`, `pbkdf2Iterations`, `setIterationsForTesting`, `resetIterationsForTesting`) and pruned unused crypto imports (`SecureRandom`, `AEADBadTagException`, `Cipher`, `SecretKeyFactory`, `GCMParameterSpec`, `PBEKeySpec`, `SecretKeySpec`).
   - Updated `app/src/main/kotlin/com/adamoutler/ssh/sync/GEMINI.md` defining `DriveSyncManager` strictly as a transport client, establishing `BackupCryptoManager` (250,000-iteration PBKDF2 v3 AAD cipher) as the sole encryption authority.
4. **Test Suite Modernization (`PreReleasePrivacyAndOsLeakageTest.kt`, `BillingEntitlementPersistenceTest.kt`, `DriveSyncManagerTest.kt`, `DriveSyncMultipartTest.kt`):**
   - Expanded `PreReleasePrivacyAndOsLeakageTest.kt` to verify that startup initialization detects missing and forged HMAC tags, clears the preference file, and keeps `isCloudSyncEnabled.value` false.
   - Updated `BillingEntitlementPersistenceTest.kt` to write valid HMAC tags during cache tests and assert automatic preference purging on tampered entries.
   - Refactored `DriveSyncManagerTest.kt` and `DriveSyncMultipartTest.kt` to remove reflection invocations of deleted `encrypt`/`decrypt` methods.
