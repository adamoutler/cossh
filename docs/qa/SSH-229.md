# QA Verification: SSH-229 — OpenSSH Visual Host Key Randomart & High-Friction MITM Alert

## Epic
**SSH-188**: [EPIC] Security Differentiators — "Most Secure SSH Client on Android"

## Feature Overview
SSH-229 implements the OpenSSH Drunken Bishop visual host key fingerprint algorithm, obsidian terminal container rendering, and a high-friction MITM security warning dialog requiring a 2.5-second hold confirmation on host key changes.

## Implemented Components
1. **`OpenSshRandomartGenerator.kt`** (`com.adamoutler.ssh.crypto.randomart`):
   - Pure Kotlin implementation of the authentic OpenSSH 17x9 field matrix ($X \in [0, 16], Y \in [0, 8]$).
   - Augmentation string: `" .o+=*BOX@%&#/^SE"`.
   - Start point at center `(8, 4)` marked with `'S'`, terminal point marked with `'E'`.
   - Exact OpenSSH frame headers `+--[KEY_TYPE]--+` and footers `+----[HASH]----+`.
   - Functions `generate(rawDigest, keyTypeTitle, hashAlgorithmTitle)` and `generateFromPublicKeyBytes(publicKeyBytes, keyTypeTitle, useSha256)`.
2. **`RandomartBox.kt`** (`com.adamoutler.ssh.ui.components`):
   - Obsidian terminal container (`#0B0F19`), monospace 12sp typography.
   - Distinct green styling for Start `'S'` (`#10B981`) and amber for End `'E'` (`#F59E0B`).
   - Customizable border styling for security comparison contexts.
3. **`TofuHostKeyVerifier.kt`** & **`ConnectionStateRepository.kt`**:
   - `HostKeyPromptRequest` extended with optional `expectedRandomart` and `receivedRandomart`.
   - `TofuHostKeyVerifier` computes randomart from the remote server's public key bytes and previous known key bytes during handshake.
4. **`AppNavigation.kt`**:
   - Initial TOFU dialog renders `RandomartBox` alongside SHA-256 fingerprint.
   - When `request.isKeyChanged == true`, presents high-friction alert with side-by-side comparison (Expected Previous Key vs Received Untrusted Key) with distinct borders and a 2500ms `HoldToConfirmButton`.
5. **`KnownHostsScreen.kt`**:
   - Expandable "Show OpenSSH Randomart" toggle on saved host cards.
