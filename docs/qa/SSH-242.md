# QA Audit: SSH-242 — Pre-Release Crypto Hardening, Hardware Keystore Wiring & AppLock Immunity

## Epic
**SSH-188**: [EPIC] Security Differentiators — "Most Secure SSH Client on Android"

## Scope of Implementation
1. **Biometric App-Lock Exception Bypass Elimination (`MainActivity.kt` & `AppLockManager.kt`):**
   - Eliminated the biometric unlock bypass in `MainActivity.kt` lines 177-181. When `BiometricPrompt.Builder` or `prompt.authenticate` throws an exception, `AppLog.e` logs the diagnostic event and `appLockManager` remains securely locked unless `appLockManager.allowHeadlessTestFallback` is explicitly set to `true`.
   - Added `var allowHeadlessTestFallback: Boolean = false` in `AppLockManager.kt` strictly defaulting to `false`.
2. **Preservation of Window-Level `FLAG_SECURE` (`PamAuthDialog.kt`, `EncryptedKeyPassphraseModal.kt`, `UrlConfirmationBottomSheet.kt`, `KeyManagementScreen.kt`):**
   - In each component's `DisposableEffect`, recorded `val wasAlreadySecure = ((window?.attributes?.flags ?: 0) and WindowManager.LayoutParams.FLAG_SECURE) != 0` before setting `FLAG_SECURE`.
   - In `onDispose`, guarded `window?.clearFlags(FLAG_SECURE)` with `if (!wasAlreadySecure)`.
   - Prevents child dialog and sheet dismissals from inadvertently stripping `FLAG_SECURE` from `MainActivity`, ensuring continuous screen recording and screenshot protection.
3. **End-to-End StrongBox / TEE Hardware Keystore Keys (`IdentityProfile.kt`, `IdentityStorageManager.kt`, `IdentityViewModel.kt`, `SshHandshakeCoordinator.kt`):**
   - Added `val keystoreAlias: String? = null` to `IdentityProfile` with full serialization, `equals`, and `hashCode` support.
   - Enhanced `IdentityStorageManager` to persist `keystoreAlias` in both JSON metadata and `${identity.id}_keystore_alias` preference entries. Maintained backward compatibility by hydrating legacy profiles and filtering out auxiliary preference keys in `getAllIdentities()`.
   - In `IdentityViewModel`, wired `result.alias` from `StrongBoxKeyManager.generateStrongBoxKeyPair()` into `_uiState` and preserved `keystoreAlias` when calling `saveIdentity()`.
   - In `SshHandshakeCoordinator`, implemented `HardwareKeyAuthenticator` wrapping `HardwareKeyProvider`, extracted `parsePublicKeyFromOpenSsh`, and implemented `resolveHardwareKeyProvider` resolving keys from `AndroidKeyStore` or the thread-safe `testHardwareKeyProviders` test registry.
4. **Automated Unit Tests (`PreReleaseCryptoAndAppLockHardeningTest.kt`):**
   - Comprehensive unit test suite covering all security assertions across biometric fallback immunity, window flag persistence, identity storage serialization, and SSHJ key provider authentication.
