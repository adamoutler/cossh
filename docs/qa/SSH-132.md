# SSH-132 QA Proof and Evidence

## Description
This ticket required supporting an Initial Directory (CWD) on connection.

## Technical Implementation
- **Data Class:** Added `val initialDirectory: String? = null` to `ConnectionProfile`. Serialization handles this seamlessly.
- **UI:** Added an `OutlinedTextField` labeled "Initial Directory (CWD)" to the Advanced Configuration section in `AddEditProfileScreen.kt`. It includes the required `supportingText` warning about the MOTD.
- **PTY Injection:** Updated `SshConnectionManager.kt` (`connectPty` and `connectTelnet`) to automatically write `cd '/escaped/path'\r\n` directly to the `shell.outputStream` immediately after the shell is allocated, but before handing the stream off to the bridge.

## Verification
- `BackupCryptoManagerTest.kt` was updated to ensure that `initialDirectory` properly survives backup encryption and decryption.
- The unit test `BackupCryptoManagerTest > testExportAndImportBackup` passes successfully.
- CI pipeline demonstrates zero-tolerance failures.
