# Terminal Options

The **Terminal Options** section provides customization settings for how the SSH terminal behaves and renders on your device.

## Default Input Mode
- **Standard:** The default view. The soft keyboard and extra terminal keys (Ctrl, Alt, Tab, etc.) are hidden until the terminal is tapped.
- **Fixed:** The extra terminal keys are always visible on-screen. Tapping the terminal will still toggle the soft keyboard.

## Keep Screen On Mode
- **System:** Uses the default Android system sleep settings.
- **Smart:** Keeps the screen on only when there is active network or terminal activity.
- **Always:** Prevents the device from sleeping while the terminal session is active.
