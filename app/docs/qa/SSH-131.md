# SSH-131 QA Proof and Evidence

## Description
This ticket required adding a profile selector and default host to the Inject Key dialog.

## Technical Implementation
- **UI Architecture:** `InjectKeyDialog` was updated to use an `ExposedDropdownMenuBox`. It accepts `profiles: List<ConnectionProfile>` and displays matches based on nickname or host.
- **Default Host:** The `host` field uses "127.0.0.1" as a placeholder and explicitly defaults to `127.0.0.1` if left blank upon clicking "Inject".
- **Keyboard Handling:** Applied `Modifier.verticalScroll` and `Modifier.imePadding()` to ensure the UI is fully visible when the keyboard is open on small screens.
- **Data Flow:** `AddEditIdentityScreen.kt` now fetches `val profiles = SecurityStorageManager(context).getAllProfiles()` and passes them down to the dialog.

## Verification
The application compiles perfectly. 
Paparazzi tests continue to pass and unit tests confirm that no regressions were introduced.
