# User Story: SSH-207 - Configurable SSH Keepalive and Dead-Peer Detection

**As an SSH terminal operator working over mobile carrier networks and firewalled gateways,**
I want CoSSH to transmit periodic encrypted SSH keepalive packets and promptly detect dead peers,
**so that** quiescent sessions do not silently freeze or drop due to aggressive carrier NAT state expiration.

## Acceptance Criteria
1. **Configurable Keepalive Intervals (`ConnectionProfile` & `AddEditProfileScreen`):**
   - Support keepalive interval selection in seconds (`keepAliveIntervalSeconds`) with presets: 0s (Disabled), 15s, 30s, and 60s.
   - Default to 15s for new SSH profiles to maintain resilient mobile connections while optimizing battery life.
2. **Hardened SSHJ Keepalive Provider (`SecureSshConfig`):**
   - Explicitly configure `KeepAliveProvider.KEEP_ALIVE` in `SecureSshConfig` to activate cryptographic keepalive probe exchanges.
3. **Dead-Peer Detection & Coordinator Handshake (`SshHandshakeCoordinator`):**
   - When `keepAliveIntervalSeconds > 0`, configure `client.connection.keepAlive.keepAliveInterval` immediately upon successful authentication.
   - Reset socket read timeout `client.timeout` from handshake timeout (10s) to 0 (infinite) upon entering streaming mode to prevent quiescent socket reads from throwing false timeouts.
4. **Zero-Tolerance Quality:**
   - Zero compiler warnings, strictly safe typing, no unhandled exceptions.
   - Comprehensive test suite covering interval validation and timeout resets.
