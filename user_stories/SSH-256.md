# User Story: SSH-256 — Play Store Assets, Release Bundle Pipeline, Security Disclosures & Module Manifests

## Goal
Ensure complete production release readiness for CoSSH on the Google Play Store and open-source mirrors by standardizing store graphics (icon and feature graphic banner), adding Android App Bundle (`bundleRelease`) generation to CI/CD workflows, providing thorough privacy policy disclosures and security boundary documentation, and establishing self-describing architectural `GEMINI.md` manifests across core application packages.

---

## Technical Scope & Mitigations

1. **Google Play Store Asset Standards:**
   - **App Icon (`docs/img/icon.png`):** Formatted to exact 512x512 pixels, 32-bit RGBA PNG, under 1,024 KB.
   - **Feature Graphic (`docs/img/banner.png`):** Formatted to exact 1024x500 pixels, 24-bit RGB PNG (no alpha channel), under 1,024 KB.
   - **Multi-Density Launcher Icons:** Generated raster launcher icons (`ic_launcher.png` and `ic_launcher_round.png`) across `mipmap-mdpi` (48x48), `mipmap-hdpi` (72x72), `mipmap-xhdpi` (96x96), `mipmap-xxhdpi` (144x144), and `mipmap-xxxhdpi` (192x192), while keeping `mipmap-anydpi/` adaptive vectors intact.

2. **CI/CD Release App Bundle Generation:**
   - Updated `.forgejo/workflows/ci.yml` and `.github/workflows/ci.yml` to execute `./gradlew bundleRelease` alongside `./gradlew assembleRelease` during release verification steps.

3. **Privacy Disclosures & Security Boundaries (`docs/privacy-policy.md` & `README.md`):**
   - Explicitly documented 250,000 PBKDF2 iterations for master password key derivation.
   - Enumerated all six Android permissions declared in `AndroidManifest.xml` with security rationale: `INTERNET`, `USE_BIOMETRIC`, `POST_NOTIFICATIONS`, `WAKE_LOCK`, `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_SPECIAL_USE`.
   - Documented hardware security boundaries: Android Keystore, StrongBox Keymaster (hardware HSM), Trusted Execution Environment (TEE), and FIDO2 / WebAuthn hardware security keys.
   - Documented complete user data sovereignty and remote Cloud Sync data deletion procedures.
   - Linked `README.md` to `docs/privacy-policy.md`, `docs/security-whitepaper.md`, and `LICENSE`.

4. **Self-Describing Architecture Manifests (`GEMINI.md`):**
   - Authored comprehensive manifests containing Logical Purpose, Key Components & APIs, Behavioral Contracts & Design Patterns, and Dependencies in:
     - `app/src/main/kotlin/com/adamoutler/ssh/GEMINI.md`
     - `app/src/main/kotlin/com/adamoutler/ssh/openssh/GEMINI.md`
     - `app/src/main/kotlin/com/adamoutler/ssh/sftp/GEMINI.md`
     - `app/src/main/kotlin/com/adamoutler/ssh/util/GEMINI.md`
     - `app/src/main/kotlin/com/adamoutler/ssh/vm/GEMINI.md`

---

## Acceptance Criteria

1. **Asset Dimensions & Formats:**
   - `docs/img/icon.png` is decodable as 512x512 with alpha, size <= 1,024 KB.
   - `docs/img/banner.png` is decodable as 1024x500 without alpha, size <= 1,024 KB.
   - All raster mipmap densities (`mdpi`, `hdpi`, `xhdpi`, `xxhdpi`, `xxxhdpi`) contain valid `ic_launcher.png` and `ic_launcher_round.png` at appropriate sizes.
2. **CI Configuration:**
   - Both `.forgejo/workflows/ci.yml` and `.github/workflows/ci.yml` invoke `bundleRelease`.
3. **Documentation:**
   - `docs/privacy-policy.md` documents 250,000 PBKDF2 iterations, all six permissions, hardware boundaries (StrongBox, TEE, FIDO2/WebAuthn), and remote deletion.
   - `README.md` contains relative links to Privacy Policy, Security Whitepaper, and LICENSE.
4. **Manifests:**
   - All five target packages contain valid `GEMINI.md` files describing purpose, components, contracts, and dependencies.
5. **Automated Verification:**
   - `ReleaseBundleAndMetadataVerificationTest` executes and passes 100% of assertions.
