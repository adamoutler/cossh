# User Story: SSH-204 - Navigation Gating & Snippet Authentication

**As an SSH terminal operator,**
I want incoming deep links to be safely queued until I authenticate and high-privilege snippets to require biometric confirmation before running,
**so that** sensitive remote commands and connection intents cannot bypass authentication or trigger unintended server actions.

## Acceptance Criteria
1. **Cobalt-Themed Biometric Lock Screen (`AppLockScreen`):**
   - Provide a dedicated, full-screen composable `AppLockScreen` featuring the CoSSH cobalt aesthetic, lock icon, explanatory security copy, and an "Unlock with Biometrics" action button.
2. **Activity Lifecycle Gating & Content Protection (`MainActivity`):**
   - Bind `MainActivity` `onStart` and `onStop` to `AppLockManager.onAppForegrounded()` and `onAppBackgrounded()`.
   - In `setContent`, observe `AppLockManager.isLocked`. When locked, intercept rendering with `AppLockScreen` and prevent access to `AppNavigation` and sensitive terminal content.
   - When unlocked or disabled, seamlessly render the normal app UI without flicker or navigation loss.
   - Wire biometric prompt flow using Android P `BiometricPrompt.Builder` and `CryptoObject` decryption verification.
3. **Deep-Link Intent Queuing & Sanitized Resumption (`AppNavigation`):**
   - When the app is launched or receives a new intent while `isLocked == true`, buffer the incoming `Intent` in `AppLockManager.pendingResumeIntent` rather than processing it immediately.
   - Once `isLocked` transitions from `true` to `false`, pop the buffered intent, clear `pendingResumeIntent`, and route through `IntentSanitizer.sanitizeAndNavigate()` to complete the deferred deep link securely.
4. **Snippet Execution Authentication Gate (`TerminalSnippetHandler` & `TerminalScreen`):**
   - In `TerminalSnippetHandler`, evaluate `snippet.requireAuth`. If `true`, delegate to `requestAuthentication(snippet) { /* execute */ }`.
   - Never write sensitive snippet commands to the terminal PTY unless authentication succeeds.
   - In `TerminalScreen`, connect `requestAuthentication` to trigger `BiometricPrompt` on API 28+ (or biometric confirmation fallback) before dispatching snippet commands.
5. **Regression Prevention & Integrity:**
   - Standard non-authenticated snippets (`requireAuth == false`) execute immediately without prompt.
   - Zero warnings, strictly safe typing, complete zero-wipe cleanup of all sensitive ephemeral data.
