# User Story: SSH-200 - SOCKS5 Listener Hardening & Sensitive Clipboard Protection with Auto-Clear

**As a mobile user forwarding network traffic through dynamic SOCKS5 proxies and copying terminal text on Android,**
I want CoSSH's SOCKS5 proxy listener hardened against connection exhaustion attacks and resource leaks (enforcing a maximum of 32 concurrent connections, a 5-second server socket timeout, a 15-second handshake timeout, and clean teardown of all active sockets), and terminal clipboard copies tagged with `EXTRA_IS_SENSITIVE` and automatically purged from system clipboard memory after 30 seconds,
**so that** hostile local applications cannot exhaust device sockets through malicious SOCKS5 flooding, and sensitive tokens, passwords, or shell outputs copied from the terminal are not persistently exposed to background clipboard sniffers.

## Acceptance Criteria
1. **SOCKS5 Listener Concurrency & Socket Timeout Hardening:**
   - Enforce `MAX_CONCURRENT_FORWARD_CONNECTIONS = 32` in `PortForwardingOrchestrator.kt`, rejecting and immediately closing any connections exceeding the limit.
   - Set `serverSocket.soTimeout = 5000` (`SERVER_SOCKET_SO_TIMEOUT_MS`) on dynamic listeners to ensure responsive lifecycle polling and clean thread shutdown.
   - Enforce `socket.soTimeout = 15_000` (`SOCKS5_HANDSHAKE_TIMEOUT_MS`) on incoming client sockets during the initial SOCKS5 handshake phase.
   - Once the SSH direct-tcpip tunnel opens, reset the client socket to streaming mode: `soTimeout = 0`, `keepAlive = true`, and `tcpNoDelay = true`.
   - Track all active client sockets using `ConcurrentHashMap.newKeySet<Socket>()`.
   - In `stopAll()`, cleanly close all tracked active client sockets and server sockets, and shut down the worker executor.
2. **Sensitive Clipboard Auto-Clear:**
   - Create `com.adamoutler.ssh.security.SecureClipboardManager.kt`.
   - On Android 13+ (API 33+), set `ClipDescription.EXTRA_IS_SENSITIVE = true` in clip extras so the OS masks preview popups and avoids syncing sensitive clips to cloud clipboards.
   - Launch a 30-second coroutine delay on the provided scope to automatically purge the clipboard if its content still matches the copied text.
   - Cancel any pending auto-clear timer when a new copy operation is performed.
   - Provide explicit manual `clearClipboard(context: Context)` functionality.
   - Wire `TerminalViewModel.kt`'s `onCopyTextToClipboard` to `SecureClipboardManager.copyToClipboard`.
