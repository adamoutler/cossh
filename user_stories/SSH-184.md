# User Story: SSH-184 — [EPIC] Authentication & Key Management Parity

## Goal
Reach full enterprise-grade feature and security parity for SSH authentication and key management, matching and exceeding legacy clients (JuiceSSH, Termius, ConnectBot):
1. Multi-challenge Keyboard-Interactive & PAM (2FA TOTP/Duo) authentication with strict memory sanitization.
2. Passphrase-protected private key decryption supporting OpenSSH `bcrypt-pbkdf`, PKCS#8, and legacy PEM containers, alongside comprehensive ECDSA (NIST P-256, P-384, P-521) key parity.
3. Storage Access Framework (SAF) document picker integration for importing raw and extensionless key files directly from storage into Android Keystore MasterKey encryption with interactive unlock modals.
4. Dedicated Known Hosts management screen under Settings with OpenSSH HMAC-SHA1 (`|1|...`) hashed host matching, one-touch plaintext-to-hashed batch migration, and atomic file replacements under mutex.
5. Elimination of ambiguous, broken profile-level direct key storage, strictly unifying all SSH key authentication under Keystore-backed `IdentityProfile` models.

## Child Tickets & Scope
- **SSH-213**: Implement Multi-Challenge Keyboard-Interactive & PAM (2FA TOTP) Authentication with Memory Sanitization (`Done`)
- **SSH-214**: Implement Passphrase-Protected Key Decryption (OpenSSH bcrypt-pbkdf, PKCS#8) & ECDSA Key Parity (`Done`)
- **SSH-215**: Implement SAF Key File Importer & Interactive Passphrase Unlock Modal in Identity Manager (`Done`)
- **SSH-216**: Implement Dedicated Known Hosts Management Screen & OpenSSH Hashed Hosts Parity (`Done`)
- **SSH-217**: Deprecate Broken Profile-Level Key Auth in Favor of Unified Identity Profiles (`Done`)

## Acceptance Criteria
1. **Full Authentication Parity**: All 5 constituent child tickets fully implemented, passing 100% of unit, integration, and UI screenshot tests.
2. **Cryptographic Hardening & Zero Retention**:
   - Zero plaintext keys or passphrases retained in memory; active wiping (`fill(0)` / `fill('\u0000')`) in `finally` blocks.
   - Atomic replacement for `ssh_known_hosts` preventing race-condition corruption.
   - Strict bounds checking (64KB ceiling on SAF key imports, 5 max PAM challenge rounds).
3. **Artifact-Backed Verification**:
   - Pixel-perfect Paparazzi screenshot artifacts committed under `docs/qa/` for each UI component.
   - Comprehensive test coverage with zero warnings, strictly safe typing, and zero unhandled exceptions.
