# User Story: SSH-226 — Pre-Connect Wake-on-LAN (WOL) Dispatcher & Rate-Limited Port Knocking Engine

## Epic
**SSH-187**: [EPIC] Power Features — SFTP, Mosh, Automation, Accessibility

## User Story
**As a** network and homelab administrator managing firewalled or sleeping servers,
**I need** CoSSH to execute pre-connection actions—specifically broadcasting Wake-on-LAN (WOL) magic packets and executing sequential TCP/UDP port knocks with rate-limiting and timeouts—prior to opening an SSH socket,
**So that** sleeping hosts wake up and firewall rules open automatically without manual scripting.

## Acceptance Criteria
1. **Pre-Connect Configuration Domain Models (`ConnectionProfile.kt`):**
   - Create `WolConfig(val macAddress: String, val broadcastIp: String = "255.255.255.255", val port: Int = 9, val postWakeDelayMs: Long = 2000L)`.
   - Create `enum class KnockProtocol { TCP, UDP }`.
   - Create `PortKnockStep(val port: Int, val protocol: KnockProtocol = KnockProtocol.TCP)`.
   - Create `PortKnockingConfig(val steps: List<PortKnockStep>, val stepDelayMs: Long = 150L, val postKnockDelayMs: Long = 1000L, val probeTimeoutMs: Int = 400)`.
   - Add optional `wolConfig: WolConfig? = null` and `portKnockingConfig: PortKnockingConfig? = null` to `ConnectionProfile` with full `@Serializable` backward compatibility and updated `equals`/`hashCode`.
2. **Hardened WOL & Port Knocking Engines (`WolManager.kt` & `PortKnockingManager.kt`):**
   - **WOL Magic Packet Construction:** Validate MAC format via strict regex (`^([0-9A-Fa-f]{2}[:-]){5}([0-9A-Fa-f]{2})$`). Build 102-byte payload (`6 * 0xFF` + 16 MAC repetitions) and broadcast via non-blocking `DatagramSocket` on `Dispatchers.IO`.
   - **Port Knocking Engine:** Execute sequential TCP socket connect attempts (with bounded 400ms timeout) and UDP datagram probes. Enforce a 5-second cooldown rate limit between sequences to prevent network flooding and firewall lockouts.
3. **Pre-Connection Dispatcher (`SshHandshakeCoordinator.kt`):**
   - Wire pre-connection execution inside `executeWithConnection` before socket handshake.
   - Dispatch WOL packet if configured with post-wake delay.
   - Dispatch Port Knock sequence with step and post-knock delays.
4. **Configuration UI in `AddEditProfileScreen.kt` & `PreConnectActionsCard.kt`:**
   - Add "Pre-Connect Actions" collapsible card.
   - Fields: Wake-on-LAN switch with MAC Address input and Port Knocking sequence builder with step additions (port number + TCP/UDP chip).
   - TalkBack accessibility labels and instant format validation.
5. **Automated Test Coverage & Paparazzi:**
   - Unit tests in `WolManagerTest.kt` and `PortKnockingManagerTest.kt` verifying packet construction, MAC format validation, socket timeout handling, and rate limiting.
   - Paparazzi screenshot artifact `docs/qa/SSH-226-pre-connect-settings.png`.
6. **Zero-Tolerance Quality:**
   - Zero compiler warnings, strictly safe typing, no unhandled exceptions.
