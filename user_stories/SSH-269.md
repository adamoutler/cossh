# User Story: SSH-269 — Standardize GA Store Assets, Clean Master Icon, Package Fastlane Metadata & Align F-Droid Release

## Persona & Context
**Role:** DevSecOps Engineer and Product Release Architect  
**Goal:** Prepare CoSSH (Cobalt SSH) for Market Release General Availability (GA) across Google Play, F-Droid, and GitHub distributions with validated, artifact-free store graphics and standardized Fastlane metadata trees.

## Story
*As a DevSecOps engineer and product release architect preparing CoSSH for Market Release General Availability (GA) across Google Play and F-Droid, I need `docs/img/icon.png` and all fallback raster mipmaps re-rendered with Deep Cobalt squircle backgrounds to eliminate white chevron bleed on light launchers while preserving clean transparent outer corners, a standardized `fastlane/metadata/android/en-US/` directory tree populated with compliant listing texts (title, short/full descriptions, changelog) and 8 authentic, unclipped 1080×1920 phone screenshots, `metadata/com.adamoutler.cobaltssh.yml` synchronized with NDK r29 and `-PbuildUnsigned=true`, release signing guarded against silent debug keystore fallback, and automated verification tests in `ReleaseBundleAndMetadataVerificationTest` asserting icon cleanliness, Fastlane constraints, and build reproducibility, so that public distribution assets and release packages strictly satisfy enterprise production standards.*

## Detailed Scope & Acceptance Criteria
1. **Master Store Icon & Raster Mipmaps:**
   - Re-render `docs/img/icon.png` (512x512 RGBA) with Deep Cobalt squircle background (`#001C3D`), eliminating white chevron bleeding while preserving `alpha == 0` on outer corners `(0,0)`, `(511,0)`, `(0,511)`, `(511,511)`.
   - Eliminate all rectangular bounding box artifacts (`[x: 312..490, y: 385..424]`).
   - Regenerate all legacy raster mipmap densities (`mdpi`, `hdpi`, `xhdpi`, `xxhdpi`, `xxxhdpi`) for both squircle and round configurations.
2. **Fastlane Metadata Tree (`fastlane/metadata/android/en-US/`):**
   - Author compliant `title.txt` (<= 30 chars), `short_description.txt` (<= 80 chars), and `full_description.txt` (<= 4000 chars).
   - Author `changelogs/default.txt` (<= 500 chars).
   - Place store icon `images/icon.png` (512x512 RGBA) and feature graphic `images/featureGraphic.png` (1024x500 RGB) with authentic hex stream overlay.
   - Package 8 authentic, unclipped 1080x1920 (9:16) phone store listing screenshots in `images/phoneScreenshots/`.
3. **F-Droid Recipe Synchronization (`metadata/com.adamoutler.cobaltssh.yml`):**
   - Align version code and version name with the git commit counter build scheme (`1.898` / `898`).
   - Remove broken `subdir: app` and invalid regex `sed` command.
   - Specify `ndk: r29` matching `app/build.gradle.kts` (`29.0.14206865`) and add `-PbuildUnsigned=true` gradle flag.
4. **Gradle Release Signing Guard & Unsigned Builds (`app/build.gradle.kts`):**
   - Wire `-PbuildUnsigned=true` to set `release.signingConfig = null` for genuine unsigned APK outputs.
   - Guard release keystore fallback.
5. **Automated Verification:**
   - Extend `ReleaseBundleAndMetadataVerificationTest` to assert clean transparent corners and zero black box pixels in `docs/img/icon.png`.
   - Verify Fastlane metadata existence and character length constraints.
   - Verify F-Droid recipe parameters and NDK synchronization.
