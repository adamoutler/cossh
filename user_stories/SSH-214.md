# User Story: SSH-214 - Passphrase-Protected Key Decryption (OpenSSH bcrypt-pbkdf, PKCS#8) & ECDSA Key Parity

**As a security-conscious engineer importing existing SSH credentials,**
I want to decrypt passphrase-protected OpenSSH (bcrypt-pbkdf), PKCS#8, and legacy PEM private keys and generate ECDSA key pairs across NIST curves,
**so that** I can seamlessly use my encrypted production keys in CoSSH with zero-retention memory sanitization and modern elliptic-curve cryptographic parity.

## Acceptance Criteria
1. **Passphrase Decryption Engine (`PemUtils`):**
   - Automatically detect encrypted private key formats: OpenSSH v1 (`bcrypt-pbkdf`, AES/ChaCha20), PKCS#8 (`PBES2`/`PBEWithSHAAnd3-KeyTripleDES-CBC`), and legacy OpenSSL PEM (`Proc-Type: 4,ENCRYPTED`).
   - Throw `KeyIsEncryptedException` with format/cipher summary when key requires passphrase and none is supplied.
   - Throw `InvalidPassphraseException` on wrong passphrase, MAC check failure, or decryption tag mismatch.
   - Symmetrically decrypt valid keys and derive corresponding public keys (`Ed25519`, `RSA`, `ECDSA`).
2. **Elliptic Curve (ECDSA) Key Parity (`SSHKeyGenerator`):**
   - Generate ECDSA key pairs across NIST curves: P-256 (`secp256r1`), P-384 (`secp384r1`), and P-521 (`secp521r1`).
   - Encode ECDSA public keys in RFC 5656 OpenSSH wire format (`ecdsa-sha2-nistp256`, `ecdsa-sha2-nistp384`, `ecdsa-sha2-nistp521`).
3. **Volatile State Memory Sanitization:**
   - Passphrase buffers must strictly use mutable `CharArray` with immediate zero-wiping (`passphrase.fill('\u0000')`) in `finally` blocks.
   - Intermediate decrypted key DER byte arrays must be actively overwritten and wiped (`bytes.fill(0)`) post-import.
4. **Interactive Unlock Modal (`EncryptedKeyPassphraseModal`):**
   - Material 3 dialog with `FLAG_SECURE` window protection against screen capture and task-switcher previews.
   - `SecurePasswordEditText` input with `IME_FLAG_NO_PERSONALIZED_LEARNING` to prevent keyboard telemetry / dictionary learning.
   - Monospace format summary badge and assertive live region error messaging.
5. **Zero-Tolerance Quality:**
   - Zero compiler warnings, strictly safe typing, no unhandled exceptions.
   - Comprehensive unit and Paparazzi UI screenshot tests.
