# User Story: SSH-148 - Feature: Use Local Network DNS (Bypass Private DNS)

**As a user connecting to local servers (like a homelab or mock server),**
I need the app to resolve local hostnames even when Android's Private DNS is enabled,
**so that** I don't have to disable system-wide secure DNS just to use the app.

## Acceptance Criteria
1. **Per-Profile Setting:** Add a boolean flag `useLocalDns` (default: false) to the `ConnectionProfile` data class and ViewModel/State flows. Do not make this global.
2. **UI Implementation:** Add an "Advanced Network Settings" section to the `AddEditProfileScreen`. Include a toggle with the primary label: `Use Local Network DNS`. Add the subtext: `Overrides secure Private DNS to resolve local hostnames. Queries may be unencrypted and visible to the network.`
3. **Network Implementation:** Modify the DNS resolution logic in `SshHandshakeCoordinator.executeWithConnection()`. If `useLocalDns` is enabled on the profile, use `android.net.ConnectivityManager` to obtain the active `Network` and call `network.getAllByName(host)` to resolve the IP using the network's DHCP DNS servers, bypassing the system-wide Private DNS. Wrap the resolved address in `InetAddress.getByAddress(hostname, ipBytes)` to ensure SSHJ still performs host key verification against the original hostname, not the IP.
4. **Security Enforcement:** Ensure strict Host Key Verification remains enabled. The UI warning must be clear about the security trade-off.
