# User Story: SSH-212 - RFC 1073 Telnet NAWS Window Size Subnegotiation

## Title
Implement RFC 1073 Telnet NAWS Window Size Subnegotiation with Mandatory IAC Escaping & Loop Guard

## User Story
**As a** network administrator managing legacy routers and terminal multiplexers over Telnet,  
**I need** RFC 1073 NAWS (Negotiate About Window Size) subnegotiation with mandatory RFC 854 IAC collision escaping and loop guards,  
**So that** my terminal dimensions synchronize dynamically with full-screen curses/vim utilities without state desynchronization or command injection.

## Acceptance Criteria
1. **RFC 1073 Protocol Subnegotiation (`TelnetConnectionHandler.kt` & `TelnetNawsProtocol.kt`):**
   - Implements option 31 (`0x1F`, NAWS) using `WindowSizeOptionHandler` and dynamic subnegotiation.
   - When server sends `IAC DO NAWS`, client responds with `IAC WILL NAWS` and transmits 16-bit terminal width and height in network byte order.
   - Implements RFC 1143 Q-method state machine (`NawsNegotiationStateMachine`) to ignore duplicate `IAC DO NAWS` requests once negotiated in `State.YES`, suppressing infinite loops.
2. **Mandatory RFC 854 IAC Escaping (Zero Injection Vulnerability):**
   - Subnegotiation frame builder and socket writer strictly double any `0xFF` byte to `0xFF 0xFF`.
   - Dimension inputs are clamped to RFC 1073 valid bounds `1..65535` (falling back to 80x24 defaults if <= 0).
3. **Dynamic Terminal Window Resize Notification:**
   - Decoupled `ActiveSessionState.onWindowResize` interface binds both SSH and Telnet terminal resize handlers.
   - Dispatches debounced (100ms) resize events to remote server to prevent network saturation during orientation or pinch-zoom changes.

## Verification Proof
- `TelnetNawsSecurityTest.kt`: Unit tests verifying dimension clamping, payload structure, RFC 854 byte doubling on wire (including edge cases width=255 and width/height=65535), and RFC 1143 loop suppression.
- `TelnetResizeDebounceTest.kt`: Integration test verifying 100ms window resize debounce and mock Telnet NAWS subnegotiation frame capture.
- `TelnetConnectionHandlerCoverageTest.kt`: Full lifecycle tests for Telnet connection handling.
