# User Story: SSH-245 - JuiceSSH Feature Parity & UI Wiring

**As a mobile systems administrator transitioning from JuiceSSH to CoSSH,**
I need full parity in connection organization, file transfer accessibility, terminal input customization, background longevity, and session multitasking,
**so that** I can seamlessly manage production server infrastructure without regression in capability, convenience, or security.

## Acceptance Criteria

1. **Folder & SortOrder Retention:**
   - When editing or creating a connection profile in `AddEditProfileScreen`, the user must be able to specify a folder/group.
   - The `AddEditProfileViewModel` must not strip `folderId` or `sortOrder` when loading an existing profile or saving back to encrypted storage.
   - Password fields must strictly configure `KeyboardOptions(autoCorrect = false, keyboardType = KeyboardType.Password)`.

2. **SFTP Browser Integration:**
   - Each SSH connection card in the connection list dropdown menu must present an "SFTP Browser" option.
   - Invoking "SFTP Browser" must navigate to `sftpBrowser?profileId={profileId}`.
   - The browser route in `AppNavigation` must connect through `SshjSftpClientAdapter` when an active SSH client session exists, falling back safely to `FakeSftpClientAdapter` when offline.

3. **Terminal Input, Font & Clipboard Customization:**
   - The user must be able to select the default Extra Keys preset (Default, Vim Coding, Tmux, Navigation) in Settings, and have it reflected in active terminal sessions.
   - The user must be able to adjust the global terminal font size in Settings with immediate persistence.
   - The user must be able to toggle OSC 52 clipboard access in Settings (defaulting to false for clipboard security).
   - The terminal input connection must set `IME_FLAG_NO_PERSONALIZED_LEARNING` to prevent mobile keyboards from learning and leaking sensitive CLI commands or tokens.

4. **Background Longevity & Notification Privacy:**
   - Active SSH sessions must acquire an Android CPU `PARTIAL_WAKE_LOCK` (`CoSSH::SessionWakeLock`) with safety timeout to prevent Android DOZE mode from dropping live connections while running in the background.
   - All foreground service notifications (summary and per-session) must enforce `NotificationCompat.VISIBILITY_PRIVATE` so sensitive hostnames and connection statuses are redacted on locked screens.

5. **Collapsible Host Groups & Multitasking Tab Bar:**
   - Connection group headers in the main connection list must support expanding and collapsing by tapping the header.
   - The connection list search bar must match against folder names as well as hostnames and nicknames.
   - The terminal session tab bar must remain accessible when only a single session is active so that users can tap "+ Connect" to open and manage concurrent sessions.
