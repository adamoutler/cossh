# User Story: SSH-232 — Implement Real-Time On-Screen Connection Diagnostic Log Stream Overlay

## User Story
**As an SSH terminal user and systems administrator,**  
**I need** to see real-time streaming connection logs on screen while connecting (similar to JuiceSSH's connecting screen), showing DNS resolution, TCP handshake, SSH protocol banner exchange, KEX algorithm negotiation, host key verification fingerprint, offered authentication methods, and partial authentication events,  
**So that** I have immediate visibility into connection progress, stalls, or handshake errors.

---

## Acceptance Criteria
1. **Thread-Safe Log Repository:** Create `ConnectionLogRepository.kt` providing a per-session ring buffer (150 entries max) emitting `StateFlow<List<ConnectionLogEntry>>` with millisecond timestamps, severity levels, and category tags.
2. **Subsystem Log Emitters:** Wire `SshHandshakeCoordinator.kt`, `SshConnectionManager.kt`, and `SshService.kt` to pipe connection milestones (`[DNS]`, `[TCP]`, `[SSH]`, `[KEX]`, `[HOSTKEY]`, `[AUTH]`, `[MFA]`, `[CHANNEL]`, `[READY]`, `[ERROR]`) into `ConnectionLogRepository`.
3. **Material 3 Connecting Overlay:** Create `ConnectingLogOverlay.kt` rendering:
   - Animated connection status indicator with host nickname/IP.
   - Monospace typography on dark obsidian terminal surface with auto-scrolling log lines.
   - "Copy Diagnostics" action button with haptic feedback.
4. **Paparazzi UI Snapshot:** Headless snapshot test in `ConnectingLogOverlayScreenshotTest.kt` verifying dark/light theme and error state rendering, committed to `docs/qa/SSH-232-connecting-logs.png`.
5. **Unit Tests:** Comprehensive unit tests in `ConnectionLogRepositoryTest.kt` verifying ring-buffer bounding, StateFlow emissions, formatted transcripts, and thread safety.
6. **Zero-Tolerance Quality:** Zero compiler warnings, strictly safe typing, and zero unhandled exceptions.

---

## Technical Details
- **Obsidian Terminal Container:** `#0B0F19` background with `#00D2FF` cobalt accents and colored milestone chips.
- **Haptic Diagnostics Export:** Copy button copies formatted transcript to clipboard via `SecureClipboardManager` and performs `KEYBOARD_TAP` haptic feedback.
- **Non-blocking Terminal Integration:** Floats seamlessly above `TerminalView` while connecting, automatically fading out upon `ConnectionState.Connected` and staying visible upon connection failure for instant diagnostics.
