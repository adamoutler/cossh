# User Story: SSH-241 — Software Supply Chain Security, SLSA v1.0 Provenance & Byte-for-Byte Reproducible Builds

## Epic
**SSH-188**: [EPIC] Security Differentiators — "Most Secure SSH Client on Android"

## User Story
**As a** paranoiac Android security architect and open-source software auditor,  
**I need** CoSSH to enforce SLSA v1.0 Level 3 in-toto build provenance and guarantee byte-for-byte reproducible APK/AAB builds with F-Droid verification compatibility,  
**So that** users and independent third-party auditors can cryptographically verify that distributed release binaries match the public Git source code bit-for-bit without hidden compiler tampering or build supply chain poisoning.

## Acceptance Criteria
1. **Compiler Warning Elimination (`SshfpVerifier.kt` & `PasswordCipher.kt`):**
   - In `SshfpVerifier.kt`, validate DNS RR class `rrClass == CLASS_IN` and enforce `require(hostname.isNotBlank())` to eliminate unused variable/parameter compiler warnings.
   - In `PasswordCipher.kt`, invoke `setUserAuthenticationParameters(300, KeyProperties.AUTH_BIOMETRIC_STRONG or KeyProperties.AUTH_DEVICE_CREDENTIAL)` on API 30+ (Android R) and suppress deprecation on older APIs.
2. **SLSA v1.0 & in-toto v1 Provenance Engine (`SupplyChainVerifier.kt`):**
   - Implement in-toto v1 Statement (`https://in-toto.io/Statement/v1`) schema with SLSA v1.0 (`https://slsa.dev/provenance/v1`) predicate serialization and parsing.
   - Implement `generateProvenance` and `generateProvenanceJson` capturing artifact digest, builder ID, build type, invocation ID, external parameters, and resolved dependency digests.
   - Implement `validateProvenance` checking schema URIs, subject non-emptiness, artifact SHA-256 match, and builder ID match.
   - Implement `computeSha256(ByteArray)` and `computeSha256(File)` returning 64-character lowercase hexadecimal hashes.
3. **Deterministic Archive Reproducibility Engine (`SupplyChainVerifier.kt` & `app/build.gradle.kts`):**
   - Configure Gradle `AbstractArchiveTask` in `app/build.gradle.kts` with `isPreserveFileTimestamps = false` and `isReproducibleFileOrder = true`.
   - Implement `verifyZipReproducibility(zipBytes, expectedNormalizedTimeMillis)` verifying:
     - Strict lexicographical ordering of archive entries.
     - Uniform normalized DOS timestamps across all entries within 2-second resolution tolerance.
     - Emits structured `ReproducibilityReport` with issue descriptions upon out-of-order or unnormalized entries.
4. **F-Droid Verification Specification (`metadata/com.adamoutler.cobaltssh.yml`):**
   - Author declarative F-Droid YAML manifest specifying repository, build steps, unsigned APK outputs, and `reproducible: true`.
5. **Architectural Whitepaper:**
   - Update Section 9 summary matrix and author Section 10 in `docs/security-whitepaper.md`.
6. **Zero-Tolerance Quality:**
   - 0 compiler warnings, 0 Detekt issues, 100% test pass.
