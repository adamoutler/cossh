# User Story: SSH-179 - Antigravity QA Gate — Operational, Bypass-Proof Ticket Closure

**As an Android Systems Architect,**
I need an uncompromising, zero-trust automated QA Gate in the Antigravity environment,
**so that** Kanban tickets can only transition to `Done` when code is clean, pushed, verified by CI/CD on Dash, certified by an out-of-band reality-checker AI evaluation (Pattern B), and protected against agent frustration loops and bypass maneuvers.

## Acceptance Criteria
1. **PreToolUse Interception:** Intercepts `call_mcp_tool`, eager tools (`mcp_kanban_*`), and macros attempting to transition tickets to `Done` or `Completed`.
2. **CLI Shield (`check_cli_bypass`):** Traps and rejects `run_command` invocations attempting direct Kanban database mutations via `curl`, `wget`, `gh`, `plane`, `python`, `node`, `ruby`, or reading `KANBAN_API_KEY` / `mcp_config.json`.
3. **Anti-Frustration Defenses:**
   - 30-second rate-limit cooldown per ticket ID.
   - 3-strike circuit breaker keyed on `(ticket_id, tree_hash)` preventing retry loops and empty-commit evasion.
   - Non-blocking POSIX concurrency lock (`/tmp/qa-gate.lock`).
4. **5-Stage Verification Pipeline:**
   - Stage 1: Clean git working tree (`git status --porcelain`).
   - Stage 2: Upstream tracking branch verified and up to date (`git log @{u}..HEAD`).
   - Stage 3: CI/CD workflow and hook integrity (`git diff origin/main...HEAD .github/workflows/ .agents/hooks/`).
   - Stage 4: Dash CI build status succeeded and cryptographically bound to HEAD commit SHA (`github/adamoutler/cossh/CI`).
   - Stage 5: Pattern B clean-room out-of-band evaluation with `reality-checker` (>200 chars, `READY` verdict required, `NEEDS WORK` / `FAIL` rejected).
5. **Kanban Commenting:** Full reality-checker certification report is automatically posted as an HTML comment on the ticket via Kanban API.
6. **Automated Verification:** 100% test coverage of the QA Gate via `.agents/tests/test_qa_gate.py` runnable under both `pytest` and `unittest`.

## Verification Proof
To satisfy the reality-checker, proof is explicit, artifact-based, and committed:
* Comprehensive test suite in `.agents/tests/test_qa_gate.py` passing 100% of tests.
* Certification documentation committed in `docs/qa/SSH-179.md`.
