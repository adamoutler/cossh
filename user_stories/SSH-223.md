# User Story: SSH-223 — Material 3 SFTP File Browser Screen, Breadcrumb Navigation & In-App Text Preview Modal

## Epic
**SSH-187**: [EPIC] Power Features — SFTP, Mosh, Automation, Accessibility

## User Story
**As a** mobile administrator navigating remote server filesystems,
**I want** a Material 3 SFTP file browser with interactive breadcrumb navigation, sorting, multi-selection, file permission editor dialog, and a secure in-app text preview modal (bounded to 2MB to prevent memory exhaustion),
**So that** I can inspect, navigate, and organize remote server files directly from my phone.

## Acceptance Criteria
1. **Material 3 SFTP File Browser (`SftpBrowserScreen.kt` & `SftpBrowserViewModel.kt`):**
   - Top App Bar with active profile nickname, current path breadcrumb bar allowing direct tap navigation to any parent directory segment, and real-time search filter input.
   - File/Directory List items: item icon (Folder, File, Symlink, Code, Archive), filename, formatted file size (Bytes, KB, MB, GB), human-readable POSIX permission chip (e.g. `rwxr-xr-x`), and modified date.
   - Empty state indicator ("Directory is empty") and error banner with retry option.
   - Sort bottom sheet / menu: Name (A-Z, Z-A), Size (Asc, Desc), Date Modified (Newest, Oldest), Folders First toggle.
2. **Contextual Multi-Select Top Bar & File Actions:**
   - Multi-select mode triggered by long-press: selected item count, Download action, Delete action (with confirmation dialog), and Select All.
   - Single item context menu: "Download", "Rename", "Permissions (chmod)", "Delete", and "View as Text".
   - **POSIX Permissions Editor Dialog (`SftpPermissionsDialog.kt`):**
     - Octal input and 3x3 checkbox matrix (User, Group, Others x Read, Write, Execute).
     - Live octal calculation (`0755`, `0644`) with instant validation.
3. **In-App Text Viewer Modal (`SftpTextViewerModal.kt`):**
   - Stream remote file preview into read-only scrollable text modal.
   - **Memory Guard:** Enforce strict 2MB ceiling. If remote file exceeds 2MB, display warning card: "File is too large for preview (> 2MB). Download to view externally."
   - Monospace font rendering with dark/light theme support and TalkBack accessibility.
4. **Visual Proof & Paparazzi:**
   - Headless snapshot tests in `SftpBrowserScreenScreenshotTest.kt` capturing directory list, breadcrumbs, permissions dialog, and text preview modal.
5. **Zero-Tolerance Quality:**
   - Zero compiler warnings, strictly safe typing, no unhandled exceptions.
