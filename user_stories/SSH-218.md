# User Story: SSH-218 — Hardened Terminal URL Detection, Strict URI Sanitization, and Secure Confirmation Modal

## Epic
**SSH-186**: [EPIC] Terminal Experience

## User Story
**As an** SSH terminal user,
**I want** CoSSH to detect valid web URLs in terminal output and prompt me with a secure confirmation dialog before opening them in a browser,
**So that** deceptive schemes, homoglyph attacks, and malicious links cannot compromise my device.

## Acceptance Criteria
1. **Hardened URL Detection & Sanitization Core (`TerminalUrlSanitizer.kt`):**
   - Extract URLs bounded to max 2048 chars matching strict HTTP/HTTPS regex.
   - Strip all Unicode Bidi overrides (`\u202A`–`\u202E`, `\u2066`–`\u2069`) and ASCII control characters before display.
   - Enforce dual RFC parser agreement (`android.net.Uri.parse` and `java.net.URI`). Reject all non-HTTP/HTTPS schemes (`file:`, `content:`, `intent:`, `javascript:`, `data:`, etc.).
   - Reject URLs with userinfo/authority injection (`@`).
   - Detect IDN Punycode hostnames (`xn--`) and confusable homoglyphs.
   - Cleanly strip trailing punctuation attached to URLs in terminal transcripts (`)`, `]`, `}`, `.`, `,`, `;`, `:`, `'`, `"`).
2. **Material 3 Anti-Phishing Confirmation Bottom Sheet (`UrlConfirmationBottomSheet.kt`):**
   - Enforce `FLAG_SECURE` on containing window while displayed.
   - Prominently display destination registered host in high-contrast bold font, demoting path and query strings.
   - Display prominent security warning banners for plain HTTP cleartext, raw IP addresses (no cert parity), and IDN Punycode lookalike domains.
   - Dual actions: "Copy Link" (with SecureClipboardManager 30s auto-clear) and "Open Link".
   - Default action focused on "Cancel".
3. **Terminal Tap & Long-Press Integration (`TerminalScreen.kt`):**
   - Hook into `TerminalViewClient.onSingleTapUp` and `onLongPress` using `TerminalView.getColumnAndRow(e, true)` and `session.emulator.screen.getWordAtLocation`.
   - Dispatch to `UrlConfirmationBottomSheet`.
   - Launch validated URL via `Intent(Intent.ACTION_VIEW, sanitizedUri)` with `Intent.CATEGORY_BROWSABLE` wrapped in chooser with error handling (`ActivityNotFoundException`).
4. **Zero-Tolerance Quality:**
   - Zero compiler warnings, strictly safe typing, no unhandled exceptions, and $\ge 80\%$ test coverage.
