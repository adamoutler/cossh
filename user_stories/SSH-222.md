# User Story: SSH-222 — Hardened SFTP Client Engine with Strict Path Canonicalization & Traversal Guards

## Epic
**SSH-187**: [EPIC] Power Features — SFTP, Mosh, Automation, Accessibility

## User Story
**As a** systems administrator managing remote files over secure shell connections,
**I want** a hardened, reactive SFTP client engine leveraging SSHJ's native subsystem with strict remote path canonicalization, symlink traversal guards, and atomic file transfer staging,
**So that** file operations and transfers execute reliably without exposing the device to directory traversal attacks or corrupting partial files upon network disruption.

## Acceptance Criteria
1. **SFTP Domain Models & Transfer Contracts (`com.adamoutler.ssh.sftp.model`):**
   - Create `SftpFileItem` data class: `name: String`, `fullPath: String`, `size: Long`, `isDirectory: Boolean`, `isRegularFile: Boolean`, `isSymlink: Boolean`, `permissions: String` (e.g. `drwxr-xr-x`), `octalPermissions: Int` (e.g. `0755`), `modifiedTimeEpochMs: Long`.
   - Create `SftpTransferState` sealed interface: `Idle`, `Transferring(bytesTransferred: Long, totalBytes: Long, speedBytesPerSec: Long, percent: Float)`, `Completed(bytesTransferred: Long)`, `Failed(throwable: Throwable)`.
2. **Hardened SFTP Manager Core (`SftpClientManager.kt`):**
   - Abstract underlying transport via `SftpClientAdapter` (with production `SshjSftpClientAdapter` wrapping SSHJ's native `SFTPClient` and zero-network `FakeSftpClientAdapter` for high-speed unit testing).
   - **Path Canonicalization & Directory Traversal Guards (`SftpPathValidator.kt`):**
     - Strict POSIX path canonicalization neutralizing `../`, `.\`, and null bytes (`\u0000`).
     - Bounds checking rejecting paths resolving outside allowed root.
   - Remote file operations: `listDirectory(path: String): List<SftpFileItem>`, `createDirectory(path: String)`, `delete(path: String, isDirectory: Boolean)`, `rename(oldPath: String, newPath: String)`, `setPermissions(path: String, permissions: Int)`, `stat(path: String)`.
3. **Atomic File Transfer Engine & Staging Guards:**
   - Stream incoming remote bytes to private staging files (`.cossh_part_<uuid>`) and execute atomic move (`Files.move(..., ATOMIC_MOVE, REPLACE_EXISTING)`) upon verified completion.
   - Immediate cancellation cleanup: orphaned staging files are reliably wiped on coroutine cancellation or failure.
   - Memory inspection guard: enforce 2MB maximum limit when previewing remote text files to prevent out-of-memory crashes.
4. **Automated Unit Test Coverage:**
   - Automated unit tests in `SftpPathValidatorTest.kt` verifying path canonicalization, traversal rejection, and null byte protection.
   - Automated unit tests in `SftpClientManagerSecurityTest.kt` verifying directory listing, atomic download staging and cleanup, cancellation hygiene, and 2MB inspection ceiling.
5. **Zero-Tolerance Quality:**
   - Zero compiler warnings, strictly safe typing, no unhandled exceptions.
