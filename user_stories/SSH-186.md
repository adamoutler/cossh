# User Story: SSH-186 — [EPIC] Terminal Experience

## Goal
Deliver polished, hardened terminal ergonomics matching and exceeding legacy clients (JuiceSSH, Termius, ConnectBot):
1. Replace generic Android notification icons with branded monochrome vector drawables for foreground sessions.
2. Implement bounded pinch-to-zoom font scaling (8sp to 32sp) with smooth threshold accumulation and density consistency.
3. Support terminal bell haptic tactile feedback and accurate hardware/virtual Shift modifier state tracking (`readShiftKey`).
4. Implement hardened terminal URL detection with Unicode Bidi stripping, dual RFC parser agreement, userinfo rejection, IDN Punycode detection, and `FLAG_SECURE` confirmation modals.
5. Engineer full VT100/xterm hardware keyboard modifier formulas, navigation keys, F1-F12 function chords, Backtab, and auto-reset of modifiers on focus loss.
6. Provide terminal cursor customization (Block, Underline, Vertical Bar) with blinking toggles and authentic 1 Hz square-wave animated preview in settings.
7. Deliver multi-session terminal tab strip with dedicated per-session output flows, flicker-free hot-swap switching, and zero-retention session teardown memory wiping.

## Acceptance Criteria
1. **Full Terminal Ergonomics & Parity**: All 7 constituent child tickets fully implemented, passing 100% of unit, integration, and UI screenshot tests.
2. **Security & Memory Hardening**:
   - Zero-retention memory scrubbing of session buffers, stream registries, and terminal screen line buffers on teardown.
   - Strict URI sanitization preventing command injection, homoglyph attacks, and untrusted browser intent dispatch.
   - Enforce 16-byte upper ceiling on generated hardware keyboard escape sequences.
3. **Artifact-Backed Verification**:
   - High-fidelity Paparazzi screenshot artifacts committed under `docs/qa/` for notification vector, font scales, URL sheet, cursor preview, and multi-session tabs.
   - Comprehensive test coverage with zero warnings, strictly safe typing, and zero unhandled exceptions.
