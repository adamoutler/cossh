# User Story: SSH-211 - Hardened OpenSSH Config Importer with Strict Directive Allowlist & Traversal Neutralization

**As a DevOps engineer migrating existing SSH infrastructure from desktop or server environments,**
I want to import OpenSSH `~/.ssh/config` files securely into CoSSH,
**so that** multi-host configurations are ingested seamlessly without exposing the app to arbitrary command execution (RCE) or path traversal vulnerabilities.

## Acceptance Criteria
1. **Strict Directive Allowlist (`OpenSshConfigParser`):**
   - Parse standard OpenSSH directives: `Host`, `HostName`, `User`, `Port`, `IdentityFile`, `ProxyJump`.
   - Strictly ignore/neutralize all arbitrary execution directives (`ProxyCommand`, `LocalCommand`, `PermitLocalCommand`, `Match exec`).
   - Validate port ranges (1..65535) and default to 22.
2. **Path Traversal Neutralization & Key Matching:**
   - Neutralize directory traversal attempts in `IdentityFile` paths (e.g. `../../etc/passwd` or `~/.ssh/id_ed25519`) by extracting strictly sanitized base filenames.
   - Associate matching `IdentityProfile` records by base key name.
3. **Hardened Input Bounds & DoS Prevention:**
   - Cap configuration file size at 256 KB.
   - Limit individual line length to 4,096 characters to prevent ReDoS / memory thrashing.
   - Bound total parsed host definitions to 250 entries to safeguard local encrypted database.
4. **Interactive Conflict Resolution & Import Summary UI:**
   - Provide "Import OpenSSH Config" action in connection list overflow menu using Android Storage Access Framework (SAF).
   - Display conflict resolution dialog when duplicate nicknames exist (allowing Skip or Rename options).
   - Display post-import summary dialog detailing successfully imported, renamed, and skipped profile counts.
5. **Zero-Tolerance Quality:**
   - Zero compiler warnings, strictly safe typing, no unhandled exceptions.
   - Comprehensive unit and Paparazzi UI screenshot tests.
