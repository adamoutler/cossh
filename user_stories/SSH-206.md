# User Story: SSH-206 - Cloud Restore UI, Disable Sync & Zero-Knowledge Passphrase Storage

**As a security-conscious CoSSH user,**
I want a dedicated Cloud Restore flow, a clean sync disable toggle with optional remote backup deletion, and zero-knowledge in-memory handling of my sync passphrase,
**so that** I can restore my encrypted profiles on a new device, disable cloud sync at will without leaving orphan remote data, and be guaranteed my passphrase never exists as an unmanaged heap String.

## Acceptance Criteria
1. **Zero-Knowledge Passphrase Memory Sanitization:** `SecurityStorageManager.saveSyncPassphrase` and `getSyncPassphrase` encode and decode between `CharArray` and `ByteArray` directly using NIO `CharBuffer`, `ByteBuffer`, and `StandardCharsets.UTF_8` with explicit buffer zero-wiping (`Arrays.fill`, `fill('\u0000')`) in `finally` blocks, never creating an immutable heap `String(passphrase)`. Added `clearSyncPassphrase()` for secure credential purging.
2. **Global Sync State Persistence:** `SettingsManager` manages `isCloudSyncActive` boolean preference (default `true`), allowing users to toggle background sync without losing their encrypted profiles.
3. **Interactive Settings Controls & Dialogs:** `SettingsScreen` replaces the legacy TODO placeholder with an active Switch toggle, adds `DisableSyncConfirmationDialog` with an option to purge remote Google Drive backups, adds `RestorePassphraseDialog`, a "Restore from Cloud" button, and status banner messaging.
4. **SettingsViewModel Cloud Sync Workflow:** `SettingsViewModel` implements:
   - `enableCloudSync()` to activate sync in settings and state.
   - `disableCloudSync(deleteRemoteBackup: Boolean)` to cancel the unique WorkManager task (`"cossh_cloud_sync"`), clear stored passphrase from Keystore, update settings, and optionally invoke `DriveSyncManager.deleteBackup()`.
   - `restoreFromCloud(passphrase)` to fetch the remote backup, import profiles and identities via `BackupCryptoManager.importProfilesFromZip`, save them to secure storage, and zero-wipe the input passphrase buffer in `finally`.
5. **ARM64 & WorkManager Resilience:** `SettingsViewModel` injects optional `WorkManager?` to prevent native SQLite missing-binary crashes on ARM64 Linux hosts during headless unit tests.
