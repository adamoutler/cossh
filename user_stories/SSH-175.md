# User Story: SSH-175 - Implement Dynamic Port Forwarding (SOCKS Proxy)

**As an administrator,**
I need to configure Dynamic Port Forwarding (SOCKS Proxy) in my SSH profiles,
**so that** I can route arbitrary application traffic securely through my remote server.

## Acceptance Criteria
1. **Data Model Extension:** Extend `PortForwardType` enum to include `@SerialName("DYNAMIC") DYNAMIC` with robust serialization and deserialization.
2. **Segmented Control in Dialog:** Update `AddEditProfileScreen` Port Forwarding Dialog to include a `Dynamic` option in the segmented control.
3. **Conditional Remote Field Visibility:** When `DYNAMIC` is selected, automatically hide the `Remote Host` and `Remote Port` text fields.
4. **Security Risk Notice:** Display an explicit warning `Card` when `Dynamic` is selected regarding the risks of an open proxy (`⚠️ Warning: This turns your device into a proxy. Ensure the port is not exposed to untrusted networks.`).
5. **SOCKS5 Network Engine:** Update the `PortForwardingOrchestrator` to handle dynamic port forwarding correctly using SSHJ direct-tcpip channels and RFC 1928 SOCKS5 handshake processing.
6. **Accessibility Semantics:** TalkBack announces the definition and risks of "Dynamic" port forwarding when selected via `liveRegion = LiveRegionMode.Polite`.
