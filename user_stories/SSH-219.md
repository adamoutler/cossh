# User Story: SSH-219 — Hardware Keyboard VT100/xterm Key-Mapping Engine with Focus Loss Auto-Reset

## Epic
**SSH-186**: [EPIC] Terminal Experience

## User Story
**As a** developer using a physical hardware keyboard on Android (tablet, DeX, or Chromebook),
**I want** complete VT100/xterm key mapping (Ctrl+Key, Alt+Key, modified arrows, and function keys F1-F12) without stuck modifiers or memory leaks,
**So that** my terminal workflow in vim, tmux, and CLI tools is identical to a desktop workstation.

## Acceptance Criteria
1. **ANSI Hardware Key Mapper Engine (`TerminalAnsiKeyMapper.kt` & `TerminalKeyMapper.kt`):**
   - Calculate xterm modifier parameters: `1 + (Shift * 1) + (Alt * 2) + (Ctrl * 4)`.
   - Fix hardware Alt modifier bug: inspect `e?.isAltPressed == true` in conjunction with `getAltState().isActive` across all key processing pathways in `TerminalKeyMapper.kt`.
   - Implement navigation key mapping (Up, Down, Left, Right, Home, End, PgUp, PgDn, Ins, Del) with modifier support.
   - Implement function keys F1-F12 with modifiers (SS3 for unmod F1-F4, CSI for F5-F12 and modified F-keys).
   - Support `KEYCODE_ESCAPE` (`0x1B`) and `KEYCODE_TAB` with Shift (Backtab: `\u001B[Z`).
   - Enforce 16-byte upper ceiling on all generated escape sequences to prevent buffer overflow attacks.
2. **Zero Heap-String Keystroke Engine:**
   - Translate single-byte ANSI control codes (`Ctrl+A`..`Ctrl+Z` -> `0x01`..`0x1A`) and UTF-8 multi-byte characters directly into `ByteArray` without allocating intermediate heap `String` objects.
   - Synchronize physical Shift key presses and releases (`KEYCODE_SHIFT_LEFT`, `KEYCODE_SHIFT_RIGHT`) with `readShiftKey()`.
3. **Focus Loss Modifier Auto-Reset:**
   - On `TerminalView.onWindowFocusChanged(false)` and composable disposal, automatically reset all hardware modifiers (`hardwareShiftPressed`, `hardwareCtrlPressed`, `hardwareAltPressed`) and sticky virtual states to `INACTIVE`.
4. **Zero-Tolerance Quality:**
   - Zero compiler warnings, strictly safe typing, no unhandled exceptions, and $\ge 80\%$ test coverage.
