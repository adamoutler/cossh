# User Story: SSH-213 - Multi-Challenge Keyboard-Interactive & PAM (2FA TOTP) Authentication with Memory Sanitization

**As an Android systems engineer logging into hardened enterprise SSH bastions protected by multi-factor authentication (MFA/2FA),**
I want CoSSH to prompt me sequentially for interactive keyboard-interactive PAM challenges (e.g. PAM Password, Duo/TOTP codes) with zero-retention memory sanitization and echo protection,
**so that** I can authenticate seamlessly to 2FA-secured infrastructure without my one-time tokens or credentials remaining exposed in memory or displayed in cleartext.

## Acceptance Criteria
1. **Interactive PAM Challenge-Response Coordinator (`KeyboardInteractiveAuthenticator` & `UserPromptRegistry`):**
   - Intercept SSHJ keyboard-interactive challenges (`AuthKeyboardInteractive` via `createChallengeResponseProvider`).
   - Support multiple sequential prompt rounds (e.g., password prompt followed by 2FA / TOTP challenge).
   - Enforce bounded challenge round safety (max 5 rounds; abort with `UserAuthException` if server loops).
   - Support cancellation from user prompt dialog aborting handshake cleanly.
2. **Volatile Memory Sanitization & Input Masking:**
   - Prompt responses stored and handled ephemerally as `CharArray` / `CharBuffer`.
   - Explicit zero-wiping (`Arrays.fill(response, '\u0000')`) in `finally` blocks upon completion or failure.
   - Intelligent heuristic echo safeguard: if server requests echo (`echo = true`) but prompt text contains sensitive tokens (`password`, `passcode`, `pin`, `token`, `secret`, `verification code`, `totp`), force password visual masking (`PasswordVisualTransformation`).
   - Sanitize server prompt text by stripping ANSI escape sequences and bidirectional Unicode override characters (`\u202A`..`\u202E`, `\u2066`..`\u2069`).
3. **Material 3 PAM Challenge Dialog (`PamAuthDialog`):**
   - Material 3 dialog with `FLAG_SECURE` window policy to prevent screen capture / task snapshotting.
   - IME privacy enforcement (`IME_FLAG_NO_PERSONALIZED_LEARNING`).
   - Clear instructional banner, prompt badge indicating challenge round (`Round $round`), and TalkBack accessibility semantics.
4. **Zero-Tolerance Quality:**
   - Zero compiler warnings, strictly safe typing, no unhandled exceptions.
   - Comprehensive unit and Paparazzi UI screenshot tests.
