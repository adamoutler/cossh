# User Story: SSH-225 — Home-Screen Dynamic Shortcuts, Quick Connect Launcher & Biometric-Gated IPC

## Epic
**SSH-187**: [EPIC] Power Features — SFTP, Mosh, Automation, Accessibility

## User Story
**As a** power user connecting frequently to production and homelab servers,
**I want** home-screen dynamic shortcuts for my favorite SSH profiles, with strict intent validation and mandatory biometric App Lock gating,
**So that** I can launch sessions in one tap while guaranteeing third-party apps cannot trigger unauthorized connections or bypass the app lock.

## Acceptance Criteria
1. **Dynamic Launcher Shortcuts (`ShortcutManagerCompat`):**
   - Provide "Add to Home Screen" action in `ConnectionItem` and `ConnectionListScreen`.
   - Publish dynamic launcher shortcuts via `ShortcutManagerCompat.pushDynamicShortcut` with profile nickname, host, and branded CoSSH protocol icon (`R.drawable.ic_shortcut_ssh`).
   - Limit dynamic shortcuts to max 4 profiles per Android OS guidelines.
2. **Hardened Intent Receiver in `IntentSanitizer.kt`:**
   - Define `ACTION_LAUNCH_PROFILE = "com.adamoutler.ssh.LAUNCH_PROFILE"`.
   - Strictly validate `EXTRA_PROFILE_ID` against alphanumeric regex (`^[a-zA-Z0-9_-]{1,64}$`) and require verification against stored `SecurityStorageManager.getProfile(profileId)`.
   - **Zero External Command Injection:** Explicitly reject and ignore any external intent extras attempting to pass ad-hoc hostnames, ports, passwords, or shell command strings. All parameters must originate exclusively from encrypted internal storage.
3. **Biometric App Lock Invariant:**
   - If `AppLockManager.isLocked.value == true`, any incoming shortcut or automation intent must be buffered in `AppLockManager.pendingResumeIntent`.
   - The connection MUST NOT open or unseal credentials until `MainActivity` completes successful biometric/credential unlock via `BiometricPrompt.CryptoObject`.
4. **Automated Test Coverage & Paparazzi:**
   - Unit tests in `ShortcutIntentSanitizerTest.kt` verifying shortcut intent dispatch, parameter sanitization, profile ID lookup, and rejection of ad-hoc command injections.
   - Unit tests in `ShortcutAppLockIntegrationTest.kt` verifying that shortcut intents are queued while locked and only executed after biometric authentication.
   - Paparazzi screenshot artifact `docs/qa/SSH-225-shortcut-menu.png` showing the "Add to Home Screen" action and shortcut preview.
5. **Zero-Tolerance Quality:**
   - Zero compiler warnings, strictly safe typing, no unhandled exceptions.
