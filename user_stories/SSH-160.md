# User Story: SSH-160 - Implement Smart Keep Screen On Configuration for Terminal

**As a system administrator,**
I need a connection-specific option to keep my terminal screen awake during active data streams or while I'm holding the device,
**so that** I don't have to constantly tap the screen during long-running tasks, without compromising security when the phone is in my pocket.

## Acceptance Criteria
1. **Connection Profile Configuration:** Add `keepScreenOnMode` enum property (`SYSTEM_DEFAULT`, `SMART_AWAKE`, `ALWAYS_ON`) to `ConnectionProfile` data class with full persistence.
2. **UI Controls:** Provide segmented options for Display Modes (`System`, `Smart`, `Always On`) in `AddEditProfileScreen` and the Terminal long-press settings menu.
3. **Pocket-Dial Vulnerability Protection:** Proximity sensor integration (`ProximitySensorManager`) automatically clears `FLAG_KEEP_SCREEN_ON` whenever the sensor reports `isNear = true`, even if `ALWAYS_ON` is active.
4. **Smart Awake Mode:** Keeps screen awake only when `isDataFlowing == true` and device is not in pocket (`!isProximityNear`).
5. **System Default Mode:** Respects standard Android OS sleep and timeout configurations (`FLAG_KEEP_SCREEN_ON` cleared).
