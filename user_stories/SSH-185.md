# User Story: SSH-185 — [EPIC] Connectivity Parity (keepalive, reconnect, jump hosts, import/export)

## Goal
Reach full connectivity parity with JuiceSSH and Termius across mobile networking and bastion infrastructure:
1. Configurable cryptographic SSH keepalives and dead-peer detection (`ServerAliveInterval`, `ServerAliveCountMax`) preventing carrier NAT drops.
2. Hardened auto-reconnect on network change with truncated exponential backoff, connectivity pause, instant circuit breakers on auth rejection, and zero-prompt background TOFU guards.
3. Isolated multi-hop Jump Host (ProxyJump) architecture via direct-tcpip chaining with double-blind TOFU host key verification and strict DAG cycle/loop rejection.
4. Ephemeral Quick Connect bottom sheet supporting `[user@]host[:port]` ad-hoc sessions with zero-persistence guarantees, session-only TOFU caching, and volatile memory sanitization.
5. Storage Access Framework (SAF) OpenSSH `~/.ssh/config` importer with strict directive allowlists, RCE vector rejection (`ProxyCommand`, `LocalCommand`), directory traversal neutralization on `IdentityFile`, and conflict resolution dialogs.
6. RFC 1073 Telnet NAWS window size subnegotiation with mandatory RFC 854 IAC escaping (`0xFF` doubling) and RFC 1143 Q-method loop guards.
