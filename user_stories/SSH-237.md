# User Story: SSH-237 — Extra Keys Presets (tmux, Vim, Navigation), Tmux Action Helpers, Accessibility Live Regions & Mosh Architectural Spike

## Goal
Empower mobile terminal operators with high-efficiency keyboard row presets (`DEFAULT`, `VIM_CODING`, `TMUX`, `NAVIGATION`), automated tmux multiplexer action bindings with selectable prefix keys, sanitized TalkBack live-region announcements for terminal transcripts and modifier states, and an authoritative architectural spike evaluating Mosh (Mobile Shell) UDP state synchronization for CoSSH.

## Background & Problem Statement
1. **Mobile Keyboard Ergonomics:** On-screen Android keyboards lack crucial control keys (Esc, Tab, Ctrl, Alt, brackets, pipes) essential for Vim and terminal multiplexers. Operators require context-aware extra key presets that can be swapped or serialized cleanly.
2. **Tmux Multiplexing Friction:** Executing tmux commands on touch devices requires complex multi-key combinations (`Ctrl-B` followed by punctuation or arrows). A dedicated helper is required to emit exact, prefix-aware byte sequences for pane splits, zooming, window lifecycle, and navigation.
3. **Screen Reader Accessibility (TalkBack):** Raw terminal transcripts contain extensive ANSI escape codes (CSI, OSC, 24-bit colors, cursor coordinates) that corrupt TalkBack speech. Terminal output must be stripped of residual escape codes, bounded for polite live-region announcements, and modifier latch transitions (`Active: Off`, `Sticky`, `Locked`) must be clearly articulated.
4. **Cellular Network Fragility (Mosh Spike):** Mobile connections suffer from IP roaming, packet loss, and aggressive CGNAT firewall timeouts. A comprehensive architectural spike is required to evaluate Mosh (Mobile Shell) over UDP with AES-128-OCB, Android 15+ 16KB ELF page alignment, and Doze mode mitigations.

## Scope & Deliverables
- **`ExtraKeysPreset.kt`**:
  - `ExtraKeysPresetId`: Enumeration of presets (`DEFAULT`, `VIM_CODING`, `TMUX`, `NAVIGATION`).
  - `ExtraKeySpec`: Serializable data model for terminal key definitions.
  - `ExtraKeysPresets`: Preset configurations, validation engine (`validateKeySpec`, `validatePreset`), and JSON round-trip serialization (`serializePreset`, `deserializePreset`).
- **`TmuxActionHelper.kt`**:
  - `TmuxPrefix`: `CTRL_B` (0x02) and `CTRL_A` (0x01).
  - `TmuxCommand`: Actions for `SPLIT_HORIZONTAL`, `SPLIT_VERTICAL`, `PANE_UP`, `PANE_DOWN`, `PANE_LEFT`, `PANE_RIGHT`, `ZOOM_TOGGLE`, `NEW_WINDOW`, `NEXT_WINDOW`, `PREV_WINDOW`, `DETACH_SESSION`, `KILL_PANE`.
  - `buildCommandBytes`: Generates exact prefix and suffix byte sequences for PTY injection.
- **`TerminalAccessibilityHelper.kt`**:
  - `stripAnsiControlCodes`: Cleans ANSI CSI, OSC, and non-printable control characters.
  - `extractAccessibleLines`: Extracts up to `maxLines` of visible sanitized transcript text.
  - `buildModifierAnnouncement`: Formats TalkBack announcements for `Active: Off`, `Sticky`, and `Locked` states.
  - `buildOutputAnnouncement`: Formats polite, length-bounded live-region announcements.
- **`docs/architecture/mosh-spike.md`**:
  - In-depth architectural spike detailing Mosh State Synchronization Protocol (SSP), AES-128-OCB encryption, SSH bootstrap handshake, 16KB ELF alignment, CGNAT keepalives (20s), Doze mode mitigations, and phased roadmap.
- **Unit Test Suites**:
  - `ExtraKeysPresetTest.kt`: 100% test coverage across presets, bounds validation, JSON roundtripping, and accessibility helpers.
  - `TmuxActionHelperTest.kt`: 100% test coverage across all tmux commands, prefixes, and byte payloads.

## Acceptance Criteria
1. **Extra Keys Presets & Serialization**:
   - `ExtraKeysPresets.getPreset()` supplies valid 2-row layouts for all four preset identifiers.
   - `VIM_CODING` includes `Esc`, `:`, `/`, `|`, `~`, `Tab`, `{`, `}`.
   - `TMUX` includes `Ctrl-B`, `%`, `"`, `z`, `c`, `n`, `p`, `d`.
   - `NAVIGATION` includes `Home`, `End`, `PgUp`, `PgDn`, and directional arrows.
   - Serializing and deserializing presets via JSON preserves exact key specifications and catches malformed JSON or duplicate keys.
2. **Tmux Action Helper**:
   - Correctly prepends selected `TmuxPrefix` (`CTRL_B` or `CTRL_A`) to command suffix bytes.
   - Accurately generates byte sequences for horizontal splits (`"`), vertical splits (`%`), zoom toggle (`z`), window creation (`c`), and arrow navigation (`ESC [ A-D`).
3. **Accessibility Sanitization & TalkBack Live Regions**:
   - Strips ANSI escape sequences and OSC titles without dropping human-readable terminal content.
   - Correctly announces modifier latch states: `Active: Off` (Inactive), `Sticky`, and `Locked`.
   - Live region output truncated gracefully with ellipsis beyond `maxChars`.
4. **Mosh Architectural Spike**:
   - Fully documents State Synchronization Protocol (SSP), AES-128-OCB, SSH bootstrap parsing, 16KB page alignment (`-Wl,-z,max-page-size=16384`), CGNAT keepalive strategy, and four-phase rollout roadmap.
5. **Quality & Verification**:
   - All unit tests pass cleanly with zero warnings and zero regressions.
