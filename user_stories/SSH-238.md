# User Story: SSH-238 — OpenSSH known_hosts Bulk Porter (Import/Export & Conflict Detection)

## Epic
**SSH-188**: [EPIC] Security Differentiators — "Most Secure SSH Client on Android"

## User Story
**As a** system administrator managing dozens of remote servers,  
**I need** CoSSH to provide hardened bulk import and export capabilities for standard OpenSSH `known_hosts` files with bounded payloads, strict control-character neutralization, wire-format key validation, and automated conflict detection across plaintext and HMAC-SHA1 hashed hosts,  
**So that** I can securely seed or migrate trusted server fingerprints into CoSSH without risking Denial-of-Service, injection attacks, or silent host key substitutions (Man-in-the-Middle).

## Acceptance Criteria
1. **Hardened Resource Bounds & Input Sanitization (`KnownHostsBulkPorter.kt`):**
   - Enforces `MAX_PAYLOAD_BYTES = 1024 * 1024` (1 MB) for both string and `InputStream` sources.
   - Enforces `MAX_ENTRY_COUNT = 2000` entries per import batch.
   - Enforces `MAX_LINE_LENGTH = 8192` characters.
   - Strictly neutralizes and rejects lines containing unescaped control characters (`\r`, `\n`, `\u0000`, `\u001B`, `\u007F`).
   - Sanitizes exported and imported comments against control sequences.
2. **OpenSSH Wire-Format Public Key Validation:**
   - Implements `validatePublicKeyBlob(keyType: String, base64Blob: String): Boolean`.
   - Validates Base64 decoding, big-endian uint32 wire length header, matching key type identifier, and key material payload existence.
3. **Format & Marker Support:**
   - Parses standard plaintext `host[,ip]`, bracketed `[host]:port`, hashed OpenSSH HMAC-SHA1 `|1|salt|hash`, `@cert-authority`, and `@revoked` entries.
   - Updates `KnownHostRecord` with `val isRevoked: Boolean = false`.
4. **Conflict Resolution Strategies:**
   - Detects host key conflicts across both plaintext and HMAC-SHA1 hashed entries using `manager.matchesHost(...)`.
   - `STRICT_REJECT_CONFLICTS`: Aborts import (`isSuccess = false`) leaving `manager` completely untouched if any incoming key differs from an existing key for the host, returning full conflict details.
   - `SKIP_EXISTING`: Retains existing host keys, skipping conflicting entries, while importing new entries.
   - `OVERWRITE_CHANGED`: Overwrites conflicting keys in-place, preserving file comments.
5. **OpenSSH Export:**
   - Implements `exportToOpenSshFormat` (string and `OutputStream` overloads) preserving `@cert-authority`, `@revoked`, host patterns, key types, Base64 blobs, and sanitized comments.
6. **Automated Unit Tests:**
   - 100% test pass in `KnownHostsBulkPorterTest.kt` and `KnownHostsManagerTest.kt`.
   - Zero compiler warnings, 0 detekt code smells, safe typing, and complete exception safety.
