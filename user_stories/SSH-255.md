# User Story: SSH-255 - Release Artifact Hygiene, Disconnected SFTP Guard & Dead Code Purge

**As a DevSecOps engineer and Android Systems Architect preparing CoSSH for production release,**
I want test doubles, diagnostic scratch scripts, prototype screens, and root build test files purged from production artifacts, and the SFTP file browser safeguarded with a fail-fast `DisconnectedSftpClientAdapter`,
**so that** release APK/AAB outputs remain minimal, attack surfaces are minimized, mock adapters cannot inadvertently execute in production environments, and disconnected SFTP sessions display clear, actionable error states without regressions.

## Acceptance Criteria
1. **Disconnected SFTP Guard & Test Double Segregation (`DisconnectedSftpClientAdapter.kt` & `AppNavigation.kt`):**
   - Implemented `DisconnectedSftpClientAdapter` implementing `SftpClientAdapter` where all operations throw `IOException("SFTP client is not connected: active SSH session required")`.
   - In `AppNavigation.kt` (`sftpBrowser` route), replaced fallback instances of `FakeSftpClientAdapter()` with `DisconnectedSftpClientAdapter()`.
   - Segregated `FakeSftpClientAdapter.kt` exclusively into `app/src/test/kotlin/com/adamoutler/ssh/sftp/` to guarantee test doubles are never bundled in release binaries.
2. **Dead Code & Prototype Screen Purge:**
   - Removed obsolete `PlaceholderScreen()` composable from `MainActivity.kt` and purged `PlaceholderScreenScreenshotTest.kt` along with its snapshot.
   - Removed diagnostic script `ReflectionTest.kt` from `src/main`.
   - Purged dead prototype screen `KeyManagementScreen.kt` from `src/main`, removed its route and import from `AppNavigation.kt`, removed its navigation call from `AppNavigationCoverageTest.kt`, and deleted associated tests and snapshots.
   - Removed root scratch files `build.gradle.kts.test` and `test.gradle.kts`.
3. **Automated Verification & Zero Test Breakages:**
   - Unit tests in `DisconnectedSftpClientAdapterTest.kt` verifying all 9 operations throw `IOException`.
   - Architecture verification tests in `ReleaseArtifactHygieneVerificationTest.kt` ensuring zero test doubles or dead code exist in `src/main` and scratch files are absent.
   - 100% passing tests across the SFTP, navigation, and security suites.
