# User Story: SSH-252 — Advanced SSH Wheelhouse Adversarial Tests

## Goal
As a paranoiac Android security architect, I want comprehensive functional and adversarial tests covering all mission-critical advanced SSH wheelhouse subsystems (ProxyJump graph cycles, jump host target credential sanitization, biometric SSH-Agent wire security, FIDO2 hardware key wire parsing, SFTP traversal guards, and RFC 4252 multi-factor continuation), so that rogue bastions, malicious servers, and hostile wire packets cannot exploit the client, escape sandboxes, harvest private keys, or leak ephemeral credentials in mutable memory.

---

## Subsystem Architecture & Test Scope

### 1. Jump Host / ProxyJump Graph Validation (`JumpHostGraphValidator`)
- **Functional Validation**: Verify valid linear multi-hop bastion routing chains (`Client -> Bastion1 -> Bastion2 -> Target`) pass graph cycle validation without false positives.
- **Adversarial Validation**: Verify direct self-loops (`A -> A`), 2-node cycles (`A -> B -> A`), and 4-node transitive cycles (`A -> B -> C -> D -> A`) are detected and blocked immediately during candidate selection and graph validation.

### 2. Jump Host Target TOFU MITM Isolation & Ephemeral Credential Sanitization (`SshConnectionHandler` & `SshHandshakeCoordinator`)
- **Jump Host Failure Isolation**: When an upstream bastion profile is missing or connection fails, the target profile's ephemeral `password` byte array must be actively zero-wiped in memory (`all { it == 0.toByte() }`).
- **Target Handshake Rejection**: When target authentication or host key verification rejects credentials, both `ConnectionProfile.password` and `IdentityProfile` sensitive buffers (`password`, `privateKey`) must be actively zero-wiped.
- **Autonomous Reconnect TOFU Rejection**: During autonomous background reconnect (`isAutonomousReconnect = true`), `TofuHostKeyVerifier` strictly rejects changed host keys without prompting the user (Zero-Prompt Security Policy) and zeroes ephemeral credentials.

### 3. Biometric SSH-Agent Hardened Wire Security (`BiometricAuthAgentHandler`)
- **Key Harvesting Defense**: When profile identity whitelist is empty, key enumeration requests (`SSH2_AGENTC_REQUEST_IDENTITIES` = 11) strictly return 0 keys (`SSH2_AGENT_IDENTITIES_ANSWER` with count 0), preventing rogue servers from enumerating or harvesting identities.
- **Forward Loop Guard**: Forwarding beyond `MAX_ALLOWED_HOPS` (`1`) strictly aborts with framed failure `[0, 0, 0, 1, 5]` (`SSH_AGENT_FAILURE`).
- **Biometric Confirmation Bridge**: Sign requests (`SSH2_AGENTC_SIGN_REQUEST` = 13) return `SSH_AGENT_FAILURE` if `BiometricAgentConfirmationBridge` denies authorization or encounters an exception, and return valid `SSH2_AGENT_SIGN_RESPONSE` (14) only upon explicit biometric approval.
- **Adversarial Wire Packets**: Empty buffers, unknown message types (`0xFF`), negative/oversized length prefixes, truncated payloads, and sign requests for unwhitelisted keys safely return `SSH_AGENT_FAILURE` without unhandled exceptions.

### 4. FIDO2 Security Key Adversarial Wire Parsing (`OpenSshFido2WireParser`)
- **Dual Algorithm Support**: Complete binary wire encoding and decoding for `sk-ssh-ed25519@openssh.com` and `sk-ecdsa-sha2-nistp256@openssh.com` public key blobs and wire signatures.
- **Flag & Counter Validation**: Verifies monotonic signature counter and enforces `userPresent` (`0x01`) and `userVerified` (`0x04`) flags.
- **Signed Data Blob Construction**: Accurate 69-byte WebAuthn data blob construction: $\text{SHA-256}(\text{app}) \parallel \text{flags} \parallel \text{counter} \parallel \text{SHA-256}(\text{msg})$.
- **Adversarial Wire Rejection**: Rejects wrong key algorithm headers, truncated public key blobs, signatures missing User Presence flag (`0x00`), oversized length prefixes, wrong signature types, and malformed ASN.1 DER ECDSA signatures.

### 5. SFTP Subsystem Path Traversal & Null-Byte Injection (`SftpPathValidator` & `SftpClientManager`)
- **Posix Path Traversal Neutralization**: Canonicalizes complex relative segments (`../../etc/shadow`, `/var/www/../../../etc/passwd`, `a/b/c/../../d`) to absolute canonical POSIX paths.
- **Null-Byte Injection Neutralization**: Strictly throws `IllegalArgumentException` on Unicode null-byte injection (`\u0000`) in `canonicalize` and `join`.
- **Chroot Sandbox Boundary Guard**: Enforces `isWithinBounds` to detect escapes outside assigned chroot directory trees.
- **Safety Limits & Atomic Staging**: Enforces 2MB maximum file preview limit, atomic download staging via `.cossh_part_<uuid>`, and automatic staging artifact cleanup on completion or cancellation.

### 6. Multi-Factor Authentication (`MultiFactorContinuationEngine` / `SSH_AUTH_PARTIAL`)
- **Secondary Factor Continuation**: When server returns `SSH_AUTH_PARTIAL` (`hadPartialSuccess() == true`), orchestrates secondary factor continuation (`password` or `keyboard-interactive` OTP) without dropping live transport.
- **Adversarial Empty Methods Handling**: Cleanly terminates without infinite loops when server returns partial success with empty `allowedMethods`, zeroing ephemeral credential buffers.
- **Failing Secondary Factor Handling**: Cleanly throws `UserAuthException` and sanitizes memory buffers when secondary factor fails.
- **Thread Interruption Handling**: Aborts immediately upon thread interruption without hanging.
