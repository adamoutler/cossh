# User Story: SSH-192 - Replace Generic Notification Icon with Branded Monochrome CoSSH Status Bar Vector

**As an active SSH user running sessions on Android,**
I need a distinctive, branded monochrome notification icon in the system status bar and notification drawer,
**so that** I can instantly recognize active CoSSH foreground sessions at a glance rather than confusing them with generic system notifications.

## Acceptance Criteria
1. **Monochrome Vector Asset:** Create `app/src/main/res/drawable/ic_stat_ssh.xml` complying with Android status bar notification design guidelines (24dp viewport, `#FFFFFF` monochrome silhouette on transparent background, featuring the CoSSH shield outline and terminal prompt `>_`).
2. **Foreground Service Integration:** Replace generic `android.R.drawable.ic_dialog_info` small icon references in `SshService.kt` (`createSummaryNotification` and session notification builder) with `com.adamoutler.ssh.R.drawable.ic_stat_ssh`.
3. **Robolectric Verification:** Verify via unit test `SshServiceNotificationTest` that:
   - `R.drawable.ic_stat_ssh` loads and renders successfully onto a dark cobalt background (`#0A192F`) with non-transparent white pixels.
   - Summary notification smallIcon is set to `R.drawable.ic_stat_ssh`.
   - Active session notification smallIcon is set to `R.drawable.ic_stat_ssh`.
   - Foreground service start sets `lastForegroundNotification.smallIcon` to `R.drawable.ic_stat_ssh`.
4. **Visual Evidence:** Test generates and saves a visual proof PNG artifact at `docs/qa/SSH-192-notification-icon.png` depicting the rendered badge for reality-checker verification.
