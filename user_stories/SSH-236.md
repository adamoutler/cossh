# User Story: SSH-236 — Portable Profile Exporter & JuiceSSH Import Compatibility Engine

## User Story
**As an administrator migrating from JuiceSSH or managing multi-device SSH deployments,**  
**I need** CoSSH to parse JuiceSSH JSON backups and export sanitized, portable OpenSSH and JSON manifests,  
**So that** I can seamlessly migrate connection profiles, preserve grouping hierarchies, and share host definitions across platforms without exposing credentials or introducing directive injection vulnerabilities.

---

## Acceptance Criteria
1. **JuiceSSH Backup Parser:** Parse JuiceSSH JSON backup structures containing `connections` (`name`, `address`, `port`, `username`, `type` / protocol, `group`) and `groups` (`id`, `name`), resolving group IDs to folder names in `ConnectionProfile.folderId`.
2. **Host & Credential Validation:** Validate all destination addresses, ports (1..65535), and usernames via `HostValidator`, verifying IPv4, IPv6, and RFC 1123 hostname compliance while stripping shell injection tokens.
3. **DoS Defense & Bounds Enforcement:** Enforce a strict 1 MB (`MAX_PAYLOAD_BYTES`) payload size limit and 500 connection entry limit (`MAX_ENTRY_COUNT`) across string and stream inputs.
4. **Collision Resolution Strategies:** Implement deterministic merging via `ImportCollisionStrategy` (`SKIP`, `OVERWRITE`, `RENAME`) against existing profile lists and intra-batch duplicates.
5. **OpenSSH Config Export & Round-Trip Compatibility:** Export SSH profiles to standard OpenSSH `~/.ssh/config` stanzas (`Host`, `HostName`, `User`, `Port`, `ProxyJump`, `ServerAliveInterval`), verified for 100% round-trip fidelity with `OpenSshConfigParser.parse(...)`.
6. **Zero Secret Leakage:** Serialized JSON manifests guarantee zero passwords, zero ciphertexts, and zero private keys or keystore references are included.
7. **Directive Injection Defense:** Strip control characters (`\r`, `\n`, `\u0000`) and whitespace from aliases and directives to neutralize OpenSSH command execution vectors (`ProxyCommand`, `LocalCommand`, `Match`).
8. **Test Coverage & Zero Warnings:** Full unit test suite covering DoS boundaries, injection neutralization, collision modes, and round-trip parsing with zero compilation warnings.

---

## Technical Details
- **`com.adamoutler.ssh.network.HostValidator`:** Hardened validation utility providing sanitization (`stripControlChars`), RFC 1123 hostname checks, IPv4/IPv6 address validation, port boundary enforcement (1..65535), and username character verification.
- **`com.adamoutler.ssh.network.JuiceSshImporter`:** Parses JuiceSSH JSON backups, resolves group mappings, applies bounds checks, and merges with existing profiles via `ImportCollisionStrategy`.
- **`com.adamoutler.ssh.network.PortableProfileExporter`:** Generates standard OpenSSH `~/.ssh/config` stanzas and sanitized, secret-free JSON manifests with alias whitespace tokenization defense.
