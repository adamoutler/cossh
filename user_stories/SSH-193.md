# User Story: SSH-193 - Implement Bounded Pinch-to-Zoom Terminal Font Scaling (8sp–32sp)

**As an SSH terminal user,**
I want to use pinch-to-zoom touch gestures on the terminal display to adjust the text size between 8sp and 32sp,
**so that** I can dynamically enlarge small text for readability or shrink text to fit wide terminal buffers without opening settings menus.

## Acceptance Criteria
1. **Bounded Font Range (8sp–32sp):** Terminal font size scaling must be strictly clamped to a minimum of 8sp and a maximum of 32sp via `TerminalScaleHandler.clampFontSize`.
2. **Hysteresis & Thresholding:** Pinch scaling must only increment/decrement font size when the scale gesture crosses thresholds (`< 0.9f` for zoom out, `> 1.1f` for zoom in) to prevent jitter during micro-movements, returning `1.0f` on threshold trigger to reset termux gesture accumulation.
3. **State Synchronization:** `AndroidView` `factory` in `TerminalScreen.kt` must initialize `TerminalView.setTextSize` with device density/fontScale matching the `update` block, and `TerminalViewClient.onScale` must read latest state via `rememberUpdatedState`.
4. **ViewModel Bound Enforcement:** `TerminalViewModel.updateFontSize` must clamp incoming sizes to `8..32`sp before updating `fontSizeFlow`.
5. **Headless Visual Support:** Headless test fallbacks in `TerminalScreenContent` must reflect `currentFontSize.sp` to verify visual font scale differences under test runners.
