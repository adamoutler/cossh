# User Story: SSH-229 - OpenSSH Visual Host Key Randomart (Drunken Bishop) & High-Friction MITM Alert Modal

**As a security-conscious engineer connecting to remote SSH servers,**
I want authentic OpenSSH Drunken Bishop visual host key randomart and a high-friction visual comparison modal during host key verification,
**so that** I can instantly recognize server identity through visual cognitive patterns and avoid accidentally accepting Man-in-the-Middle (MITM) spoofing attacks.

## Acceptance Criteria
1. **Authentic Drunken Bishop Algorithm:** Implement OpenSSH's 17x9 bounded field matrix in pure Kotlin (`OpenSshRandomartGenerator.kt`), using the standard augmentation palette `" .o+=*BOX@%&#/^SE"`, start position at center `(8, 4)` marked with `'S'`, end marker `'E'`, and exact OpenSSH boxed ASCII frame headers `+--[KEY_TYPE]--+` and footers `+----[HASH]----+`.
2. **High-Contrast Terminal Component:** Create `RandomartBox.kt` styled with obsidian terminal aesthetic (`#0B0F19`), 12sp monospace typography, vibrant green `'S'` start marker, and vibrant amber `'E'` end marker.
3. **First-Contact TOFU Integration:** Update `TofuHostKeyVerifier` to compute received host key randomart and render it within the initial trust-establishment prompt in `AppNavigation.kt`.
4. **High-Friction MITM Alert Modal:** When an existing host's key changes (`isKeyChanged == true`), render a high-friction alert dialog presenting side-by-side / distinct-border comparison (Expected Previous Key vs Received Untrusted Key) with their respective randomart boxes, and require holding a 2500ms `HoldToConfirmButton` to overwrite the existing key.
5. **Known Hosts Visual Inspection:** Update `KnownHostsScreen.kt` host cards with an expandable "Show OpenSSH Randomart" row allowing on-demand inspection of stored host public keys.
6. **Automated Verification:** Exhaustive unit tests in `OpenSshRandomartGeneratorTest.kt` verifying exact bit-for-bit parity against reference OpenSSH `ssh-keygen -l -v` output vectors and boundary conditions.
