# User Story: SSH-181 — [EPIC] CI/CD Integrity & Engineering Health

## Goal
Establish a robust, tamper-resistant CI/CD quality gate and healthy engineering baseline:
1. Enforce a non-negotiable minimum of 80% instruction test coverage via `jacocoTestCoverageVerification` in Gradle and CI pipelines.
2. Remediate SonarCloud coverage exclusions so critical security, crypto, network, and backup packages are fully audited.
3. Pin all GitHub Actions and Forgejo CI steps to immutable commit SHAs with least-privilege `contents: read` permissions.
4. Align `compileSdk` and `targetSdk` at 35, eliminating SDK mismatch warnings.
5. Prune dead and unused dependencies (`jose4j`, `jdom2`, `protobuf-java`, `netty-*`) from the project configuration.
6. Configure the `detekt` static analysis plugin to enforce code quality locally and in CI.
7. Make the SonarCloud quality gate strictly blocking, preventing merges on failed quality checks.

## Child Tickets & Scope
- **SSH-198**: Enforce ≥80% Jacoco Coverage Verification, Remediate Sonar Exclusions, and Pin CI Workflows (`Done`)
- **SSH-202**: Align compileSdk/targetSdk to 35, Prune Unused Dependencies, Configure Detekt, and Enforce Blocking Sonar Gate (`Done`)

## Acceptance Criteria
1. **Blocking Quality Gates**:
   - `jacocoTestCoverageVerification` executes in CI and enforces `>= 80%` instruction coverage across the codebase.
   - SonarCloud step is strictly blocking (no `continue-on-error: true`).
2. **Supply-Chain Security & Action Pinning**:
   - All CI actions pinned to full 40-character commit SHAs.
   - Minimal token permissions (`permissions: { contents: read }`).
3. **Toolchain & Dependency Alignment**:
   - `targetSdk` aligned with `compileSdk = 35`.
   - Zero unused direct libraries bundled.
   - Clean `./gradlew detekt testDebugUnitTest lintDebug` pass.
