# User Story: SSH-208 - Auto-Reconnect on Network Change with Circuit Breakers & TOFU Guard

**As a mobile SSH terminal operator frequently moving between Wi-Fi access points and cellular towers,**
I want CoSSH to automatically recover dropped connections using exponential backoff while enforcing strict circuit breakers and zero-prompt TOFU security,
**so that** my terminal session survives transient interruptions without exposing credentials or falling prey to man-in-the-middle attacks.

## Acceptance Criteria
1. **Exponential Backoff Reconnect Loop (`SshService`):**
   - Automatically attempt reconnection upon unexpected socket drops or network loss when `profile.autoReconnect == true`.
   - Apply exponential backoff starting at 2s, doubling up to a maximum cap (32s-60s) up to `maxReconnectAttempts` (default 5).
2. **Immediate Circuit Breakers:**
   - Immediately abort reconnection without retrying upon authentication failure (`UserAuthException` / bad credentials) to prevent server account lockouts.
   - Immediately abort upon manual user disconnect or explicit session cancellation.
3. **Zero-Prompt TOFU Host Key Guard (`TofuHostKeyVerifier` & `SshConnectionManager`):**
   - During autonomous background reconnection (`isAutonomousReconnect == true`), any host key mismatch or unknown host key must immediately fail with `HOST_KEY_MISMATCH_SECURITY_ALERT` / `ConnectionState.Terminated`.
   - Never pop up interactive dialogs in the background during autonomous reconnect.
4. **Terminal Reconnect Banner UI (`TerminalReconnectBanner` & `TerminalScreen`):**
   - Display a non-modal pinned status banner at the top of the terminal screen indicating reconnection progress (`$attempt/$maxAttempts`) with an animated progress bar and a "Cancel" button to abort.
   - Announce status changes via TalkBack accessibility using `LiveRegionMode.Polite`.
5. **Session State Continuity:**
   - Preserve terminal transcripts across reconnect attempts; emit inline warning ANSI notice when dropped, and green success notice when restored.
