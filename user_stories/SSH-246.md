# User Story: SSH-246 — Release Build Hardening, R8/ProGuard Rules, & CI Quality Pipeline

## Goal
Harden the release build configuration, ProGuard/R8 obfuscation rules, CI quality pipelines, and test runner concurrency settings to guarantee zero runtime reflection failures, clean artifact verification, reproducible builds, and attack-resistant production binaries:
1. Protect critical runtime reflection and native components under R8 full-mode obfuscation (SSHJ, Google Tink, Termux Terminal/View, WorkManager `SyncWorker`, and kotlinx.serialization models across security, network, UI, data, and backup modules).
2. Prune unused Google Drive client dependencies (`google-api-services-drive`, `google-api-client-android`, `google-auth-library-oauth2-http`) from Gradle dependency definitions and version catalogs.
3. Enable production Google Drive Cloud Sync (`ENABLE_CLOUD_SYNC = true`) in the `release` build type.
4. Remove the deprecated `TrustAllX509TrustManager` suppression from Android Lint to enforce zero insecure X.509 trust manager implementations.
5. Align test runner concurrency constraints with AGENTS.md Rule 7 (`maxParallelForks = 1`, `forkEvery = 25`, `maxHeapSize = "3072m"`) to eliminate Robolectric concurrent download collisions and JVM thrashing under QEMU emulation.
6. Integrate Detekt Kotlin static code analysis directly into the Forgejo and GitHub CI workflows.

## Scope & Technical Implementation
- **R8 / ProGuard Protection (`app/proguard-rules.pro`)**:
  - Keep and dontwarn rules for `net.schmizz.sshj.**`.
  - Keep and dontwarn rules for `com.google.crypto.tink.**`.
  - Keep rules for `com.termux.terminal.**` and `com.termux.view.**`.
  - Reflection keep rule for WorkManager `com.adamoutler.ssh.sync.SyncWorker`.
  - Comprehensive serialization rules for `@kotlinx.serialization.Serializable` classes and fields across `com.adamoutler.ssh.security.**`, `com.adamoutler.ssh.network.**`, `com.adamoutler.ssh.ui.**`, `com.adamoutler.ssh.data.**`, and `com.adamoutler.ssh.backup.**`.
- **Dependency & Build Cleanliness (`app/build.gradle.kts`, `gradle/libs.versions.toml`)**:
  - Pruned unused `libs.google.api.services.drive`, `libs.google.api.client.android`, and `libs.google.auth.library.oauth2.http`.
  - Set `buildConfigField("boolean", "ENABLE_CLOUD_SYNC", "true")` in `buildTypes.release`.
  - Stripped `TrustAllX509TrustManager` from `android.lint.disable`.
- **Test Runner Concurrency Alignment (`app/build.gradle.kts`)**:
  - Configured `maxParallelForks = 1` and `forkEvery = 25` in `testOptions.unitTests.all`.
  - Configured `maxParallelForks = 1` and `forkEvery = 25` in `tasks.withType<Test>`.
- **Continuous Integration Hardening (`.forgejo/workflows/ci.yml`, `.github/workflows/ci.yml`)**:
  - Added `./gradlew detekt` execution to test and lint stages in both Forgejo and GitHub CI pipelines.
- **Verification (`app/src/test/kotlin/com/adamoutler/ssh/security/ReleaseBuildHardeningVerificationTest.kt`)**:
  - Full automated regression test suite auditing ProGuard rules, Gradle properties, dependency pruning, and CI configurations.

## Acceptance Criteria
1. **R8/ProGuard Hardening**:
   - `app/proguard-rules.pro` contains explicit keep and dontwarn entries for SSHJ, Tink, Termux, SyncWorker, and domain serializable models.
2. **Dependency & Lint Hygiene**:
   - Zero obsolete Google Drive API client dependencies declared in `build.gradle.kts` or `libs.versions.toml`.
   - `TrustAllX509TrustManager` is removed from global lint suppressions.
   - Release builds enable cloud sync (`ENABLE_CLOUD_SYNC = true`).
3. **Deterministic CI/CD Execution**:
   - `maxParallelForks = 1` and `forkEvery = 25` enforced across unit test configurations.
   - Detekt static analysis executes in both Forgejo and GitHub CI workflows.
4. **Verification**:
   - `ReleaseBuildHardeningVerificationTest` executes and passes all test cases.
