# User Story: SSH-221 — Multi-Session Tab Strip, Flicker-Free Hot-Swap Switching, and Zero-Retention Session Teardown

## Epic
**SSH-186**: [EPIC] Terminal Experience

## User Story
**As a** systems administrator running multiple concurrent SSH sessions across tabs,
**I want** an in-terminal tab bar with flicker-free session switching, clear security indicators (SSH shield vs Telnet warning), and complete zero-retention memory scrubbing upon tab closure,
**So that** background sessions never cross-contaminate and closed sessions leave no sensitive data in memory.

## Acceptance Criteria
1. **Isolated Per-Session Flow Streams & State Fix (`SessionStreamRegistry.kt` & `ConnectionStateRepository.kt`):**
   - Provide dedicated per-session flows (`getSessionOutputFlow(sessionId): SharedFlow`), eliminating cross-session buffer congestion and bleed.
   - Refactor `ConnectionStateRepository` to key connection states by `sessionId` rather than `profileId`, preventing state collision between multiple concurrent sessions of the same profile.
2. **Compact Material 3 Terminal Tab Strip (`TerminalSessionTabBar.kt` & `TerminalScreen.kt`):**
   - Render horizontal `ScrollableTabRow` (38dp height) when `activeSessions.size > 1`, auto-collapsing when session count <= 1.
   - Tab anatomy: protocol indicator (Cobalt Shield for SSH, Amber Warning for Telnet), profile nickname or host, animated connection status dot (Green connected, Amber pulsating reconnecting, Red error), and individual close button (`x`).
   - Trailing "+ Connect" tab button to launch session picker or quick connect.
3. **Flicker-Free Hot-Swap Switching:**
   - Retain a persistent `TerminalView` instance, hot-swapping via `terminalView.attachSession(newSession)` without re-inflating Android View hierarchies.
   - Replay buffered background bytes atomically on attach and call `terminalView.onScreenUpdated()`.
4. **Zero-Retention Session Teardown:**
   - Closing a tab cleanly closes SSH shell channel, closes and wipes `ptyOutputStream`, drains and `fill(0)`s `outputBuffer`, reflects and wipes Termux `mLines` character arrays, and cancels the background coroutine job in `SshService`.
5. **Zero-Tolerance Quality:**
   - Zero compiler warnings, strictly safe typing, no unhandled exceptions, and $\ge 80\%$ test coverage.
