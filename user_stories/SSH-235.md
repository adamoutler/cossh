# User Story: SSH-235 — FIDO2 / WebAuthn Hardware Security Keys (`sk-*`) & Biometric SSH-Agent Forwarding Guard

## Epic
**SSH-188**: [EPIC] Security Differentiators — "Most Secure SSH Client on Android"

## User Story
**As a** security engineer operating in untrusted network environments and remote jumphosts,  
**I need** CoSSH to support OpenSSH FIDO2 hardware security keys (`sk-ssh-ed25519@openssh.com` and `sk-ecdsa-sha2-nistp256@openssh.com`) and provide a hardened in-app SSH-Agent handler with per-use biometric confirmation, identity whitelisting, and a strict single-hop loop guard,  
**So that** my credentials cannot be silently drained by compromised intermediate jumpboxes or rogue agent socket hijackers.

## Acceptance Criteria
1. **OpenSSH FIDO2 Wire Protocol Parser (`OpenSshFido2WireParser.kt`):**
   - Supports OpenSSH `sk-ssh-ed25519@openssh.com` and `sk-ecdsa-sha2-nistp256@openssh.com` wire types adhering to `PROTOCOL.u2f`.
   - Implements `encodePublicKeyBlob` and `parsePublicKeyBlob` for FIDO2 public keys including the application identifier (e.g. `ssh:`).
   - Implements `serializeWireSignature` and `parseWireSignature` encoding signature bytes/coordinates, flags byte, and 32-bit counter.
   - Implements `buildSignedDataBlob` producing the standard 69-byte WebAuthn buffer:
     $$\text{SHA-256}(\text{application}) \parallel \text{flags} \parallel \text{counter} \parallel \text{SHA-256}(\text{message})$$
   - Implements `extractEcdsaRs` and `encodeEcdsaRsToDer` converting between ASN.1 DER and wire mpint $(r, s)$ coordinates.
   - Implements `validateFlags` verifying user presence (`0x01`) and user verification (`0x04`).
2. **Hardened Biometric SSH-Agent Handler (`BiometricAuthAgentHandler.kt`):**
   - Implements OpenSSH agent protocol handler:
     - `SSH2_AGENTC_REQUEST_IDENTITIES` (11) -> `SSH2_AGENT_IDENTITIES_ANSWER` (12)
     - `SSH2_AGENTC_SIGN_REQUEST` (13) -> `SSH2_AGENT_SIGN_RESPONSE` (14) or `SSH_AGENT_FAILURE` (5)
   - Enforces per-profile identity whitelisting: returns 0 keys if the whitelist is empty or none match.
   - Enforces per-use biometric confirmation bridge (`BiometricAgentConfirmationBridge`): requires user confirmation before authorizing any cryptographic signature.
   - Enforces forward loop guard: `MAX_ALLOWED_HOPS = 1`. Any sign request with hop count $\ge 1$ is immediately rejected with `SSH_AGENT_FAILURE` to block recursion attacks across intermediate jumpboxes.
3. **Automated Unit Tests:**
   - 100% test pass in `OpenSshFido2WireParserTest.kt` and `BiometricAuthAgentHandlerTest.kt`.
   - Zero compiler warnings, strictly safe typing, complete exception safety.
