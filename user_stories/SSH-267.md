# User Story: SSH-267 — Expose Global Terminal Cursor Style and Blinking Controls in SettingsScreen

## Goal
Enable operators to customize the global terminal cursor appearance and blinking behavior in `SettingsScreen` and `SettingsViewModel`, providing seamless configuration and DECSCUSR ANSI emulator escape sequence updates across all active terminal sessions.

---

## Technical Details & Architecture

1. **Global Cursor Preferences Persistence (`SettingsManager.kt`)**:
   - `globalCursorStyle`: String preference ("BLOCK", "UNDERLINE", "VERTICAL_BAR") defaulted to `BLOCK`.
   - `cursorStyle`: Strongly typed `TerminalCursorStyle` enum accessor with robust fallback to `BLOCK`.
   - `globalCursorBlink`: Boolean preference defaulted to `true`.

2. **Reactive State Modeling (`SettingsViewModel.kt`)**:
   - `SettingsUiState.globalCursorStyle`: Exposes `TerminalCursorStyle`.
   - `SettingsUiState.globalCursorBlink`: Exposes `Boolean`.
   - `updateCursorStyle(style: TerminalCursorStyle)`: Atomically updates `SettingsManager` and emits state update to `_uiState`.
   - `updateCursorBlink(blink: Boolean)`: Atomically updates `SettingsManager` and emits state update to `_uiState`.

3. **Terminal Canvas & Emulator Synchronization (`TerminalScreen.kt` & `TerminalViewModel.kt`)**:
   - `TerminalScreen` collects `cursorStyleFlow` and `cursorBlinkFlow` from `TerminalViewModel`.
   - Sets physical Termux cursor blinker state: `terminalViewRef?.setTerminalCursorBlinkerState(cursorBlink, true)`.
   - Emits standardized DECSCUSR ANSI control sequences to emulator:
     - `BLOCK`: Blink `\u001B[1 q`, Steady `\u001B[2 q`
     - `UNDERLINE`: Blink `\u001B[3 q`, Steady `\u001B[4 q`
     - `VERTICAL_BAR`: Blink `\u001B[5 q`, Steady `\u001B[6 q`

---

## Acceptance Criteria

1. **State & Storage Synchronization**:
   - Calling `SettingsViewModel.updateCursorStyle(TerminalCursorStyle.UNDERLINE)` and `updateCursorStyle(TerminalCursorStyle.VERTICAL_BAR)` immediately updates `uiState.globalCursorStyle` and persists to `SettingsManager`.
   - Calling `SettingsViewModel.updateCursorBlink(false)` and `updateCursorBlink(true)` updates `uiState.globalCursorBlink` and persists to `SettingsManager`.
2. **Terminal Application**:
   - `TerminalScreen` dynamically applies `cursorStyle` and `cursorBlink` to the underlying terminal view client and session emulator.
3. **Automated Verification**:
   - 100% pass rate in `SettingsViewModelTest` unit tests (`testUpdateCursorStyle`, `testUpdateCursorBlink`).
