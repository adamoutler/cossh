# User Story: SSH-268 — Implement Configurable Terminal UX Settings: Volume Keys, Pinch-to-Zoom, Bell Haptics, Back Button, IME & Pocket Detection

## Goal
Empower operators with deep terminal interaction controls across hardware input, haptics, gesture navigation, and security inspection, seamlessly wiring preferences from `SettingsManager` through `TerminalKeyMapper`, `TerminalScreen`, and sensor subsystems.

---

## Technical Details & Architecture

1. **Volume Keys Control (`TerminalVolumeKeysAction`)**:
   - `SYSTEM_VOLUME`: Hardware volume keys bypass terminal interception, allowing standard Android media and notification volume adjustments.
   - `ZOOM_FONT`: Intercepts `KEYCODE_VOLUME_UP` and `KEYCODE_VOLUME_DOWN` in `TerminalKeyMapper` and Compose `onKeyEvent` to dynamically increase or decrease font size.
   - `TerminalKeyMapper`: Supports `interceptVolumeKeys: Boolean = true` (default) with per-call override on `onKeyDown`/`onKeyUp`. When `false`, returns `false` without invoking zoom callbacks.

2. **Pinch-to-Zoom Toggle**:
   - `TerminalViewClient.onScale(scale: Float)` checks `settingsManager.isPinchToZoomEnabled`.
   - When disabled, returns `1.0f` to prevent unintended canvas scaling during multi-touch gestures.
   - When enabled, delegates to `TerminalScaleHandler.onScale(...)`.

3. **Terminal Bell Haptics Toggle**:
   - In `TerminalScreen.kt`, the `terminalViewModel.bellEvents` collector gates tactile haptic feedback behind `settingsManager.isTerminalBellHapticEnabled`.
   - When disabled, bell events execute silently without vibrating the device or disrupting operator focus.

4. **Configurable Back Button Behavior (`TerminalBackButtonBehavior`)**:
   - `SEND_ESC`: Emits ANSI ESC (`byteArrayOf(0x1B)`) to the active terminal session, preventing accidental app exit while interacting with CLI editors (Vim, Nano) or TUI applications. `TerminalViewClient.shouldBackButtonBeMappedToEscape()` returns `true`.
   - `BACKGROUND_SESSION`: Calls `onNavigateBack()` immediately to background the active session without showing the `KeepAliveDialog`.
   - `PROMPT_DIALOG`: Preserves double-tap within 500ms for instant backgrounding or displays the `KeepAliveDialog`.

5. **Direct Character Input Enforcement**:
   - `TerminalViewClient.shouldEnforceCharBasedInput()` directly reads `settingsManager.enforceCharBasedInput`, disabling predictive text buffers and autocorrect on soft keyboards when activated.

6. **Power & Pocket Detection Optimization**:
   - `rememberProximitySensorState(enabled: Boolean = true)`: When disabled by `settingsManager.isPocketDetectionEnabled = false`, deregisters sensor hardware callbacks and yields constant `false`, conserving battery and avoiding sensor conflicts.

7. **Terminal URL Confirmation Defense (`TerminalUrlConfirmationMode`)**:
   - `ALWAYS`: Presents `UrlConfirmationBottomSheet` for every detected URL link tap.
   - `SUSPICIOUS_ONLY`: Safe HTTPS domain links (`candidate.isSecure && !candidate.isDirectIp && !candidate.isPunycode`) launch directly via the system browser chooser; suspicious links (HTTP, direct IP, IDN Punycode) prompt the confirmation bottom sheet.
   - `NEVER`: Directly opens all sanitized URLs via `Intent(Intent.ACTION_VIEW, candidate.uri)`.

---

## Acceptance Criteria

1. **Volume Key Interception**:
   - When `volumeKeysAction == SYSTEM_VOLUME`, `TerminalKeyMapper` and `TerminalScreen` return `false` on volume key events, invoking zero zoom logic.
   - When `volumeKeysAction == ZOOM_FONT`, volume keys scale font size.
2. **Pinch-to-Zoom**:
   - When `isPinchToZoomEnabled == false`, `onScale` returns `1.0f`.
3. **Bell Haptics**:
   - When `isTerminalBellHapticEnabled == false`, bell events produce no tactile vibration.
4. **Back Button Modes**:
   - `SEND_ESC` sends raw `0x1B` byte to the terminal session.
   - `BACKGROUND_SESSION` navigates back directly.
   - `PROMPT_DIALOG` triggers keep-alive confirmation.
5. **Sensor Lifecycle**:
   - Disabling pocket detection prevents hardware proximity listener registration.
6. **Automated Verification**:
   - 100% test pass rate in `TerminalKeyMapperTest` and `SettingsViewModelTest`.
