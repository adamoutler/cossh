# User Story: SSH-244 — Comprehensive Privacy & OS Leakage Hardening

## Epic
**SSH-240**: [EPIC] Pre-Release Security, Privacy, and OS Leakage Hardening

## User Story
**As a** privacy-conscious administrator utilizing CoSSH for remote infrastructure management,
**I want** zero data leakage to operating system services (sensitive clipboard flagging, automatic clipboard scrubbing, incognito keyboard options on credential inputs, complete cloud backup/device-transfer exclusions of billing and audit state, and billing entitlement cryptographic tamper protection),
**So that** sensitive keys, hashes, logs, and billing entitlements can never be exfiltrated through OS clipboard history, auto-fill/learning keyboards, Google cloud backups, or device migrations.

## Acceptance Criteria
1. **Scrub `SecureClipboardManager` Reference & Route Clipboard Writes (`SecureClipboardManager.kt`, `KnownHostsViewModel.kt`, `SecurityAuditLogScreen.kt`, `SftpTextViewerModal.kt`):**
   - In `SecureClipboardManager.clearIfMatching()`, after clearing the clipboard when `currentText == expectedText`, scrub `lastCopiedText = null` to eliminate in-memory credential retention.
   - Expose `@VisibleForTesting internal fun getLastCopiedTextForTest(): String? = lastCopiedText`.
   - Route `KnownHostsViewModel.copyFingerprintToClipboard` to `SecureClipboardManager.copyToClipboard(context, fingerprint, "SSH Fingerprint", viewModelScope)` setting `ClipDescription.EXTRA_IS_SENSITIVE = true` on Android 13+ and auto-clearing after 30s.
   - Route `SecurityAuditLogScreen` JSON-LD export and hash copy actions through `SecureClipboardManager.copyToClipboard(...)`.
   - Route `SftpTextViewerModal` file content copy actions through `SecureClipboardManager.copyToClipboard(...)`.
2. **Enforce Incognito Keyboard Options on Credential Inputs (`QuickConnectBottomSheet.kt`, `AddEditIdentityScreen.kt`):**
   - All password and private key `OutlinedTextField` components specify `keyboardOptions = KeyboardOptions(autoCorrect = false, keyboardType = KeyboardType.Password)` to suppress predictive typing and keyboard learning caches.
3. **Backup & Device Extraction Exclusions (`backup_rules.xml`, `data_extraction_rules.xml`):**
   - Add exclusions for:
     - `sharedpref` path `BillingPrefs.xml`
     - `sharedpref` path `security_audit_anchor_prefs.xml`
     - `file` path `security_audit`
   - Fully declared in `<full-backup-content>` (`backup_rules.xml`) and in both `<cloud-backup>` and `<device-transfer>` sections of `data_extraction_rules.xml`.
4. **Billing Entitlement Tamper Guard (`BillingManager.kt`):**
   - Compute an HMAC-SHA256 signature tag (`cloud_sync_entitled_hmac`) over `"cloud_sync_entitled:true:${context.packageName}"` when `BillingManager` persists `cloud_sync_entitled = true` via `persistEntitlement(prefs)`.
   - Provide `verifyEntitlementIntegrity(): Boolean` that validates both `cloud_sync_entitled = true` and the HMAC signature tag against tampering and cloning.
5. **Comprehensive Automated Verification (`PreReleasePrivacyAndOsLeakageTest.kt`):**
   - Unit tests covering clipboard memory scrubbing, sensitive extras tagging, backup rule XML definitions, data extraction XML definitions, and billing entitlement HMAC integrity validation.
   - Zero compiler warnings, strictly safe typing, and no unhandled exceptions.
