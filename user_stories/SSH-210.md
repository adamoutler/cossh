# User Story: SSH-210 - Hardened Ephemeral Quick Connect with Zero-Retention Memory Sanitization & Session TOFU

**As a systems administrator connecting to one-off servers or ephemeral cloud instances,**
I want to launch ad-hoc SSH and Telnet sessions using a quick connect interface without persisting credentials or host keys to permanent storage,
**so that** sensitive one-time credentials are sanitized immediately upon session termination and permanent storage remains free of ephemeral clutter and orphan host keys.

## Acceptance Criteria
1. **Hardened URI / Target Address Parser (`QuickConnectParser`):**
   - Support `[user@]hostname[:port]` or IP address input for both SSH and Telnet.
   - Support IPv6 addresses enclosed in square brackets (`[::1]:22`).
   - Default port automatically according to protocol (SSH: 22, Telnet: 23).
   - Strictly reject shell injection characters (`;&|$\`<>`), control characters, spaces, and out-of-range ports (1..65535).
2. **Zero-Retention Ephemeral Storage (`EphemeralProfileStore` & `SecurityStorageManager`):**
   - Flag ephemeral sessions with `ConnectionProfile.isEphemeral = true`.
   - Store ephemeral profiles strictly in volatile memory via `EphemeralProfileStore`.
   - Prevent `SecurityStorageManager.saveProfile()` from writing ephemeral profiles to encrypted storage or database (throws `IllegalArgumentException`).
   - Overwrite and sanitize password bytes (`destroySensitiveData()`) on profile eviction or session termination.
3. **Session TOFU Host Key Isolation (`EphemeralHostKeyRegistry`):**
   - Cache accepted host keys for ephemeral sessions strictly in volatile memory during the active session.
   - Enforce TOFU verification during the ephemeral session to prevent MITM attacks without polluting persistent `ssh_known_hosts`.
4. **Material 3 Quick Connect Sheet (`QuickConnectBottomSheet`):**
   - Material 3 bottom sheet accessible from the connection list top bar bolt action.
   - Support dual actions: "Connect" (ephemeral in-memory execution) and "Save & Connect" (permanent encrypted profile persistence).
   - Accessibility semantics (`contentDescription`, `LiveRegionMode.Assertive` error messaging, `ImeAction.Go`).
5. **Zero-Tolerance Quality:**
   - Zero compiler warnings, strictly safe typing, no unhandled exceptions.
   - Comprehensive unit and Paparazzi UI screenshot tests.
