# User Story: SSH-197 - Implement Terminal Color Themes, Monospace Font Selection, and Paparazzi Snapshots

**As an SSH terminal power user,**
I want to customize the terminal's color theme and monospace font and preview them in settings,
**so that** I have an ergonomic, high-contrast, visually pleasant terminal environment tailored to my preferences across all my SSH sessions.

## Acceptance Criteria
1. **Curated Color Palettes (`TerminalTheme`):** Support curated terminal palettes for `COBALT_BLUE` (default CoSSH cobalt blue aesthetic), `SOLARIZED_DARK`, `MONOKAI`, and `DRACULA`. Each theme provides full 16-color ANSI definitions (indices 0..15), default foreground, background, and cursor colors.
2. **Monospace Font Choices (`TerminalFontChoice`):** Support monospace typography selection with `DEFAULT_MONOSPACE`, `JETBRAINS_MONO`, `FIRA_CODE`, `INCONSOLATA`, and `SOURCE_CODE_PRO`, with safe fallback to `Typeface.MONOSPACE`.
3. **Preferences & Profile Persistence:** `SettingsManager` manages global user preferences via `globalColorTheme` and `globalFontChoice`. `ConnectionProfile` supports per-host customization via `colorTheme: String? = null` and `fontChoice: String? = null`.
4. **Active Terminal Engine Styling:** `TerminalScreen` updates the underlying Termux `TerminalView` and emulator via `tv.setBackgroundColor(theme.background)`, `tv.setTypeface(fontChoice.getTypeface())`, and populates `session.emulator.mColors.mCurrentColors` (ANSI 0..15, foreground index 256, background index 257, cursor index 258).
5. **Headless & Settings Preview:** `TerminalScreenContent` headless preview reflects the theme colors and font when `ConnectionStateRepository.isHeadlessTest = true`. `SettingsScreen` features an authentic `TerminalPreviewCard` and ExposedDropdownMenu selectors for interactive customization.
6. **Regression Prevention & Integrity:** All models maintain safe serialization, equality, and zero-warning compilation.
