# User Story: SSH-187 — [EPIC] Power Features — SFTP, Mosh, Automation, Accessibility

## Goal
Deliver hardened, enterprise-grade power features that differentiate CoSSH as a modern, robust, and secure terminal and systems administration platform:
1. **Hardened SFTP Client Engine**: Reactive SFTP subsystem client wrapping SSHJ with strict POSIX path canonicalization, symlink traversal guards, directory operations, and in-process Apache MINA test verification.
2. **Material 3 SFTP File Browser & In-App Text Viewer**: Full-featured remote file browser with interactive breadcrumb path navigation, sorting, multi-selection, POSIX 3x3 permission matrix editor (`chmod`), and memory-guarded (2MB ceiling) scrollable text preview modal.
3. **SAF Scoped Storage Bridge & Background Transfers**: Integration with Android's Storage Access Framework (`DocumentFile` / `ContentResolver`), atomic download staging (`.cossh_part_`), cancellation cleanup, and real-time transfer progress banner.
4. **Home-Screen Dynamic Shortcuts & Biometric-Gated IPC**: Quick connect launcher shortcuts via `ShortcutManagerCompat`, strict intent sanitization rejecting external command injections, and mandatory biometric App Lock gating.
5. **Pre-Connect Wake-on-LAN & Rate-Limited Port Knocking**: Non-blocking UDP magic packet broadcast engine (strict MAC regex validation) and sequential TCP/UDP port knocking engine with 5-second cooldown rate limiting.

## Acceptance Criteria
1. **Full Power Features Delivery**: All 5 child tickets fully implemented, passing 100% of unit, integration, and UI screenshot tests.
2. **Security & Memory Hardening**:
   - Path traversal and null byte neutralization across all remote filesystem operations.
   - Atomic staging preventing partial or corrupted files in destination storage.
   - Strict 2MB ceiling on in-app text preview preventing memory exhaustion.
   - Dynamic shortcuts reject hostile extra injections and enforce biometric App Lock authentication before connection establishment.
   - Strict MAC regex and rate-limiting cooldown preventing network flooding.
3. **Artifact-Backed Verification**:
   - High-fidelity Paparazzi screenshot artifacts committed under `docs/qa/` verifying all UI surfaces and workflows.
   - Unit test suites passing cleanly with zero warnings, strictly safe typing, and zero unhandled exceptions.
