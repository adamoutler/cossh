# User Story: SSH-217 - Deprecate Broken Profile-Level Key Auth in Favor of Unified Identity Profiles

**As a security architect and systems administrator maintaining CoSSH,**
I want to eliminate the broken, half-implemented profile-level direct key storage and unify all SSH private key management exclusively under `IdentityProfile` (backed by Android Keystore MasterKey),
**so that** ambiguous credential storage is eradicated, dead code is removed, and key authentication is strictly typed, hardened, and crash-proof.

## Acceptance Criteria
1. **Unify Key Authentication under Identity Profiles (`AddEditProfileScreen.kt` & `AddEditProfileViewModel.kt`):**
   - Remove the non-functional direct `AuthType.KEY` FilterChip and phantom `availableKeys` dropdown in `AddEditProfileScreen.kt` that attempted to select phantom keys from `SecurityStorageManager.getAllKeys()`.
   - Standardize that selecting Key authentication in `AddEditProfileScreen` links to a configured `IdentityProfile` via `identityId`.
   - When Key auth is active:
     - If an identity is selected, display `SelectedIdentityCard` detailing identity name, username, public key algorithm snippet, and Keystore MasterKey hardware security chip.
     - If no identities exist, display `EmptyIdentitiesPromptCard` with a one-touch "Create / Manage Identities" button.
     - If identities exist but none is selected, display `IdentityDropdown` with "Select an Identity Profile" placeholder.
   - Prune dead code in `SecurityStorageManager.kt` (`getAllKeys()`) and `AddEditProfileViewModel.kt` (`getAvailableKeys()`).
2. **Hardened Handshake Resolution (`SshHandshakeCoordinator.kt`):**
   - Ensure `SshHandshakeCoordinator.getAuthenticator` strictly resolves keys through `IdentityStorageManager.getIdentity(profile.identityId)`.
   - Replace uncaught runtime `IllegalArgumentException` with clean domain `UserAuthException` when an identity is missing or unconfigured.
   - Preserve backward compatibility for unit testing when a `KeyPair` is directly provided.
3. **Zero-Tolerance Quality:**
   - Zero compiler warnings, strictly safe typing, no unhandled exceptions.
   - Minimum 80% test coverage maintained.
