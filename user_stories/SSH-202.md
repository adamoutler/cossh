# User Story: SSH-202 - CoSSH CI/CD Integrity, SDK 35 Alignment, Dependency Pruning, Detekt Static Analysis, and Blocking Quality Gates

**As a DevSecOps & Android Systems Architect,**
I want the repository to align targetSdk with compileSdk at 35, prune unused legacy dependencies and dead ProGuard rules, introduce zero-tolerance Detekt static code analysis, and configure blocking SonarCloud quality gates across all CI pipelines,
**so that** dead dependency baggage is eliminated, supply-chain attack surface is minimized, static analysis code smells are rejected at compile time, and pipeline quality gates cannot be bypassed silently.

## Acceptance Criteria
1. **SDK Alignment**:
   - `targetSdk` is set to `35` in `app/build.gradle.kts`, perfectly matching `compileSdk = 35`.
   - `OldTargetApi` warning is suppressed in Android Lint configuration to allow stable API 35 target level.
2. **Dependency Pruning**:
   - Removed unused packaging exclude rule `META-INF/io.netty.versions.properties` from `app/build.gradle.kts`.
   - Removed obsolete `configurations.all { resolutionStrategy { force(...) } }` Netty block from `app/build.gradle.kts`.
   - Removed direct dependencies on `libs.jose4j`, `libs.jdom2`, `libs.protobuf.java`, and `libs.netty.*` (both `implementation` and `testImplementation`) from `app/build.gradle.kts`.
   - Removed version entries for `netty`, `jose4j`, `jdom2`, and `protobuf` from `gradle/libs.versions.toml`.
   - Removed library declarations for `netty-*`, `jose4j`, `jdom2`, and `protobuf-java` from `gradle/libs.versions.toml`.
   - Removed obsolete `-keep` and `-dontwarn` rules for `io.netty.**` and `org.jose4j.**` from `app/proguard-rules.pro`.
3. **Detekt Static Analysis Configuration**:
   - Added `detekt = "1.23.6"` to `[versions]` and `detekt = { id = "io.gitlab.arturbosch.detekt", version.ref = "detekt" }` to `[plugins]` in `gradle/libs.versions.toml`.
   - Applied `alias(libs.plugins.detekt)` in root `build.gradle.kts` and configured the `detekt` extension pointing to `config/detekt/detekt.yml` with `source.setFrom(files("app/src/main/kotlin", "app/src/main/java"))`.
   - Created `config/detekt/detekt.yml` enforcing `build.maxIssues: 0`, Compose-friendly function naming (`ignoreAnnotated: ['Composable']`), and disabled styling/complexity rules that clash with Spotless (`MagicNumber`, `LongMethod`, `TooManyFunctions`, `WildcardImport`, `MaxLineLength`).
4. **Blocking SonarCloud Quality Gates**:
   - In `.github/workflows/ci.yml` and `.forgejo/workflows/ci.yml`: removed `continue-on-error: true` and `set +e` error masking from the SonarCloud scan step. Configured `set -o pipefail` and piped output to `tee /tmp/sonar.log` to guarantee quality gate failures block CI execution.
5. **Local Verification**:
   - Verified that `JAVA_HOME=/usr/lib/jvm/java-21-openjdk-arm64 QEMU_LD_PREFIX=/home/adamoutler/Android/x86_64-rootfs ./gradlew detekt testDebugUnitTest jacocoTestReport jacocoTestCoverageVerification lintDebug` completes with exit code 0, 0 detekt issues, 0 lint warnings, and >=80% Jacoco instruction coverage.
