# User Story: SSH-158 - [Bug] Missing credentials lead to black screen instead of ephemeral prompt

**As a user,**
if I attempt to connect to a profile that has no saved password (or a blank username),
**so that** the terminal does not open to a black screen and hang,
I need the app to detect missing or failed authentication and provide an ephemeral prompt so I can manually enter my username and password to continue the connection.

## Acceptance Criteria
1. **Intercept Missing Credentials:** Intercept connection attempts where `username` or `password` (if using password auth) are missing before or during the SSH handshake.
2. **Ephemeral UI State:** Emit a specific UI state (`ConnectionState.RequiresCredentials`) that triggers an ephemeral username/password dialog (`AuthPromptDialog`) on the `TerminalScreen`.
3. **Resumption without Persistence:** Once the user provides the ephemeral credentials, resume/retry the connection with the injected credentials without saving them permanently to the profile.
4. **Retry on Failure:** If authentication fails with invalid credentials, prompt again with a retry error message rather than dropping to a dead black screen.
