# User Story: SSH-247 — Binary & Reverse-Engineering Hardening

## Goal
Harden the application binary, build pipeline, and runtime security defenses against static reverse-engineering, decompilation xref analysis, Frida dynamic instrumentation, and debugging data leakage:
1. Enable R8 full mode (`android.enableR8.fullMode=true`) in `gradle.properties` for aggressive cross-method optimizations, inlining, and identifier obfuscation.
2. Configure ProGuard/R8 `-assumenosideeffects` rules to strip verbose and debug logging (`AppLog.v`, `AppLog.d`) from release builds, preventing string cross-reference analysis and sensitive runtime diagnostic disclosure.
3. Remove legacy blanket keep rules (`-keep class com.adamoutler.ssh.** { *; }`) while preserving `@kotlinx.serialization.Serializable` model integrity, allowing R8 to shrink and obfuscate core business logic, domain models, and network handlers.
4. Replace all raw `println(...)` calls across network and UI base components with structured `AppLog` logging, ensuring no unhandled exceptions or sensitive connection parameters escape to raw standard output.
5. Reduce release NDK native debug symbols from `FULL` to `SYMBOL_TABLE` in `app/build.gradle.kts` to strip DWARF debug info from `libtermux.so` while preserving stack trace line numbers.
6. Neutralize the `BillingManager.forceCloudSyncEnabledForTest` test hook in production builds, guaranteeing dynamic hook attempts (e.g. Frida) in release mode have zero effect on cloud sync entitlement.

## Scope & Technical Implementation
- **R8 Full Mode & ProGuard Rules (`gradle.properties`, `app/proguard-rules.pro`)**:
  - `gradle.properties`: Set `android.enableR8.fullMode=true`.
  - `app/proguard-rules.pro`: Added `-assumenosideeffects` for `com.adamoutler.ssh.util.AppLog` (`v` and `d`).
  - Removed blanket keep rules for `data`, `backup`, `security`, `network`, and `ui` packages, ensuring classes are properly obfuscated while maintaining `@kotlinx.serialization.Serializable` class and field preservation.
  - Added `@JvmStatic` annotations to `AppLog` methods to ensure static bytecode signatures exist for R8 rule elimination.
- **Network Logging Sanitization (`app/src/main/kotlin/com/adamoutler/ssh/network/`)**:
  - Replaced raw `println` calls in `SshConnectionManager.kt`, `SshService.kt`, `SshConnectionHandler.kt`, `SshHandshakeCoordinator.kt`, and `PtyStreamBridge.kt` with `AppLog.d(...)`.
  - Replaced raw `println` calls in `BaseAndroidViewModel.kt` and `BaseViewModel.kt` with `AppLog.e(...)`.
- **Native Binary Symbol Hardening (`app/build.gradle.kts`)**:
  - In `buildTypes.release.ndk`, configured `debugSymbolLevel = "SYMBOL_TABLE"` to strip full DWARF native debug metadata from release native binaries.
- **Entitlement Tamper Guard Hardening (`app/src/main/kotlin/com/adamoutler/ssh/billing/BillingManager.kt`)**:
  - Gated `forceCloudSyncEnabledForTest` behind `isTestOverrideAllowed(isDebugBuild, isRobolectricEnv)`.
  - In production release builds outside test harnesses, mutating `forceCloudSyncEnabledForTest` evaluates to `false`, thwarting Frida instrumentation attacks against premium cloud sync gating.
- **Verification Suite (`app/src/test/kotlin/com/adamoutler/ssh/security/ReverseEngineeringHardeningTest.kt`)**:
  - Automated tests asserting R8 full mode, ProGuard stripping rules, release NDK symbol levels, zero raw `println` calls in network orchestrators, and production neutralization of billing test bypass flags.

## Acceptance Criteria
1. **R8 Full Mode & ProGuard Stripping**:
   - `android.enableR8.fullMode=true` is set in `gradle.properties`.
   - `app/proguard-rules.pro` contains `-assumenosideeffects` for `AppLog.v` and `AppLog.d`.
   - Blanket keep rules for app domains are removed.
2. **Network Logging Hygiene**:
   - Zero raw `println(` statements exist in `com.adamoutler.ssh.network` classes.
3. **Native Binary Hardening**:
   - `app/build.gradle.kts` release NDK config specifies `debugSymbolLevel = "SYMBOL_TABLE"`.
4. **Billing Anti-Tamper**:
   - `BillingManager` ignores `forceCloudSyncEnabledForTest` when `isDebugBuild = false` and `isRobolectricEnv = false`.
5. **Verification**:
   - `ReverseEngineeringHardeningTest` and `ReleaseBuildHardeningVerificationTest` pass with zero warnings or errors.
