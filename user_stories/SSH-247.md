# User Story: SSH-247 — Harden Binary Obfuscation, Strip AppLog/Println String Xrefs, and Gate Billing Test Hooks Against Frida/JADX

## Epic
**SSH-188**: [EPIC] Security Differentiators — "Most Secure SSH Client on Android"  
**SSH-180**: [EPIC] Security Hardening

## User Story
**As a** security architect protecting CoSSH against reverse engineering (JADX, Ghidra, Frida),  
**I need** R8 full mode enabled, `@Serializable` ProGuard keep rules tightly scoped so business/security logic methods remain obfuscated, `AppLog.v`/`AppLog.d` and raw `println()` calls stripped from release DEX bytecode, native debug symbols set to `SYMBOL_TABLE` in release builds, and `BillingManager.forceCloudSyncEnabledForTest` restricted strictly to test environments,  
**So that** adversaries cannot decompile internal cryptography and security logic into clean Java source, sensitive endpoints or connection traces are never leaked via log string cross-references in release DEX files, and a one-line Frida hook cannot trivially flip billing entitlement flags in production builds.

## Acceptance Criteria
1. **Tighten R8 / ProGuard Obfuscation (`gradle.properties` & `app/proguard-rules.pro`):**
   - Enable `android.enableR8.fullMode=true` in `gradle.properties`.
   - Scope `@kotlinx.serialization.Serializable` keep rules in `app/proguard-rules.pro` using `-if @kotlinx.serialization.Serializable class **` / `<1>$Companion` / `<1>$$serializer` rules instead of wildcard package keeps (`com.adamoutler.ssh.security.** { *; }`, `network.**`, `backup.**`), ensuring internal security, crypto, and business methods are obfuscated by R8 in release APKs.
2. **Strip `AppLog` & `println()` String Xrefs (`app/proguard-rules.pro`, `network/*`):**
   - Add `-assumenosideeffects class com.adamoutler.ssh.util.AppLog { public static void v(...); public static void d(...); }` to `app/proguard-rules.pro`.
   - Ensure zero raw `println(...)` calls exist in `network/` orchestration classes (`SshConnectionManager.kt`, `SshService.kt`, `SshConnectionHandler.kt`, `SshHandshakeCoordinator.kt`, `PtyStreamBridge.kt`) so hostnames, profile IDs, and exception traces are never emitted to `System.out` in release builds.
3. **Harden Native Symbols & Billing Test Hook (`app/build.gradle.kts` & `BillingManager.kt`):**
   - Configure release `ndk { debugSymbolLevel = "SYMBOL_TABLE" }` in `app/build.gradle.kts` so local C variable names and full DWARF source paths are stripped from release binaries.
   - Gate `BillingManager.forceCloudSyncEnabledForTest` behind `isTestOverrideAllowed()` verifying `BuildConfig.DEBUG || isRobolectricEnvironment()`, ensuring it has zero effect in production release builds even if mutated via Frida or dynamic memory injection.
4. **Verification Proof & Artifacts:**
   - Automated unit tests in `ReverseEngineeringHardeningTest.kt` verifying ProGuard stripping rules, R8 full mode, NDK symbol level, absence of raw `println` calls, and Frida-immunity of billing test hooks.
   - Zero compiler warnings, strictly safe typing, and clean execution of local test suite.
