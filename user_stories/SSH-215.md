# User Story: SSH-215 - SAF Key File Importer & Interactive Passphrase Unlock Modal in Identity Manager

**As an administrator configuring SSH authentication credentials,**
I want to import private and public key files directly from device storage or cloud providers via the Android Storage Access Framework (SAF) and seamlessly unlock encrypted keys in-place,
**so that** I do not have to manually copy and paste multi-line PEM text across apps with clipboard leakage risk.

## Acceptance Criteria
1. **SAF Document Picker Integration (`AddEditIdentityScreen`):**
   - Provide an "Import File" action launching `ActivityResultContracts.OpenDocument()` with MIME type filtering (`*/*`, `text/plain`, `application/x-pem-file`, `application/pkcs8`, `application/octet-stream`).
   - Ingest key streams safely with a strict 64 KB size ceiling to prevent OOM/DoS attacks.
2. **Encrypted Key Workflow & Modal Integration (`IdentityViewModel` & `AddEditIdentityScreen`):**
   - Automatically detect if an imported key is encrypted; if so, retain encrypted bytes in `pendingEncryptedKeyBytes`, extract cipher summary, and display `EncryptedKeyPassphraseModal`.
   - On valid passphrase confirmation, decrypt in-place via `IdentityViewModel.unlockPendingKey()`, extract public key, update `IdentityFormState`, and zero-wipe all temporary byte and char buffers.
   - On invalid passphrase, display error in modal live region without dismissing the dialog.
   - On cancellation, invoke `cancelPendingKeyUnlock()` to zero-wipe pending bytes and dismiss the modal.
3. **ECDSA Key Generation UI:**
   - Provide "Gen ECDSA" alongside "Gen Ed25519" and "Gen RSA-4096" in the key management button row.
4. **Documentation Parity:**
   - Update `wiki/Manage-Identities.md` documenting key file import, ECDSA generation, and encrypted key unlocking.
5. **Zero-Tolerance Quality:**
   - Zero compiler warnings, strictly safe typing, no unhandled exceptions.
   - Comprehensive unit and Paparazzi UI screenshot tests.
