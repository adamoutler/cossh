# User Story: SSH-240 — Automation Guard, HMAC-SHA256 Token Authentication & Quick Connect AppWidget

## Epic
**SSH-187**: [EPIC] Power Features — SFTP, Mosh, Automation, Accessibility

## User Story
**As a** power user automating terminal workflows and launching frequently accessed servers,
**I want** secure external automation intent verification (`ACTION_EXECUTE_AUTOMATION`) with cryptographic HMAC-SHA256 signatures and a home-screen Quick Connect widget,
**So that** I can trigger automated connections and access servers in one tap while guaranteeing third-party applications cannot inject hostile commands, replay tokens, or bypass authentication.

## Acceptance Criteria
1. **Automation Intent Guard (`AutomationIntentGuard.kt`):**
   - Verify incoming `ACTION_EXECUTE_AUTOMATION` intents against constant-time HMAC-SHA256 signatures over canonical payload: `$timestampMs|$nonce|$profileId|$action`.
   - Cryptographic key management in `SecurityStorageManager`: `getAutomationSecretKey()`, `generateOrGetAutomationSecretKey()`, `rotateAutomationSecretKey()`.
   - Reject null intents, invalid actions, and unsupported actions.
   - Strictly reject hostile override extras (`command`, `cmd`, `exec`, `host`, `hostname`, `port`, `password`, `user`, `username`).
   - Validate alphanumeric regex on `profileId` and `nonce`.
   - Validate timestamp freshness: reject expired or future timestamps exceeding 60,000ms clock skew tolerance.
   - Enforce profile existence in secure hardware-backed storage.
2. **Thread-Safe LRU Replay Cache (`NonceReplayCache.kt`):**
   - Maintain a thread-safe bounded LRU cache of 1,000 entries.
   - Enforce 60-second TTL: automatically purge expired nonces and reject replayed nonces within the TTL.
3. **Tamper-Evident Security Audit Logging:**
   - Add `AUTOMATION_INTENT_AUTHENTICATED` and `AUTOMATION_INTENT_REJECTED` to `AuditEventType`.
   - Log all authenticated and rejected automation intents with complete context to `SecurityAuditLogManager`.
4. **Quick Connect AppWidget Provider (`CoSshAppWidgetProvider.kt`):**
   - Extend `AppWidgetProvider` for home-screen quick connect widgets.
   - Create explicit immutable pending intents targeting `MainActivity` with `ACTION_LAUNCH_PROFILE` and `EXTRA_PROFILE_ID`.
   - Guarantee zero credentials or commands passed in widget extras.
   - Define XML metadata in `res/xml/appwidget_quick_connect_info.xml` and layout in `res/layout/widget_quick_connect.xml`.
   - Register receiver in `AndroidManifest.xml`.
5. **Automated Unit Testing & Zero-Tolerance Quality:**
   - 100% pass rate in `AutomationIntentGuardAbuseTest.kt` (covering all abuse vectors, hostile injections, timestamp drifts, replays, and signature verifications).
   - 100% pass rate in `CoSshAppWidgetProviderSecurityTest.kt` (verifying explicit intent routing, immutable flags, and zero-credential IPC).
   - Zero compiler warnings, 0 detekt issues, 0 lint warnings.
