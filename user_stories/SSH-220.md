# User Story: SSH-220 — Terminal Cursor Customization (Block/Underline/Bar, Blink Toggle & Animated Live Preview)

## Epic
**SSH-186**: [EPIC] Terminal Experience

## User Story
**As a** terminal user with specific aesthetic or accessibility needs,
**I want** to choose my preferred terminal cursor shape (Block, Underline, or Vertical Bar) and toggle cursor blinking with an instant live preview in settings,
**So that** my terminal cursor is easily trackable and matches my desktop environment.

## Acceptance Criteria
1. **Domain Model & Persistence (`TerminalCursorStyle.kt` & `SettingsManager.kt`):**
   - Create `enum class TerminalCursorStyle(val id: String, val styleCode: Int, val displayName: String)`:
     - `BLOCK("BLOCK", 0, "Block")`
     - `UNDERLINE("UNDERLINE", 1, "Underline")`
     - `VERTICAL_BAR("BAR", 2, "Bar")`
   - Add `globalCursorStyle` (default `BLOCK`) and `globalCursorBlink` (default `true`) to `SettingsManager.kt`.
   - Add optional overrides in `ConnectionProfile.kt` (`cursorStyle: String? = null`, `cursorBlink: Boolean? = null`).
2. **Terminal Engine Integration (`TerminalViewModel.kt` & `TerminalScreen.kt`):**
   - Connect Termux `setTerminalCursorBlinkerState` and DECSCUSR cursor style escape sequences (`\e[1 q` to `\e[6 q`).
   - Sync cursor preference state through `TerminalViewModel` and apply in `TerminalScreen`.
3. **UI Controls & Animated Live Preview Box (`TerminalCursorPreviewBox.kt`):**
   - Add Cursor Customization card in `TerminalScreen` settings bottom sheet with Material 3 `SingleChoiceSegmentedButtonRow` for shape selection.
   - Add "Blinking Cursor" switch with full TalkBack semantics.
   - Render `TerminalCursorPreviewBox` displaying an authentic VT100 prompt with square-wave 1 Hz blink dynamics and exact theme background/foreground colors.
4. **Zero-Tolerance Quality:**
   - Zero compiler warnings, strictly safe typing, no unhandled exceptions, and $\ge 80\%$ test coverage.
